يوصي Klex معظم المستخدمين ببوت مستضاف على السحابة. يمكنك أيضاً تشغيل البوت على جهاز الكمبيوتر الخاص بك واختيار تسجيله في Klex Cloud أو عدم تسجيله. تحتاج إلى وصول إلى مزود نموذج؛ ويتطلب إعداد Cloud أيضاً حساب Klex Cloud.

<a id="إنشاء-البوت-الخاص-بك"></a>

## إنشاء بوت مستضاف على السحابة

1. سجّل الدخول إلى [Klex Cloud](https://cloud.klex.bot) وابدأ إنشاء بوت.
2. اختر الاستضافة السحابية واتبع التعليمات لإعداد اسم البوت و[‏Soul](/bot/concepts/soul) والمزود والنموذج.
3. وصّل التطبيقات وأجهزة الكمبيوتر التي يحتاجها البوت. راجع [الاتصالات](/bot/concepts/brain-and-computers) لإدارة الوصول.

أرسل رسالة إلى البوت في التطبيق المتصل للتحقق من استجابته. يمكنك عرض نشاطه في لوحة تحكم Cloud.

<a id="التثبيت"></a>

## تثبيت Klex للاستضافة الذاتية

لتشغيل البوت على جهاز الكمبيوتر الخاص بك، ثبّت Klex من الطرفية.

### الإعداد باستخدام Cloud

ابدأ إعداد بوت مستضاف ذاتياً في Klex Cloud واتبع تعليمات التسجيل. يعمل البوت على جهازك، وتوفر Cloud واجهة الإدارة.

### الإعداد المستقل

لتشغيل بوت دون تسجيله في Cloud، ابدأ التطبيق التفاعلي:

```sh
klex --no-cloud
```

1. اضغط `a` لإنشاء بوت وأدخل اسمه.
2. في **Settings → Providers & Endpoints**، اضبط مزود النموذج. في **Model Selection**، اختر نموذج دردشة صالحاً.
3. افتح **Settings → Soul** وأنشئ Soul يصف شخصية البوت وعمله.
4. في **Settings → MCP Servers**، وصّل الخوادم المطلوبة. اضبط أذونات حساب البوت في التطبيقات المتصلة.

لتلقي أحداث من قناة خارجية، وصّل خادم MCP يدعم تحديثات الموارد المعنية أو [امتداد إشعارات الدفع](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) الخاص بـ Klex.

## إنشاء بوت مستضاف ذاتياً دون قائمة الاختيار

للتسجيل في Cloud، احصل على رمز تسجيل Klex Cloud. استخدم إجراء إدارة الأسرار المعتمد لتمريره إلى العملية باسم `KLEX_CLOUD_ENROLLMENT_TOKEN`. ثم شغّل:

```sh
klex --create-bot
```

تعامل مع الرمز كمعلومة سرية، ولا تضعه في البرامج النصية أو وسائط سطر الأوامر أو سجل الطرفية. قيّد أيضاً الوصول إلى بيئة العملية. أضف `--headless` للتشغيل دون واجهة طرفية.

لإنشاء بوت مستقل، حدد اسماً بدلاً من ذلك:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

اضبط المزود والنموذج والاتصالات قبل الاستخدام. لا يمكن استخدام `--create-bot` مع `--data-dir` أو `KLEX_DATA_DIR`؛ فهما لتحديد بوت موجود.

إذا فشل التسجيل في Cloud، يبقى دليل بيانات البوت الجديد ويُعرض مساره. مرّر الرمز عبر `KLEX_CLOUD_ENROLLMENT_TOKEN` وأعد المحاولة باستخدام `klex --data-dir PATH`. استبدل `PATH` بالدليل المعروض بدلاً من إنشاء بوت آخر.
