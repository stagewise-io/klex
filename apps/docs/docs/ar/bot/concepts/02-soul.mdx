## إنشاء Soul وتحديثه

في تطبيق Klex 0.30.1 المستضاف ذاتياً، افتح **Settings → Soul**. يمكنك عرض Soul المحفوظ، وإنشاؤه أو تحديثه بناءً على تعليماتك، أو إعادة إنشائه. يستخدم الإنشاء نموذج الدردشة المُعدّ ويُحفظ الناتج عند نجاحه. تبقى الجلسة العادية متوقفة حتى يُحفظ Soul.

على سبيل المثال، صِف في التعليمات عمل البوت والنبرة المطلوبة وطريقة اتخاذ القرار. راجع Soul الناتج وحدّثه إذا لم يطابق توقعاتك.

يمكنك أيضاً طلب تغييرات على Soul باستخدام [God Messages](/bot/concepts/god-messages). ليست هذه الطريقة الوحيدة لإنشاء Soul أو تحديثه.

## التخزين والوصول

يُحفظ Soul في [دليل بيانات](/bot/concepts/data-directory) البوت. في Klex 0.30.1، يمكن لواجهة Admin API الخاصة بالبوت قراءة Soul وإنشاؤه أو تحديثه بناءً على تعليمات إدارية. لا توجد في الجلسة العادية أداة لكتابة Soul.
