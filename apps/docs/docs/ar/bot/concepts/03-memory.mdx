تدعم ذاكرة Klex Bot **المهارات والتعلّمات**، ويمكنها استرجاع سياق ذي صلة من نشاط البوت السابق. وتُدار في بيئة البوت الخاصة، إلى جانب الجلسات النشطة التي تُبقيه قيد التشغيل.

يمكن للبوت طلب الاسترجاع في الخلفية، وقد يظهر سياق ذو صلة دون طلب. قد تكون المعلومات المسترجعة ناقصة أو خاطئة، لذا تحقّق من التفاصيل المهمة. يمكن لتلميح السياق توجيه الاسترجاع، لكنه ليس وسيلة للتحكم في الوصول.

<a id="where-chats-and-memory-are-stored"></a>

## أين تُحفظ المحادثات والذاكرة؟

تُحفظ المحادثات والذاكرة في دليل بيانات البوت:

- في **البوت المستضاف على Cloud**، يوجد الدليل في البيئة المستضافة.
- في **البوت المستضاف ذاتياً**، يوجد الدليل في المجلد المحلي المستخدم لبيانات البوت.

تُشفّر جميع بيانات البوت المستضاف على Cloud، بما فيها الذاكرة، أثناء النقل والتخزين.

<a id="how-administrators-access-them"></a>

## كيف يصل المسؤولون إليها؟

يمكن للمسؤولين الوصول إلى المحادثات والذاكرة عبر Admin API الخاصة بالبوت. تعمل لوحة Klex Cloud كواجهة ووكيل عكسي لـ Admin API الخاصة بكل بوت. للمزيد عن التخزين، راجع [دليل البيانات](/bot/concepts/data-directory).
