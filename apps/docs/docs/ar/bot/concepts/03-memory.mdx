تساعد الذاكرة Klex Bot على البناء على ما تعلّمه واستخدام سياق من العمل السابق. وهي تجمع بين **المهارات**، بما فيها الإجراءات المكتسبة والمعدّة مسبقاً، والمعرفة ذات الصلة من نشاط البوت.

يمكن للبوت استخدام المهارات لإنجاز المهام المألوفة واسترجاع السياق السابق عند الحاجة، مثل مصطلحات مشروع أو قرار سابق. ويمكنه طلب الاسترجاع في الخلفية، وقد يظهر سياق ذو صلة أثناء عمله. لمزيد من المعلومات عن الإجراءات القابلة لإعادة الاستخدام، راجع [Agent Skills](/bot/concepts/agent-skills).

<a id="where-chats-and-memory-are-stored"></a>

## أين تُحفظ المحادثات والذاكرة؟

تُحفظ المحادثات والذاكرة في دليل بيانات البوت:

- في **البوت المستضاف على Cloud**، يوجد الدليل في البيئة المستضافة.
- في **البوت المستضاف ذاتياً**، يوجد الدليل في المجلد المحلي المستخدم لبيانات البوت.

تُشفّر جميع بيانات البوت المستضاف على Cloud، بما فيها الذاكرة، أثناء النقل والتخزين.

## مراجعة المحادثات والمهارات

يمكن للمسؤولين مراجعة المحادثات والمهارات عبر Admin API الخاصة بالبوت. تعمل لوحة Klex Cloud كواجهة ووكيل عكسي لـ Admin API الخاصة بكل بوت. للمزيد عن التخزين، راجع [دليل البيانات](/bot/concepts/data-directory).
