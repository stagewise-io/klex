Agent Skill هي مجموعة تعليمات قابلة لإعادة الاستخدام لمهمة متكررة. على سبيل المثال، قد تصف مهارة طريقة إعداد تقرير عن حالة مشروع. يوضح وصف المهارة للبوت متى تنطبق التعليمات، ويحتوي متنها على خطوات الإجراء.

يتيح Klex للبوت العثور على المهارات المتاحة وتحميل الإجراء المناسب للمهمة.

<a id="where-skills-come-from"></a>

## مصادر المهارات

يمكن أن تأتي المهارات من مصادر مختلفة:

- **Template Skills** تأتي مع قوالب البوتات.
- **Learned Skills** تتطور من خبرة البوت.
- **Uploaded Skills** يقدمها المستخدمون لتزويد البوت بسلوك أو معرفة.

يخزن كل بوت مهاراته في [دليل البيانات](/bot/concepts/data-directory) الخاص به. وتُعرّف المهارة بنطاق اسم واسم، مثل `learning/project-status`.

تراجع عملية ذاكرة في الخلفية النشاط ويمكن أن تحول الدروس المفيدة إلى مهارات. وقد تحدّث المهارات المكتسبة أو تزيلها عند معالجة نشاط لاحق؛ ولا تؤدي كل محادثة بالضرورة إلى إنشاء مهارة.

تُخزن كل مهارة في ملف `SKILL.md` داخل `skills/{namespace}/{name}/`. يحتوي الملف على اسم ووصف ومتن بصيغة Markdown. ويمكن أن تحتوي المهارة أيضاً على ملفات مرجعية في مجلد `references/`.

<a id="review-and-manage-skills"></a>

## مراجعة المهارات وإدارتها

<Tabs syncKey="hosting" hash={false}>
<Tab title="مستضاف على السحابة">

ستتوفر قريباً إدارة Uploaded Skills عبر Cloud. وستكون Uploaded Skills النوع الوحيد من المهارات الذي يمكن للمستخدمين إدارته عبر Cloud.

</Tab>
<Tab title="مستضاف ذاتياً">

استخدم Admin API الخاص بالبوت لمراجعة المهارات. راجع [مراجعة نشاط البوت](/bot/guides/observability#access-the-local-admin-api) لمعرفة طريقة الوصول المحلي وحدوده الأمنية.

</Tab>
</Tabs>

يمكن لـ Admin API الخاص بالبوت عرض قائمة المهارات واسترجاع محتواها وتعديلها أو حذفها. استخدم `GET /v1/skills` لعرض القائمة و`GET /v1/skills/{namespace}/{name}` لقراءة مهارة. يدعم المسار نفسه `PATCH` و`DELETE`. وللملفات المرجعية مسارات API منفصلة. قد يفشل الحذف إذا كان كيان ذاكرة يشير إلى المهارة.

راجع دقة المهارات المكتسبة. يمكن لعملية الذاكرة تحديث هذه المهارات أو إزالتها بمرور الوقت، بما في ذلك المهارات التي عدّلها المسؤول؛ فالتعديل لا يمنع تغييرات لاحقة.
