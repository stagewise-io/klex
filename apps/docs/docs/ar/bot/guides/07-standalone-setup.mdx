يمكنك تشغيل بوت مستضاف ذاتياً دون تسجيله في Klex Cloud.

## تثبيت Klex

ثبّت Klex في الطرفية:

**macOS أو Linux أو WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

## إنشاء بوت تفاعلياً

شغّل التطبيق:

```sh
klex --no-cloud
```

1. اضغط على `a` لإنشاء بوت وأدخل اسمه.
2. في **Settings → Providers & Endpoints**، اضبط مزود نماذج. في **Model Selection**، اختر نموذجاً للمحادثة.
3. افتح **Settings → Soul** وأنشئ روحاً تصف شخصية البوت وعمله.
4. في **Settings → MCP Servers**، وصّل الخوادم التي يحتاجها البوت. اضبط أذونات حساباته في التطبيقات المتصلة.

لتلقي أحداث من قناة خارجية، وصّل خادماً يدعم MCP Events المناسبة أو الموارد الحية أو [امتداد إشعارات الدفع في Klex](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications). تتطلب MCP Events اشتراكاً في الأحداث (watch)، وتتطلب تحديثات الموارد الحية فتح المورد. تتطلب بعض الخوادم أيضاً إعداداً منفصلاً في الخدمة المتصلة.

## إنشاء بوت دون قائمة الاختيار

لإنشاء بوت مستقل دون قائمة الاختيار التفاعلية، أدخل اسماً:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

أضف `--headless` للتشغيل دون واجهة الطرفية. اضبط مزوداً ونموذج محادثة وروحاً قبل أن يتمكن البوت من العمل. لإعداد بوت جديد تفاعلياً، احذف `--headless` واستخدم الإعدادات أعلاه. للإعداد دون واجهة، استخدم Admin API؛ راجع [الوصول المحلي وحدود الأمان](/bot/guides/observability#access-the-local-admin-api). لا يمكن الجمع بين الإنشاء و`--data-dir` أو `KLEX_DATA_DIR`، فهما يحددان بوتاً موجوداً. لإيقاف بوت يعمل دون واجهة، راجع [التحكم في بوت Klex](/bot/guides/control-and-limits#stop-a-headless-bot).
