> **هل يمكنني تشغيل بوت Klex دون Klex Cloud؟**

نعم. يمكن لبوت Klex المستضاف ذاتيًا العمل دون التسجيل في Cloud. توصي Klex ببوت مستضاف في Cloud لمعظم المستخدمين، وتوصي بتسجيل البوت المستضاف ذاتيًا في Klex Cloud لتجربة إدارة أكثر اكتمالًا.

<a id="choose-how-to-host-the-bot"></a>

## اختيار طريقة استضافة البوت

<a id="klex-cloud-hosted-bot"></a>

### بوت مستضاف في Klex Cloud

تشغّل Klex البوت في بيئتها المستضافة. تُخزّن محادثات البوت وذاكرته في دليل بياناته داخل تلك البيئة. يمكنك استخدام لوحة Cloud لعرض النشاط وإدارة خوادم MCP المتصلة.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### بوت مستضاف ذاتيًا ومسجل في Klex Cloud

تشغّل البوت في بيئة تديرها ويمكنك تسجيله في Klex Cloud. يمنحك ذلك تحكمًا أكبر في مكان عمل البوت مع الاحتفاظ بإدارة Cloud. تبقى محادثات البوت وذاكرته في دليل بياناته المحلي. توفر لوحة Cloud واجهة ووكيلًا عكسيًا لواجهة Admin API الخاصة بالبوت.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### بوت مستضاف ذاتيًا دون التسجيل في Cloud

التسجيل في Cloud ليس متطلبًا تقنيًا للبوت المستضاف ذاتيًا. توصي Klex بالتسجيل لأن التجربة المستقلة أقل اكتمالًا.

<a id="self-hosted-cloud"></a>

### Cloud مستضاف ذاتيًا

تتوفر الاستضافة الذاتية لخدمة Klex Cloud لعملاء Enterprise فقط.

<a id="manage-access-and-stop-a-bot"></a>

## إدارة الوصول وإيقاف البوت

يمكنك في لوحة Cloud مراجعة نشاط البوت وتوصيل خوادم MCP أو فصلها. اضبط أذونات التطبيقات والحسابات الأخرى التي يستخدمها البوت في تلك التطبيقات أو الحسابات. لإيقاف بوت مستضاف ذاتيًا، أغلق تطبيقه. لإيقاف بوت مستضاف في Cloud، استخدم **Stop** في لوحة Cloud.
