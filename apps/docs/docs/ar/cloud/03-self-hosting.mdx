يتوفر Klex Cloud المستضاف ذاتيًا لعملاء Enterprise فقط. تواصل مع Klex لمعرفة متطلبات النشر والتوفر.

تختلف استضافة Cloud ذاتيًا عن تشغيل بوت منفرد في بيئتك الخاصة. يمكن تسجيل البوت المستضاف ذاتيًا في Klex Cloud، لكن التسجيل ليس متطلبًا تقنيًا. راجع [الاستضافة السحابية والاستضافة الذاتية](/ar/cloud/hosted-vs-local) لمعرفة خيارات استضافة البوت.
