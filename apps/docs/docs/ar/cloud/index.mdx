يستضيف [**Klex Cloud**](https://cloud.klex.bot) روبوتات Klex ويوفر لوحة لإدارتها. يمكنك أيضًا تسجيل Bot مستضاف ذاتيًا. اربط التطبيقات والخدمات التي يحتاجها Bot، واضبط حساباته وأذوناته في تلك الخدمات.

<Panel title="من المفيد معرفته">
استخدام Klex Cloud اختياري تمامًا. يمكنك تشغيل Klex Bots بدونه وربط خوادم MCP الخاصة بك.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## إعداد Klex Bot باستخدام Cloud

يتيح لك معالج إعداد Cloud إنشاء Bot مستضاف على Cloud أو إعداد Bot مستضاف ذاتيًا. يرشدك المعالج خلال إعداد Bot ونماذجه. يمكنك ربط التطبيقات والخدمات بعد الإعداد.

ابدأ باتباع [دليل البدء السريع](/ar/bot/quickstart).
