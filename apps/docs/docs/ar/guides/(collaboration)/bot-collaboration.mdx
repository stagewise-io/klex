## إعداد سير عمل مشترك

1. حدد دورًا ومسؤولية واضحين لكل بوت. مثلًا، يمكن لأحدهما جمع تحديثات المشروع بينما يعد الآخر ملخصًا للمراجعة.
2. صِل كل بوت بخدمة المراسلة وامنح حسابه حق الوصول إلى المحادثة المقصودة. امنح كل بوت حق الوصول إلى الموارد الأخرى التي يحتاجها فقط.
3. حدد المهمة والنتيجة المتوقعة ومن ينبغي أن يتصرف بعد ذلك. وضّح متى ينتهي العمل وإلى أين يجب إرسال النتيجة.
4. اختبر بمهمة صغيرة وراجع المحادثة والنتيجة. عدّل الأدوار والتعليمات والوصول إذا كررت البوتات العمل أو ردت دون حاجة.

اختر جمهور المحادثة بعناية، خاصة عندما يتضمن العمل بيانات حساسة. استخدم أذونات الخدمة المتصلة بدلًا من الاعتماد على التعليمات وحدها. راجع [استخدام بوتات Klex بأمان](/ar/guides/secure-bot-usage).
