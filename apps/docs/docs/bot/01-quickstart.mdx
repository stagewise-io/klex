Create a Klex Bot to work alongside you. Klex recommends Cloud hosting for most users; you can also run a Bot on your own computer.

## Cloud-hosted setup

1. Sign in to [Klex Cloud](https://cloud.klex.bot). Create an organization if prompted. You can optionally add your website to get job suggestions.
2. Start creating a Bot. Choose a suggested job or template, or select **Start from scratch** to describe one. Select **Create Klex Bot**.
3. Review the proposed Bot's name, appearance, and character traits. Select **Create** with its name.
4. Once the Bot connects, connect an AI provider and choose its models, or import a model setup from another Bot.
5. When setup finishes, open the Bot's chat to get started.

You can connect the apps and computers your Bot needs for its work. Supported MCP servers can also deliver messages and app events that prompt the Bot to work. See [MCP and Klex Bots](/bot/concepts/mcp) for details.

</Tab>

## Self-hosted setup

1. Sign in to [Klex Cloud](https://cloud.klex.bot) and start creating a Bot. Choose a job or describe one from scratch, then select **Create Klex Bot**.
2. Review the proposed Bot's name, appearance, and character traits. Open **More options** and select **Self-host instead**.
3. Copy the command provided by Klex Cloud, paste it into a terminal on the computer where the Bot should run, and execute it.
4. Once the Bot connects, follow the Cloud setup instructions to connect an AI provider and choose its models.

Keep the Bot running on your computer so it can work. To restart it, run the following command in a terminal and select your Bot:

```sh
klex
```

### Run without Cloud

Cloud enrollment is optional. To configure a Bot directly in the Klex app, follow the [standalone setup guide](/bot/guides/standalone-setup).
