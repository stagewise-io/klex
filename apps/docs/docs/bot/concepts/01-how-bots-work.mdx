> **Where does a Klex Bot do its work?**

A Klex Bot uses its own environment to manage memory and keep the Bot running. All work happens in other, connected environments.

![Diagram: The Bot's own environment manages memory and keeps the Bot running. Machines and MCP servers connect it to other environments, where all work takes place.](/images/klex-bot-work-environments.svg)

## Two environments, different roles

### The Bot's own environment

The Bot's own environment manages its memory and keeps the Bot running. It is not where the Bot carries out work.

### Connected environments

The Bot carries out all work in connected environments. Machines and MCP servers are connectors to those environments.
