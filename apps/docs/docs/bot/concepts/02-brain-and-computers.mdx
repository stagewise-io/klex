> **Why do you split Klex Bot hosting from the computers it uses?**

<Panel title="This answer is being written">
This page will explain the brain-only VM: the Klex Bot VM holds brain, memory, config, and
orchestration state, while all work environments — Linux VMs, browsers, shells — attach from
the outside through MCP and stay replaceable.
