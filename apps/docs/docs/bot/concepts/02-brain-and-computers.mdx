> **What do machines and MCP servers connect a Klex Bot to?**

Machines and MCP servers connect a Klex Bot to other environments. The Bot manages memory and stays running in its own environment, but carries out all work in those connected environments.

## Connectors and work environments

Machines and MCP servers are connectors; the environment they connect to is where work happens. Connecting a Bot to an environment does not move that work into the Bot's own environment.

## Configure access where it belongs

Configure permissions for connected apps and accounts in those apps or accounts. In Klex Cloud, you can review a Bot's activity and connect or disconnect MCP servers.

For the overall model, see [How Klex Bots work](/bot/concepts/how-bots-work). For storage and access to chats and memory, see [The Klex Bot data directory](/bot/concepts/data-directory).
