Klex Bot Memory currently stores **skills and learnings**. It is managed in the Bot's own environment, alongside the active sessions that keep the Bot running.

## Current and planned memory

Today, Memory stores skills and learnings. Memory for facts, individual people, and trust is planned, not a current capability. Details of how memories are created and recalled, including across chats, still need product confirmation.

## Where chats and memory are stored

Chats and memory are stored in the Bot's data directory:

- For a **Cloud-hosted Bot**, the directory is in the hosted environment.
- For a **self-hosted Bot**, it is in the local folder used for the Bot's data.

## How administrators access them

Administrators can access chats and memory through the Bot's Admin API. The Klex Cloud dashboard is a frontend and reverse proxy for each Bot's Admin API. For more on storage, see [the data directory](/bot/concepts/data-directory).
