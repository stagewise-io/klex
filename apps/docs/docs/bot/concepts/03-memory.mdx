> **Where does a Klex Bot manage and store its memory?**

A Klex Bot manages memory in its own environment, which also keeps the Bot running. The Bot does not carry out work there; all work happens in connected environments.

## Where chats and memory are stored

A Klex Bot stores its chats and memory in its data directory. For a Cloud-hosted Bot, the directory is in the hosted environment. For a self-hosted Bot, it is in the local folder used to store the Bot's data.

## How administrators access chats and memory

Admins can access chats and memory through the Bot's Admin API. The Klex Cloud dashboard acts as a reverse proxy and frontend for each Bot's Admin API.

For more detail about the data directory and hosting locations, see [The Klex Bot data directory](/bot/concepts/data-directory) and [Hosted vs. self-hosted Klex Bots](/cloud/hosted-vs-local).

This page covers the confirmed role, storage location, and administrator access for chats and memory. It does not describe what information becomes a memory, how memories are created or recalled, or retention, deletion, and backup behavior; those details need product confirmation.
