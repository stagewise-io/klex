> **Where does a Klex Bot store its chats and memory?**

A Klex Bot stores its chats and memory in its data directory. For a Cloud-hosted Bot, that directory is in the hosted environment. For a self-hosted Bot, it is in the local folder used to store the Bot's data.

Admins can access chats and memory through the Bot's Admin API. The Klex Cloud dashboard acts as a reverse proxy and frontend for each Bot's own Admin API.

## What this page covers

This page documents where chats and memory are stored and how administrators access the Bot's API. It does not specify what the Bot remembers from a conversation, the exact memory format, retention periods, deletion behavior, backups, or what model providers process. Those details need separate confirmation before publication.

See [The data directory](/bot/concepts/data-directory) for an overview of the Bot's data location, and [Data privacy](/cloud/data-privacy) for the current scope of confirmed data-handling information.
