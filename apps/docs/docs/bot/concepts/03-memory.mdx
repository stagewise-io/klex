Klex Bot Memory supports **skills and learnings** and can retrieve relevant context from the Bot's past activity. It is managed in the Bot's own environment, alongside the active sessions that keep the Bot running.

The Bot can request recall in the background, and relevant context may also surface without a request. Recall can miss information or be wrong, so check important details. A context hint can guide recall, but it is not an access control.

## Where chats and memory are stored

Chats and memory are stored in the Bot's data directory:

- For a **Cloud-hosted Bot**, the directory is in the hosted environment.
- For a **self-hosted Bot**, it is in the local folder used for the Bot's data.

All Cloud-hosted Bot data, including memory, is encrypted in transit and at rest.

## How administrators access them

Administrators can access chats and memory through the Bot's Admin API. The Klex Cloud dashboard is a frontend and reverse proxy for each Bot's Admin API. For more on storage, see [the data directory](/bot/concepts/data-directory).
