The soul describes a Bot’s personality, voice, purpose, and priorities. It is separate from its [memory](/bot/concepts/memory) and is included in the context of its regular session.

## Create or update a soul

In the self-hosted Klex 0.30.1 app, open **Settings → Soul**. You can view the saved soul, create one from instructions, update it, or re-create it from scratch. Generation uses your configured chat models and saves successful output. Regular sessions are paused until a soul is saved.

For example, instructions might describe the Bot’s job, preferred tone, and how it should approach decisions. Review the generated soul and update it if it does not reflect what you intended.

Klex also supports [god messages](/bot/concepts/god-messages), which can request a soul change. They are not the only way to create or update a soul.

## Storage and access

The soul is stored in the Bot’s [data directory](/bot/concepts/data-directory). In Klex 0.30.1, the Bot’s Admin API can read the soul and generate a new or updated one from administrator instructions. The regular session does not provide a soul-writing tool.
