> **Where does a Klex Bot store its memory and configuration?**

The data directory is the location where each bot stores its memories and configuration.

It is only accessible to the Klex application, but **not** to the Klex bot itself.
Klex Bots don't have file system access and instead get curated access to parts of their memory and other information.

This prevents leaking information or malicious manipulation of these files.
