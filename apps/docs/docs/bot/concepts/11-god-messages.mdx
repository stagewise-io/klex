God messages are administrator directives processed by a dedicated session, separate from a Bot’s regular conversations. They can request changes to the Bot’s [soul](/bot/concepts/soul).

In the self-hosted Klex app, open **Settings → God Messages** to compose and send a message. For example, an administrator might ask the Bot to update its soul to reflect a change in its role.

God messages are not the only way to manage a soul: the **Soul** settings screen and the Admin API also support creating and updating it from instructions.
