A Klex Bot runs in an environment that manages its active sessions and [memory](/bot/concepts/memory). The Bot works in external computers and apps connected through [MCP](/bot/concepts/mcp).

<a id="the-technical-foundation"></a>
<a id="main-session"></a>

## Regular session

The regular session has access to connected MCP servers. It processes incoming events and can work in connected environments. Available actions depend on the connections and permissions.

<a id="utility-sessions"></a>

## Separate tasks

A Bot can use separate sessions for internal tasks. For example, it can start a consultation on a difficult question and use the result in its work. Do not assume that multiple requests will run simultaneously or finish by a particular time.

<a id="god-session"></a>

## God messages

[God messages](/bot/concepts/god-messages) are administrator directives processed in a dedicated session, separate from regular conversations. They can request a change to the Bot's [soul](/bot/concepts/soul). Administrators can also create and update the soul through the Soul settings or Admin API.

See [How Klex Bots work](/bot/concepts/how-bots-work) for the Bot environment and its connections.
