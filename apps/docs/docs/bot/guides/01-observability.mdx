You can review a Klex Bot's activity in the [Klex Cloud dashboard](https://cloud.klex.bot).

Administrators can also access a Bot's chats and memory through its Admin API. The Cloud dashboard provides a frontend to each Bot's Admin API. For where that data is stored, see [the data directory](/bot/concepts/data-directory).

To stop a Bot or change its connected access, see [Control your Klex Bot](/bot/guides/control-and-limits).
