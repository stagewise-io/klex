Updating Klex does not generally require creating a new Bot. The Bot’s configuration, chats, and memory are associated with its [data directory](/bot/concepts/data-directory). Klex checks supported local data at startup and migrates it when required.

Compatibility depends on the versions involved; an update is not a guarantee that every integration or workflow will continue to work. Before updating, read the release notes for version-specific instructions. Afterward, check that the Bot starts, its connections work, and important workflows still produce the expected results.

## Protect self-hosted data

Before updating a self-hosted Bot, stop it and make a secure backup of its data directory. The directory can contain sensitive information, so restrict access to the backup. Follow your organization’s backup and recovery procedures.

Avoid opening an updated data directory with an older Klex version unless you have verified that it is compatible. If an update fails, investigate the reported error and consult the release notes or Klex support before changing or deleting Bot data.
