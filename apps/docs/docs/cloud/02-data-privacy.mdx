A Bot’s chats and memory are stored in its [data directory](/bot/concepts/data-directory). For a Cloud-hosted Bot, that directory is in the hosted environment. For a self-hosted Bot, it is in the environment where you run the Bot. Administrators can access this data through the Bot’s Admin API.

All Cloud-hosted Bot data, including memory, is encrypted in transit and at rest. This statement does not describe encryption for self-hosted Bots; protect your own hosting environment and storage appropriately.

## Access and connected services

A Bot can work with connected apps using the permissions of its accounts. Review the data and actions each account can access, and the policies of connected services and model providers before using sensitive information. See [Use Klex Bots securely](/guides/secure-bot-usage).

This page does not yet establish whether Klex staff can access hosted data, which third parties process it, how credentials are stored, or the retention and deletion terms. Contact Klex for current details before relying on a particular privacy or compliance requirement.
