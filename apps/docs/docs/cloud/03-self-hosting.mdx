Self-hosted Klex Cloud is available to Enterprise customers only. Contact Klex for deployment requirements and availability.

Self-hosting the Cloud is different from running an individual Bot in your own environment. A self-hosted Bot can be enrolled in Klex Cloud, but Cloud enrollment is not technically required. See [Hosted vs. self-hosted](/cloud/hosted-vs-local) for the Bot hosting options.
