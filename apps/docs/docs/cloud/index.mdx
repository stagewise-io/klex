[**Klex Cloud**](https://cloud.klex.bot) hosts Klex Bots and provides a dashboard for managing them. You can also enroll a self-hosted Bot. Connect the apps and services a Bot needs, and configure its accounts and permissions in those services.

<Panel title="Good to know">
Klex Cloud is **fully optional**. You can run Klex Bots without it and connect your own MCP servers instead.
</Panel>

## Set up a Klex Bot with Cloud

The Cloud setup wizard lets you create a Cloud-hosted Bot or set up a self-hosted Bot. It guides you through configuring the Bot and its models. You can connect apps and services after setup.

Follow the [quickstart](/bot/quickstart) to get started.
