[**Klex Cloud**](https://cloud.klex.bot) hosts Klex-friendly MCP servers for a variety of platforms. It helps give your Klex Bots dedicated identities through accounts, bot instances, or apps, so they can act as themselves in your work platforms.

<Panel title="Good to know">
Klex Cloud is **fully optional**. You can run Klex Bots without it and connect your own MCP servers instead.
</Panel>

## Set up a Klex Bot with Cloud

The Cloud setup wizard guides you through creating a Klex Bot — cloud-hosted by default, self-hosted if you prefer — including configuring models, designing its soul, and connecting MCP servers.

Follow the [quickstart](/bot/quickstart) to get started.

Provider credentials are stored in the Klex Bot's own config, inside its hosted environment — **not** centrally in the cloud.
