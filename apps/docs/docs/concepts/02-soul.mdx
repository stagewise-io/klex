---
title: The Bot's Soul
description: Control how Klex bots act and behave using their soul.
---

The soul is a compact description of the bot's purpose, its character, and its behavior.
It is stored inside the bot's data directory and is always loaded into its context, setting the baseline for the bot's behavior and reactions.

Manage the soul through **Settings → Soul** in the CLI or the dedicated Admin API. Chat sessions read the soul but cannot edit it.

## Creating a bot's soul

Configure a Chat model, then open **Settings → Soul** and describe the bot's purpose, character, and expected behavior. The bot does not process new input until a non-empty soul exists.

### [Creator mode (Cloud-only)](#creator-mode)

In the setup wizard, the cloud offers **Creator Mode**. Creator Mode gives you the option to design the character of the bot like a video game character.

## Updating the soul

Use **Settings → Soul** to update the saved soul. Blank update instructions refine the existing description; re-creation generates a new soul from scratch.

The Admin API exposes `GET /v1/soul`, `POST /v1/soul` for creation or re-creation, and `PATCH /v1/soul` for updates. Generation uses the configured Chat models. Failed generation leaves the existing soul unchanged.
