Ein Klex Bot arbeitet in externen Umgebungen, die über MCP (Model Context Protocol) verbunden sind. Ein MCP-Server kann einen vollständigen Computer oder eine App wie GitHub oder Google Workspace bereitstellen. Auch Computer werden über MCP verbunden.

Die eigene Umgebung hält den Bot am Laufen und verwaltet sein Gedächtnis. In den verbundenen Umgebungen erledigt er seine Arbeit.

<a id="choose-what-to-connect"></a>

## Verbindungen auswählen

- **Computer** bieten eine verbundene Umgebung, in der der Bot arbeiten kann.
- **Apps** stellen ihre Umgebung über einen MCP-Server bereit.

Klex bietet eine Auswahl integrierter MCP-Server. Sie können auch andere MCP-Server verbinden. Welche Umgebungen Sie verbinden, hängt von den Aufgaben des Bots ab.

<a id="manage-a-bots-access"></a>

## Zugriff eines Bots verwalten

Verbinden Sie die Apps und Computer, die Ihr Bot für seine Arbeit benötigt. Bei den meisten MCPs handelt er über ein eigenes Konto oder eine eigene Identität mit Berechtigungen für diesen Bot.

<Tabs syncKey="hosting" hash={false}>
<Tab title="Cloud-gehostet">

Öffnen Sie Ihren Bot in Klex Cloud. Verwalten Sie seine App-Verbindungen unter **Connectors** und seine verbundenen Computer unter **Computers**. Unter **Activity** können Sie auch seine Aktivitäten prüfen.

</Tab>
<Tab title="Selbst gehostet">

Verwalten Sie Serververbindungen in der Klex-App unter **Settings → MCP Servers**. Die Schritte stehen unter [MCP und Klex Bots](/bot/concepts/mcp#add-a-remote-server-in-the-self-hosted-app). Unter **Settings → Logs** können Sie lokale Diagnosedaten prüfen.

</Tab>
</Tabs>

Konfigurieren Sie Berechtigungen für die Konten und verbundenen Apps des Bots direkt in diesen Konten und Apps. Die Verbindung eines Servers und die Zugriffsfreigabe für ein Konto sind getrennte Entscheidungen. Prüfen Sie beides, wenn Sie festlegen, worauf ein Bot zugreifen und was er tun darf.

Einen Überblick finden Sie unter [So funktionieren Klex Bots](/bot/concepts/how-bots-work). Wo Chats und Gedächtnis gespeichert werden, erklärt das [Datenverzeichnis](/bot/concepts/data-directory).
