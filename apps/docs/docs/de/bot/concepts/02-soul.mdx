Die Seele beschreibt die Persönlichkeit, Ausdrucksweise, Aufgabe und Prioritäten eines Bots. Sie ist von seinem [Gedächtnis](/bot/concepts/memory) getrennt und Teil des Kontexts seiner regulären Session.

## Eine Seele erstellen oder aktualisieren

Öffnen Sie in der selbst gehosteten Klex-App 0.30.1 **Settings → Soul**. Sie können die gespeicherte Seele einsehen, sie anhand von Anweisungen erstellen oder aktualisieren oder sie von Grund auf neu erstellen. Die Generierung verwendet Ihre konfigurierten Chat-Modelle und speichert erfolgreiche Ergebnisse. Reguläre Sessions sind pausiert, bis eine Seele gespeichert wurde.

In den Anweisungen können Sie beispielsweise die Aufgabe des Bots, seinen bevorzugten Ton und seinen Umgang mit Entscheidungen beschreiben. Überprüfen Sie die generierte Seele und aktualisieren Sie sie, wenn sie nicht Ihren Vorstellungen entspricht.

Klex unterstützt auch [God Messages](/bot/concepts/god-messages), mit denen eine Änderung der Seele angefordert werden kann. Sie sind nicht die einzige Möglichkeit, eine Seele zu erstellen oder zu aktualisieren.

## Speicherung und Zugriff

Die Seele wird im [Datenverzeichnis](/bot/concepts/data-directory) des Bots gespeichert. In Klex 0.30.1 kann die Admin API des Bots die Seele lesen und anhand von Administratoranweisungen eine neue oder aktualisierte Seele generieren. In der regulären Session steht kein Tool zum Schreiben der Seele zur Verfügung.
