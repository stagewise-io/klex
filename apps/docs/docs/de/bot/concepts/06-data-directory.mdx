Jeder Klex Bot speichert seine Chats und sein Gedächtnis in seinem Datenverzeichnis. Bei einem Cloud-gehosteten Bot liegt das Verzeichnis in der gehosteten Umgebung. Bei einem selbst gehosteten Bot liegt es im lokalen Ordner, der für die Daten des Bots verwendet wird.

Administratoren können über die Admin API des Bots auf Chats und Gedächtnis zugreifen. Das Dashboard von Klex Cloud dient als Reverse-Proxy und Oberfläche für die Admin API des jeweiligen Bots.

## Einen selbst gehosteten Bot finden

In der selbst gehosteten Klex-App sucht der interaktive Start standardmäßig unter `~/.klex/agents` nach Bots. Wenn `KLEX_HOME` gesetzt ist, wird stattdessen der Ordner `agents` unter diesem Pfad verwendet. Mit `--data-dir` wählen Sie ein Verzeichnis direkt aus; die Option hat Vorrang vor `KLEX_DATA_DIR`.

Um beispielsweise einen Bot zu öffnen, dessen Datenverzeichnis bereits bekannt ist:

```sh
klex --data-dir /path/to/bot
```

Ersetzen Sie den Beispielpfad durch das tatsächliche Verzeichnis des Bots. Im [Schnellstart](/bot/quickstart) finden Sie Informationen zum Erstellen eines Bots und zur Einrichtung ohne Terminaloberfläche.

## Daten schützen

Das Verzeichnis kann sensible Informationen enthalten, darunter Konfiguration und Zugangsdaten. Beschränken Sie den Zugriff mithilfe der Berechtigungen Ihres Betriebssystems und schützen Sie erstellte Kopien. Klex fordert beim Erstellen des Verzeichnisses auf Systemen mit Unix-Dateimodi Berechtigungen nur für den Eigentümer an; bestehende Verzeichnisberechtigungen werden nicht geändert. Windows verwendet stattdessen Zugriffssteuerungslisten.

Überprüfen Sie Ihre Sicherungs- und Wiederherstellungsverfahren, bevor Sie Daten löschen oder verschieben. Diese Seite beschreibt weder ein unterstütztes Migrations- oder Wiederherstellungsverfahren noch Aufbewahrungsregeln oder die Datenverarbeitung durch Dritte.
