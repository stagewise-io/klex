Ein Agent Skill ist eine wiederverwendbare Anleitung für eine wiederkehrende Aufgabe. Ein Skill kann zum Beispiel beschreiben, wie ein Projektstatus vorbereitet wird. Seine Beschreibung erklärt, wann die Anleitung gilt; der Hauptteil enthält das Vorgehen.

Klex macht verfügbare Skills für den Bot auffindbar und weist ihn an, vor einer Aufgabe einen passenden Skill zu laden. Ein Skill leitet den Bot an, garantiert aber weder ein bestimmtes Ergebnis noch ersetzt er Kontoberechtigungen.

<a id="where-skills-come-from"></a>

## Woher Skills kommen

Ein Bot kann aus seiner Tätigkeit Skills lernen. Skills können auch aus anderen Quellen stammen, etwa aus Vorlagen. Jeder Bot speichert seine Skills in seinem eigenen [Datenverzeichnis](/bot/concepts/data-directory). Ein Namespace und ein Name kennzeichnen jeden Skill, zum Beispiel `learning/project-status`.

Wenn der Bot seinen aktiven Gesprächskontext verdichtet, kann er die daraus entfernten Aktivitäten auswerten und hilfreiche Erkenntnisse in Skills umwandeln. Das Lernen läuft im Hintergrund und kann Zeit brauchen. Nicht jedes Gespräch führt zu einem Skill.

Jeder Skill wird als Datei `SKILL.md` unter `skills/{namespace}/{name}/` gespeichert. Die Datei enthält einen Namen, eine Beschreibung und einen Markdown-Hauptteil.

<a id="review-and-manage-skills"></a>

## Skills prüfen und verwalten

Über die Admin API des Bots lassen sich Skills auflisten, lesen, bearbeiten und löschen. Mit `GET /v1/skills` rufen Sie die Liste ab und mit `GET /v1/skills/{namespace}/{name}` einen einzelnen Skill. Derselbe Pfad unterstützt auch `PATCH` und `DELETE`.

Prüfen Sie gelernte Skills auf Richtigkeit. Durch das Lernen können sie sich mit der Zeit ändern oder entfernt werden, auch wenn ein Administrator sie bearbeitet hat. Eine Bearbeitung schützt einen gelernten Skill nicht vor späteren Änderungen.
