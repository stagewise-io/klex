God Messages sind Anweisungen von Administratoren, die in einer eigenen Session getrennt von den regulären Gesprächen eines Bots verarbeitet werden. Sie können Änderungen an der [Seele](/bot/concepts/soul) des Bots anfordern.

Öffnen Sie in der selbst gehosteten Klex App **Settings → God Messages**, um eine Nachricht zu verfassen und zu senden. Ein Administrator kann den Bot zum Beispiel bitten, seine Seele an eine veränderte Rolle anzupassen.

God Messages sind nicht die einzige Möglichkeit, eine Seele zu verwalten: Auch über **Soul** in den Einstellungen und über die Admin API lässt sie sich anhand von Anweisungen erstellen oder aktualisieren.
