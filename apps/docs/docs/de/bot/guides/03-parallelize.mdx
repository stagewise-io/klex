Ein einzelner Bot kann mehrere Anfragen erhalten. Gehen Sie aber nicht davon aus, dass er sie gleichzeitig bearbeitet oder bis zu einem bestimmten Zeitpunkt abschließt. Testen Sie Ihre Arbeitslast, bevor Sie sich auf eine bestimmte Anzahl gleichzeitiger Aufgaben verlassen.

Unabhängige Aufgaben können Sie auf mehrere Bots verteilen. Lassen Sie zum Beispiel einen Bot die offenen Issues eines Projekts prüfen und einen anderen die Updates eines separaten Projekts zusammenfassen. Geben Sie jedem Bot eine eigene Aufgabe, die nötigen Verbindungen und Berechtigungen sowie einen klaren Ort für seine Ergebnisse.

<a id="coordinate-and-review"></a>

## Koordinieren und prüfen

- Teilen Sie die Arbeit so auf, dass Bots nicht unbemerkt dieselbe Ressource bearbeiten. Wenn sich Aufgaben überschneiden, legen Sie fest, wer für welche Änderung zuständig ist und wie Konflikte gelöst werden.
- Nutzen Sie für Übergaben ein gemeinsames Gespräch, auf das die Messaging-Konten der Bots Zugriff haben. Siehe [Klex Bots zusammenarbeiten lassen](/guides/bot-collaboration).
- Beginnen Sie mit einem kleinen Test. Prüfen Sie die Ergebnisse, doppelte Arbeit, Zugriffe und die Nutzung des Modellanbieters, bevor Sie die Arbeitslast erhöhen.

Mehr Bots garantieren keine schnelleren oder korrekten Ergebnisse. Das Ergebnis hängt unter anderem von den verbundenen Diensten, der Verfügbarkeit der Modelle und den Aufgaben selbst ab.
