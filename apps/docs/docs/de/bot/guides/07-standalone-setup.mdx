Sie können einen selbst gehosteten Bot betreiben, ohne ihn bei Klex Cloud anzumelden.

<a id="install-klex"></a>

## Klex installieren

Installieren Sie Klex in einem Terminal:

**macOS, Linux oder WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

<a id="create-a-bot-interactively"></a>

## Einen Bot interaktiv erstellen

Starten Sie die App:

```sh
klex --no-cloud
```

1. Drücken Sie `a`, um einen Bot zu erstellen, und geben Sie seinen Namen ein.
2. Richten Sie unter **Settings → Providers & Endpoints** einen Modellanbieter ein. Wählen Sie unter **Model Selection** ein Chat-Modell aus.
3. Öffnen Sie **Settings → Soul** und erstellen Sie eine Soul, die den Charakter und die Arbeit des Bots beschreibt.
4. Verbinden Sie unter **Settings → MCP Servers** die Server, die der Bot benötigt. Konfigurieren Sie seine Kontoberechtigungen in den verbundenen Apps.

Um Ereignisse aus einem externen Kanal zu empfangen, verbinden Sie einen Server, der die passenden MCP Events, Live-Ressourcen oder die [Push-Notification-Erweiterung](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) von Klex unterstützt. MCP Events benötigen eine Watch; für Updates von Live-Ressourcen muss die Ressource geöffnet sein. Manche Server erfordern zusätzlich eine Einrichtung im verbundenen Dienst.

<a id="create-a-bot-without-the-picker"></a>

## Einen Bot ohne Auswahlmenü erstellen

Um einen eigenständigen Bot ohne das interaktive Auswahlmenü zu erstellen, geben Sie einen Namen an:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Fügen Sie `--headless` hinzu, um den Bot ohne Terminal-Oberfläche auszuführen. Konfigurieren Sie einen Anbieter, ein Chat-Modell und eine Soul, bevor der Bot arbeiten kann. Um einen neuen Bot interaktiv einzurichten, lassen Sie `--headless` weg und verwenden Sie die oben beschriebenen Einstellungen. Für die Headless-Konfiguration verwenden Sie die Admin API; beachten Sie deren [lokalen Zugang und Sicherheitsgrenzen](/bot/guides/observability#access-the-local-admin-api). Das Erstellen lässt sich nicht mit `--data-dir` oder `KLEX_DATA_DIR` kombinieren; diese wählen einen bestehenden Bot aus. Zum Beenden eines Headless-Bots siehe [Ihren Klex Bot steuern](/bot/guides/control-and-limits#stop-a-headless-bot).
