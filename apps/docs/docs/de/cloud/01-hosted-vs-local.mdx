> **Kann ich einen Klex Bot ohne Klex Cloud betreiben?**

Ja. Ein selbst gehosteter Klex Bot kann ohne Cloud-Anbindung betrieben werden. Klex empfiehlt für die meisten Nutzer einen in Klex Cloud gehosteten Bot und für selbst gehostete Bots die Anbindung an Klex Cloud für eine vollständigere Verwaltung.

<a id="choose-how-to-host-the-bot"></a>

## Hosting für den Bot wählen

<a id="klex-cloud-hosted-bot"></a>

### In Klex Cloud gehosteter Bot

Klex betreibt den Bot in seiner Hosting-Umgebung. Die Chats und das Gedächtnis des Bots werden dort in seinem Datenverzeichnis gespeichert. Im Dashboard von Klex Cloud können Sie die Aktivität ansehen und verbundene MCPs verwalten.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Selbst gehosteter Bot mit Anbindung an Klex Cloud

Sie betreiben den Bot in einer selbst verwalteten Umgebung und können ihn an Klex Cloud anbinden. So haben Sie mehr Kontrolle über den Betriebsort und nutzen weiterhin die Cloud-Verwaltung. Chats und Gedächtnis bleiben im lokalen Datenverzeichnis des Bots. Das Dashboard von Klex Cloud dient als Oberfläche und Reverse-Proxy für die Admin API des Bots.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Selbst gehosteter Bot ohne Cloud-Anbindung

Für einen selbst gehosteten Bot ist eine Cloud-Anbindung technisch nicht erforderlich. Klex empfiehlt sie, weil der eigenständige Betrieb weniger vollständig ist.

<a id="self-hosted-cloud"></a>

### Selbst gehostete Klex Cloud

Das Selbst-Hosting des Dienstes Klex Cloud ist nur für Enterprise-Kunden verfügbar.

<a id="manage-access-and-stop-a-bot"></a>

## Zugriff verwalten und einen Bot stoppen

Im Dashboard von Klex Cloud können Sie die Aktivität des Bots prüfen und MCPs verbinden oder trennen. Die Berechtigungen für andere Apps und Konten des Bots konfigurieren Sie in den jeweiligen Apps oder Konten. Um einen selbst gehosteten Bot zu stoppen, schließen Sie seine App. Einen in Klex Cloud gehosteten Bot stoppen Sie über **Stop** im Dashboard.

> **Produkthinweis:** Diese Seite behandelt weder die Übertragung eines Bots zwischen Hosting-Arten noch die Aufbewahrung oder Löschung von Chats oder die Datenverarbeitung durch Dritte. Diese Punkte müssen gesondert bestätigt werden.
