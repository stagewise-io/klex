Selbst gehostete Klex Cloud ist nur für Enterprise-Kunden verfügbar. Kontaktieren Sie Klex zu den Voraussetzungen und der Verfügbarkeit.

Klex Cloud selbst zu hosten ist etwas anderes, als einen einzelnen Bot in der eigenen Umgebung zu betreiben. Ein selbst gehosteter Bot kann an Klex Cloud angebunden werden, die Anbindung ist technisch aber nicht erforderlich. Die Hosting-Möglichkeiten für Bots finden Sie unter [Gehostete und selbst gehostete Klex Bots](/cloud/hosted-vs-local).
