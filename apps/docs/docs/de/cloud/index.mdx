[**Klex Cloud**](https://cloud.klex.bot) hostet Klex-kompatible MCP-Server für verschiedene Plattformen. Sie unterstützt eigene Identitäten für Ihre Klex Bots über Konten, Bot-Instanzen oder Apps, damit die Bots auf Ihren Arbeitsplattformen als sie selbst handeln können.

<Panel title="Gut zu wissen">
Klex Cloud ist **vollständig optional**. Sie können Klex Bots ohne Klex Cloud betreiben und stattdessen eigene MCP-Server verbinden.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Einen Klex Bot mit Klex Cloud einrichten

Der Einrichtungsassistent von Klex Cloud führt Sie durch die Erstellung eines Klex Bots. Standardmäßig wird der Bot in der Cloud gehostet; Sie können ihn auch selbst hosten. Der Assistent hilft Ihnen dabei, Modelle zu konfigurieren, die Soul zu gestalten und MCP-Server zu verbinden.

Beginnen Sie mit dem [Schnellstart](/bot/quickstart).
