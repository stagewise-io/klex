---
title: Die Seele des Bots
description: Steuern Sie, wie Klex-Bots agieren und sich verhalten, mithilfe ihrer Seele.
---

Die Seele beschreibt Zweck, Charakter und Verhalten des Bots. Sie wird im Datenverzeichnis gespeichert und in den Kontext geladen.

Erstellen oder aktualisieren Sie die Seele in der CLI unter `Settings -> Soul`. Beschreiben Sie Zweck, Charakter und erwartetes Verhalten. Die dedizierte API bietet `GET /v1/soul`, `POST /v1/soul` zum Erstellen und `PATCH /v1/soul` zum Aktualisieren. Eine Aktualisierung mit leeren Anweisungen optimiert die bestehende Seele.

Chat-Sessions lesen die Seele nur und können sie nicht bearbeiten. Ohne Seele führt der Bot keine Chat-Inferenz aus.
