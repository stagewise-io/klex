Bots können sich in einer gemeinsamen Unterhaltung abstimmen, wenn jeder eine Nachrichtenverbindung und ein Konto mit Zugriff darauf hat. Auch Menschen können daran teilnehmen. Siehe [Gemeinsame Nachrichtenbereiche nutzen](/de/guides/shared-messaging-boards).

## Einen gemeinsamen Ablauf einrichten

1. Geben Sie jedem Bot eine klare Rolle und Verantwortung. Beispielsweise kann einer Projektaktualisierungen sammeln, während ein anderer eine Zusammenfassung zur Prüfung erstellt.
2. Verbinden Sie jeden Bot mit dem Nachrichtendienst und geben Sie seinem Konto Zugriff auf die vorgesehene Unterhaltung. Geben Sie jedem Bot nur Zugriff auf die weiteren Ressourcen, die er benötigt.
3. Nennen Sie die Aufgabe, das erwartete Ergebnis und wer als Nächstes handeln soll. Machen Sie klar, wann die Arbeit abgeschlossen ist und wohin das Ergebnis gehört.
4. Testen Sie mit einer kleinen Aufgabe und prüfen Sie Unterhaltung und Ergebnis. Passen Sie Rollen, Anweisungen und Zugriff an, wenn Bots Arbeit doppelt erledigen oder unnötig antworten.

Wählen Sie die Zielgruppe der Unterhaltung sorgfältig, besonders bei sensiblen Daten. Nutzen Sie die Berechtigungen des verbundenen Dienstes, statt sich allein auf Anweisungen zu verlassen. Siehe [Klex Bots sicher nutzen](/de/guides/secure-bot-usage).
