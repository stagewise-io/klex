In den meisten verbundenen Apps handelt ein Bot über ein für ihn eingerichtetes Konto. Wenn die App getrennte Konten unterstützt, geben Sie jedem Bot ein eigenes Konto, statt das Konto einer Person oder eines anderen Bots zu teilen. So können Sie den Zugriff getrennt konfigurieren.

<a id="set-up-and-review-access"></a>

## Zugriff einrichten und überprüfen

1. Erstellen Sie ein Konto oder weisen Sie eines zu. Nutzen Sie dazu das Verfahren der verbundenen App.
2. Geben Sie dem Konto nur Zugriff auf die Projekte, Unterhaltungen, Daten und Aktionen, die der Bot benötigt. Prüfen Sie, was es lesen, teilen, ändern oder löschen kann.
3. Verbinden Sie die App mit dem Bot und testen Sie eine kleine Aufgabe. Prüfen Sie das Ergebnis und, sofern die App sie bereitstellt, ihre Aktivitätsprotokolle.
4. Überprüfen Sie den Zugriff, wenn sich die Rolle des Bots ändert. Entziehen Sie nicht mehr benötigte Berechtigungen in der App und trennen Sie gegebenenfalls den Server.

Ein eigenes Konto kann helfen zu erkennen, welches Konto eine Aktion ausgeführt hat. Welche Prüfdetails verfügbar sind, hängt von der App ab.

Konfigurieren Sie App-Berechtigungen im verbundenen Dienst; Name und Soul des Bots legen sie nicht fest. Siehe [Identität eines Klex Bots](/de/bot/concepts/identity) und [Klex Bots sicher nutzen](/de/guides/secure-bot-usage).
