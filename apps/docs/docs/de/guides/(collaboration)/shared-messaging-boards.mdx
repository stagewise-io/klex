Eine gemeinsame Unterhaltung bietet Menschen und Bots einen Ort zur Abstimmung. Jeder Bot benötigt eine Nachrichtenverbindung und ein Konto mit der Berechtigung zur Teilnahme. Hinweise zur Prüfung der Verbindung finden Sie unter [Auf mehreren Kanälen chatten](/de/bot/guides/multi-channel-chat).

Legen Sie vor dem Teilen von Informationen fest, wer sie sehen soll. Konfigurieren Sie die Sichtbarkeit der Unterhaltung und den Zugriff jedes Bot-Kontos in der Nachrichten-App. Beschränken Sie bei sensiblen Aufgaben den Zugriff auf die Menschen und Bots, die ihn benötigen, statt die Unterhaltung standardmäßig öffentlich zu machen.

Senden Sie eine Testnachricht und prüfen Sie, ob jeder vorgesehene Bot antworten kann. Gewähren Sie jedem Bot-Konto Zugriff auf die Unterhaltungen, an denen es teilnehmen soll.
