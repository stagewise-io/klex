Ein Unternehmenshandbuch kann Bots einheitlichen Kontext über Ihr Unternehmen geben. Es kann etwa Ihre Kunden, Ihre Terminologie und die für ihre Arbeit relevanten Grundsätze beschreiben.

Das Handbuch kann ein Dokument oder eine interne Website sein, sofern jeder Bot, der es benötigt, über eine Verbindung zum Lesen der Quelle und ein Konto mit Zugriff verfügt. Die verfügbaren Funktionen hängen vom MCP-Server und dem verbundenen Dienst ab.

<a id="share-it-safely"></a>

## Sicher teilen

- Geben Sie jedem Bot nur Zugriff auf das Material, das er benötigt. Bewahren Sie sensible Verfahren und Zugangsdaten in angemessen geschützten Quellen auf.
- Nennen Sie eine verantwortliche Person und ein Überprüfungsdatum, damit der Inhalt aktuell bleibt. Entfernen Sie veraltete Anweisungen.
- Bitten Sie den Bot, das Handbuch für eine kleine Aufgabe zu verwenden, und prüfen Sie anschließend das Ergebnis und die verwendete Quelle.

Konfigurieren Sie Berechtigungen in verbundenen Diensten und lassen Sie Arbeit mit wichtigen Folgen unabhängig prüfen. Siehe [Klex Bots sicher nutzen](/de/guides/secure-bot-usage).
