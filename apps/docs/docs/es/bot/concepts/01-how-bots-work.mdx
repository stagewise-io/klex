Un Klex Bot es un agente autónomo con su propia identidad y memoria. Se ejecuta en un entorno de Bot y trabaja en otros entornos conectados mediante MCP (Model Context Protocol).

El entorno del Bot lo mantiene en funcionamiento y gestiona su memoria. El Bot realiza su trabajo en los ordenadores y aplicaciones conectados.

<span id="where-the-bot-runs"></span>

## Dónde se ejecuta el Bot

Puedes usar un Bot alojado en Cloud o ejecutar uno en tu propio entorno. Klex recomienda el alojamiento en Cloud. Un Bot autoalojado también puede registrarse en Klex Cloud. El registro no es técnicamente necesario para un Bot autoalojado, aunque la experiencia independiente es menos completa. Consulta [Alojamiento en Cloud o autoalojamiento](/cloud/hosted-vs-local).

<span id="how-the-bot-works-with-computers-and-apps"></span>

## Cómo trabaja el Bot con ordenadores y aplicaciones

Un Bot se conecta a un servidor MCP para acceder a un entorno externo. Puede ser un ordenador completo o una aplicación como GitHub o Google Workspace. Los ordenadores también se conectan mediante MCP.

En la mayoría de los MCP, el Bot actúa mediante una cuenta o identidad propia. Esa identidad se configura para cada Bot y puede tener permisos y autorizaciones de acceso. Consulta [Conexiones](/bot/concepts/brain-and-computers) para conocer el modelo de conexión y acceso.

<span id="what-the-bot-remembers"></span>

## Qué recuerda el Bot

La memoria de un Klex Bot admite habilidades y aprendizajes y puede recuperar contexto relevante de actividades anteriores. Consulta [Memoria](/bot/concepts/memory) para conocer lo que se sabe hoy y [Directorio de datos](/bot/concepts/data-directory) para obtener información sobre almacenamiento y acceso de administradores.
