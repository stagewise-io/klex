---
title: El Alma del Bot
description: Controle cómo actúan y se comportan los bots de Klex usando su alma.
---

El alma es una descripción compacta del propósito, el carácter y el comportamiento del bot. Se almacena en su directorio de datos y se carga en el contexto.

Cree o actualice el alma en `Settings -> Soul` en la CLI. Describa el propósito, el carácter y el comportamiento esperado. La API dedicada ofrece `GET /v1/soul`, `POST /v1/soul` para crear y `PATCH /v1/soul` para actualizar. Una actualización con instrucciones vacías optimiza el alma existente.

Las sesiones de chat solo leen el alma; no pueden editarla. Sin un alma, el bot no ejecuta inferencias de chat.
