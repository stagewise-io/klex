La memoria ayuda a un Klex Bot a aprovechar lo aprendido y el contexto de trabajos anteriores. Combina **skills**, incluidos procedimientos aprendidos y preconfigurados, con conocimientos relevantes de la actividad del Bot.

Un Bot puede usar skills para tareas conocidas y recuperar contexto anterior cuando resulte útil, como la terminología de un proyecto o una decisión previa. Puede solicitar recuerdos en segundo plano y también puede aparecer contexto relevante mientras trabaja. Consulta [Agent Skills](/bot/concepts/agent-skills) para saber más sobre los procedimientos reutilizables.

<a id="where-chats-and-memory-are-stored"></a>

## Dónde se almacenan los chats y la memoria

Los chats y la memoria se almacenan en el directorio de datos del Bot:

- En un **Bot alojado en Cloud**, el directorio está en el entorno alojado.
- En un **Bot autoalojado**, está en la carpeta local que se usa para sus datos.

Todos los datos de los Bots alojados en Cloud, incluida la memoria, están cifrados en tránsito y en reposo.

## Revisar chats y skills

Los administradores pueden revisar los chats y las skills mediante la Admin API del Bot. El panel de Klex Cloud sirve como interfaz y proxy inverso para la Admin API de cada Bot. Para obtener más información sobre el almacenamiento, consulta el [directorio de datos](/bot/concepts/data-directory).
