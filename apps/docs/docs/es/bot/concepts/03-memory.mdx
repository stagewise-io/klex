La memoria de Klex Bot almacena **skills y aprendizajes**. Se gestiona en el entorno propio del Bot, junto con las sesiones activas que mantienen el Bot en funcionamiento.

<a id="where-chats-and-memory-are-stored"></a>

## Dónde se almacenan los chats y la memoria

Los chats y la memoria se almacenan en el directorio de datos del Bot:

- En un **Bot alojado en Cloud**, el directorio está en el entorno alojado.
- En un **Bot autoalojado**, está en la carpeta local que se usa para sus datos.

Todos los datos de los Bots alojados en Cloud, incluida la memoria, están cifrados en tránsito y en reposo.

<a id="how-administrators-access-them"></a>

## Cómo acceden los administradores

Los administradores pueden acceder a los chats y a la memoria mediante la Admin API del Bot. El panel de Klex Cloud sirve como interfaz y proxy inverso para la Admin API de cada Bot. Para obtener más información sobre el almacenamiento, consulta el [directorio de datos](/bot/concepts/data-directory).
