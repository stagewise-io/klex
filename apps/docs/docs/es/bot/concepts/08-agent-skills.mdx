Un Agent Skill es un conjunto reutilizable de instrucciones para una tarea recurrente. Por ejemplo, un skill puede describir cómo preparar un informe de estado de un proyecto. Su descripción indica cuándo se aplican las instrucciones y su contenido explica el procedimiento.

Klex permite que el Bot descubra los skills disponibles y le indica que cargue el skill adecuado antes de actuar. Un skill orienta al Bot: no garantiza un resultado concreto ni sustituye los permisos de las cuentas.

<a id="where-skills-come-from"></a>

## De dónde vienen los skills

Un Bot puede aprender skills a partir de su actividad. También pueden proceder de otras fuentes, como plantillas. Cada Bot almacena sus skills en su propio [directorio de datos](/bot/concepts/data-directory). Cada skill se identifica mediante un espacio de nombres y un nombre, como `learning/project-status`.

Cuando el Bot comprime el contexto activo de una conversación, puede revisar la actividad descartada y convertir las lecciones útiles en skills. El aprendizaje ocurre en segundo plano y puede llevar tiempo; una conversación no produce necesariamente un skill.

Cada skill se almacena en un archivo `SKILL.md` dentro de `skills/{namespace}/{name}/`. El archivo contiene un nombre, una descripción y un cuerpo en Markdown.

<a id="review-and-manage-skills"></a>

## Revisar y gestionar los skills

La Admin API del Bot permite listar los skills, consultar su contenido, editarlos o eliminarlos. Usa `GET /v1/skills` para listarlos y `GET /v1/skills/{namespace}/{name}` para leer uno. La misma ruta admite `PATCH` y `DELETE`.

Revisa la exactitud de los skills aprendidos. El aprendizaje puede actualizarlos o eliminarlos con el tiempo, incluidos los que haya editado una persona administradora. Una edición no impide que un skill aprendido cambie más adelante.
