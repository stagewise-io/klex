Los God Messages son directrices de administración que se procesan en una sesión dedicada, separada de las conversaciones habituales del Bot. Pueden solicitar cambios en el [alma](/bot/concepts/soul) del Bot.

En la aplicación de Klex autoalojada, abre **Settings → God Messages** para redactar y enviar un mensaje. Por ejemplo, una persona administradora puede pedir al Bot que actualice su alma para reflejar un cambio de función.

Los God Messages no son la única forma de gestionar un alma: la pantalla **Soul** de los ajustes y la Admin API también permiten crearla o actualizarla a partir de instrucciones.
