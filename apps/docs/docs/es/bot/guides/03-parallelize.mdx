Puedes repartir el trabajo independiente entre varios Bots. Por ejemplo, asigna a un Bot la revisión de las incidencias abiertas de un proyecto y a otro el resumen de las actualizaciones de un proyecto distinto. Dale a cada Bot su propia tarea, las conexiones y los permisos necesarios y un lugar claro donde comunicar su resultado.

<a id="coordinate-and-review"></a>

## Coordinar y revisar

- Divide el trabajo para que los Bots no modifiquen el mismo recurso sin saberlo. Si las tareas se solapan, define quién es responsable de cada cambio y cómo se resuelven los conflictos.
- Usa una conversación compartida para los traspasos si las cuentas de mensajería de los Bots tienen acceso. Consulta [Cómo hacer que los Klex Bots colaboren](/es/guides/bot-collaboration).
- Empieza con una prueba pequeña. Revisa los resultados, el trabajo duplicado, los accesos y el uso del proveedor de modelos antes de aumentar la carga de trabajo.
