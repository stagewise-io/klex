Puedes ejecutar un Bot autoalojado sin registrarlo en Klex Cloud.

<a id="install-klex"></a>

## Instalar Klex

Instala Klex en una terminal:

**macOS, Linux o WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

<a id="create-a-bot-interactively"></a>

## Crear un Bot de forma interactiva

Inicia la aplicación:

```sh
klex --no-cloud
```

1. Pulsa `a` para crear un Bot e introduce su nombre.
2. En **Settings → Providers & Endpoints**, configura un proveedor de modelos. En **Model Selection**, selecciona un modelo de chat.
3. Abre **Settings → Soul** y crea una Soul que describa el carácter y el trabajo del Bot.
4. En **Settings → MCP Servers**, conecta los servidores que necesita el Bot. Configura los permisos de su cuenta en las aplicaciones conectadas.

Para recibir eventos de un canal externo, conecta un servidor compatible con los MCP Events correspondientes, los recursos en vivo o la [extensión de notificaciones push](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) de Klex. Los MCP Events requieren una watch y, para recibir actualizaciones de un recurso en vivo, el recurso debe estar abierto. Algunos servidores también requieren una configuración en el servicio conectado.

<a id="create-a-bot-without-the-picker"></a>

## Crear un Bot sin el selector

Para crear un Bot independiente sin el selector interactivo, proporciona un nombre:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Añade `--headless` para ejecutarlo sin la interfaz de terminal. Configura un proveedor, un modelo de chat y una Soul antes de que el Bot pueda trabajar. Para configurar un Bot nuevo de forma interactiva, omite `--headless` y usa la configuración anterior. Para configurarlo en modo headless, usa la Admin API; consulta sus [condiciones de acceso local y límites de seguridad](/bot/guides/observability#access-the-local-admin-api). La creación no se puede combinar con `--data-dir` ni con `KLEX_DATA_DIR`, que seleccionan un Bot existente. Para detener un Bot headless, consulta [Controlar tu Klex Bot](/bot/guides/control-and-limits#stop-a-headless-bot).
