> **¿Puedo ejecutar un Bot de Klex sin Klex Cloud?**

Sí. Un Bot de Klex autoalojado puede funcionar sin vincularse a Cloud. Klex recomienda un Bot alojado en Cloud para la mayoría de usuarios y recomienda vincular un Bot autoalojado a Klex Cloud para una gestión más completa.

<a id="choose-how-to-host-the-bot"></a>

## Elegir cómo alojar el Bot

<a id="klex-cloud-hosted-bot"></a>

### Bot alojado en Klex Cloud

Klex ejecuta el Bot en su entorno alojado. Los chats y la memoria del Bot se almacenan en su directorio de datos en ese entorno. Puedes usar el panel de Cloud para ver la actividad y gestionar los MCP conectados.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Bot autoalojado vinculado a Klex Cloud

Ejecutas el Bot en un entorno que gestionas y puedes vincularlo a Klex Cloud. Esto te da más control sobre dónde funciona el Bot y mantiene la gestión desde Cloud. Sus chats y su memoria permanecen en su directorio de datos local. El panel de Cloud proporciona una interfaz y un proxy inverso para la API Admin del Bot.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Bot autoalojado sin vinculación a Cloud

La vinculación a Cloud no es un requisito técnico para un Bot autoalojado. Klex la recomienda porque la experiencia independiente es menos completa.

<a id="self-hosted-cloud"></a>

### Cloud autoalojado

El autoalojamiento del servicio Klex Cloud solo está disponible para clientes Enterprise.

<a id="manage-access-and-stop-a-bot"></a>

## Gestionar el acceso y detener un Bot

En el panel de Cloud puedes revisar la actividad del Bot y conectar o desconectar MCP. Para las demás aplicaciones y cuentas que usa el Bot, configura los permisos en ellas. Para detener un Bot autoalojado, cierra su aplicación. Para detener un Bot alojado en Cloud, usa **Stop** en el panel de Cloud.
