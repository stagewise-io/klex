Klex Cloud autoalojado solo está disponible para clientes Enterprise. Contacta con Klex para conocer los requisitos de despliegue y la disponibilidad.

Autoalojar Cloud es distinto de ejecutar un Bot individual en tu propio entorno. Un Bot autoalojado puede vincularse a Klex Cloud, pero la vinculación no es un requisito técnico. Consulta [Alojado o autoalojado](/es/cloud/hosted-vs-local) para conocer las opciones de alojamiento del Bot.
