[**Klex Cloud**](https://cloud.klex.bot) aloja Klex Bots y proporciona un panel para gestionarlos. También puede registrar un Bot autoalojado. Conecte las aplicaciones y servicios que necesita el Bot y configure sus cuentas y permisos en ellos.

<Panel title="Información útil">
Klex Cloud es completamente opcional. Puede ejecutar Klex Bots sin él y conectar sus propios servidores MCP.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Configurar un Klex Bot con Cloud

El asistente de configuración de Cloud permite crear un Bot alojado en Cloud o configurar un Bot autoalojado. Le guía en la configuración del Bot y sus modelos. Puede conectar aplicaciones y servicios después de la configuración.

Siga la [guía de inicio](/es/bot/quickstart) para comenzar.
