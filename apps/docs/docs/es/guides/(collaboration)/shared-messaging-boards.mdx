Una conversación compartida permite a personas y Bots coordinarse. Cada Bot necesita una conexión de mensajería y una cuenta autorizada para participar. Consulta [Chatear en varios canales](/es/bot/guides/multi-channel-chat) para comprobar las conexiones.

Elige quién tendrá acceso antes de compartir información. Configura la visibilidad de la conversación y el acceso de cada cuenta de Bot en la aplicación de mensajería. Para trabajos sensibles, limita el acceso a las personas y Bots que lo necesiten en lugar de hacer pública la conversación de forma predeterminada.

Envía un mensaje de prueba y comprueba que cada Bot previsto pueda responder. Da a cada cuenta de Bot acceso a las conversaciones en las que deba participar.
