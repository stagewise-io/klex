Klex recommande un bot hébergé dans le Cloud pour la plupart des utilisateurs. Vous pouvez aussi exécuter un bot sur votre propre ordinateur, avec ou sans enregistrement dans Klex Cloud. Vous avez besoin d'un accès à un fournisseur de modèles ; pour la configuration Cloud, vous avez également besoin d'un compte Klex Cloud. Les commandes d'auto-hébergement ci-dessous s'appliquent à Klex 0.30.1.

<a id="créer-votre-bot"></a>

## Créer un bot hébergé dans le Cloud

1. Connectez-vous à [Klex Cloud](https://cloud.klex.bot) et commencez la création d'un bot.
2. Choisissez l'hébergement dans le Cloud et suivez les étapes pour nommer le bot, définir son [âme](/bot/concepts/soul) et configurer ses fournisseurs et modèles.
3. Connectez les applications ou ordinateurs dont le bot a besoin. Consultez [Connexions](/bot/concepts/brain-and-computers) pour gérer son accès.

Envoyez un message au bot dans une application connectée pour vérifier s'il répond. Vous pouvez consulter son activité dans le tableau de bord Cloud.

<a id="installation"></a>

## Installer Klex pour l'auto-hébergement

Pour exécuter le bot sur votre ordinateur, installez Klex depuis un terminal :

<Tabs param="install">
  <Tab title="macOS">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Linux">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Windows">`irm https://klex.bot/install.ps1 | iex`</Tab>
  <Tab title="WSL">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
</Tabs>

### Configuration assistée par Cloud

Commencez la configuration d'un bot auto-hébergé dans Klex Cloud et suivez les instructions d'enregistrement. Le bot s'exécute sur votre ordinateur ; Cloud fournit une interface d'administration.

### Configuration autonome

Pour exécuter le bot sans l'enregistrer dans Cloud, lancez l'application interactive :

```sh
klex --no-cloud
```

1. Appuyez sur `a` pour créer un bot et saisissez son nom.
2. Dans **Settings → Providers & Endpoints**, configurez un fournisseur de modèles. Dans **Model Selection**, sélectionnez un modèle de chat valide.
3. Ouvrez **Settings → Soul** et créez une âme décrivant le caractère et le travail du bot.
4. Dans **Settings → MCP Servers**, connectez les serveurs dont le bot a besoin. Configurez les autorisations de ses comptes dans les applications connectées.

Pour recevoir des événements d'un canal externe, connectez un serveur MCP qui prend en charge les mises à jour de ressources correspondantes ou [l'extension de notifications push](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) de Klex.

## Créer un bot auto-hébergé sans le menu de sélection

Pour l'enregistrer dans Cloud, obtenez un jeton d'enregistrement auprès de Klex Cloud. Fournissez-le au processus sous le nom `KLEX_CLOUD_ENROLLMENT_TOKEN`, selon votre procédure approuvée de gestion des secrets. Exécutez ensuite :

```sh
klex --create-bot
```

Traitez le jeton comme un secret : ne l'inscrivez pas dans des scripts, des arguments de ligne de commande ou l'historique du terminal, et limitez l'accès à l'environnement du processus. Ajoutez `--headless` pour exécuter le bot sans interface de terminal.

Pour un bot autonome, indiquez plutôt un nom :

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Configurez son fournisseur, son modèle et ses connexions avant d'utiliser le bot. `--create-bot` ne peut pas être combiné avec `--data-dir` ou `KLEX_DATA_DIR` : ces options désignent un bot existant.

Si l'enregistrement dans Cloud échoue, le répertoire du nouveau bot est conservé et son chemin s'affiche. Fournissez le jeton dans `KLEX_CLOUD_ENROLLMENT_TOKEN` et réessayez avec `klex --data-dir PATH`. Remplacez `PATH` par le répertoire affiché au lieu de créer un autre bot.
