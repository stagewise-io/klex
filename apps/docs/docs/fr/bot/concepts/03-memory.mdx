La mémoire aide un bot Klex à s’appuyer sur ses apprentissages et à utiliser le contexte de son travail passé. Elle réunit des **skills**, dont des procédures apprises et préconfigurées, et des connaissances pertinentes issues de son activité.

Un bot peut utiliser des skills pour les tâches familières et retrouver du contexte passé lorsque c’est utile, par exemple la terminologie d’un projet ou une décision antérieure. Il peut demander un rappel en arrière-plan ; du contexte pertinent peut aussi apparaître pendant son travail. Consultez [Agent Skills](/bot/concepts/agent-skills) pour en savoir plus sur les procédures réutilisables.

<a id="where-chats-and-memory-are-stored"></a>

## Où sont stockées les conversations et la mémoire

Les conversations et la mémoire sont stockées dans le répertoire de données du bot :

- Pour un **bot hébergé dans le Cloud**, le répertoire se trouve dans l’environnement hébergé.
- Pour un **bot auto-hébergé**, il se trouve dans le dossier local utilisé pour ses données.

Toutes les données des bots hébergés dans le Cloud, y compris leur mémoire, sont chiffrées en transit et au repos.

## Consulter les conversations et les skills

Les administrateurs peuvent consulter les conversations et les skills via l’Admin API du bot. Le tableau de bord Klex Cloud sert d’interface et de proxy inverse pour l’Admin API de chaque bot. Pour en savoir plus sur le stockage, consultez le [répertoire de données](/bot/concepts/data-directory).
