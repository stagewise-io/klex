Vous pouvez répartir le travail indépendant entre plusieurs Bots. Par exemple, chargez un Bot d'examiner les tickets ouverts d'un projet et un autre de résumer les mises à jour d'un autre projet. Donnez à chaque Bot sa propre tâche, les connexions et autorisations nécessaires, ainsi qu'un endroit précis où communiquer son résultat.

<a id="coordinate-and-review"></a>

## Coordonner et vérifier

- Répartissez le travail afin que les Bots ne modifient pas la même ressource sans le savoir. Si les tâches se chevauchent, définissez qui est responsable de chaque modification et comment résoudre les conflits.
- Utilisez une conversation partagée pour les transmissions, si les comptes de messagerie des Bots y ont accès. Voir [Faire collaborer les Klex Bots](/fr/guides/bot-collaboration).
- Commencez par un petit test. Examinez les résultats, les tâches en double, les accès et l'utilisation du fournisseur de modèles avant d'augmenter la charge de travail.
