Vous pouvez exécuter un Bot auto-hébergé sans l’inscrire dans Klex Cloud.

<a id="install-klex"></a>

## Installer Klex

Installez Klex dans un terminal :

**macOS, Linux ou WSL :**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell) :**

```powershell
irm https://klex.bot/install.ps1 | iex
```

<a id="create-a-bot-interactively"></a>

## Créer un Bot de manière interactive

Démarrez l’application :

```sh
klex --no-cloud
```

1. Appuyez sur `a` pour créer un Bot et saisissez son nom.
2. Dans **Settings → Providers & Endpoints**, configurez un fournisseur de modèles. Dans **Model Selection**, sélectionnez un modèle de chat.
3. Ouvrez **Settings → Soul** et créez une Soul qui décrit le caractère et le travail du Bot.
4. Dans **Settings → MCP Servers**, connectez les serveurs dont le Bot a besoin. Configurez les autorisations de son compte dans les applications connectées.

Pour recevoir des événements d’un canal externe, connectez un serveur qui prend en charge les MCP Events concernés, les ressources en direct ou l’[extension de notifications push](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) de Klex. Les MCP Events nécessitent une watch et les mises à jour des ressources en direct nécessitent que la ressource soit ouverte. Certains serveurs nécessitent aussi une configuration dans le service connecté.

<a id="create-a-bot-without-the-picker"></a>

## Créer un Bot sans le menu de sélection

Pour créer un Bot autonome sans le menu de sélection interactif, indiquez un nom :

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Ajoutez `--headless` pour l’exécuter sans interface de terminal. Configurez un fournisseur, un modèle de chat et une Soul avant que le Bot puisse travailler. Pour configurer un nouveau Bot de manière interactive, omettez `--headless` et utilisez les paramètres ci-dessus. Pour une configuration headless, utilisez l’Admin API ; consultez ses [conditions d’accès local et limites de sécurité](/bot/guides/observability#access-the-local-admin-api). La création ne peut pas être combinée avec `--data-dir` ou `KLEX_DATA_DIR` : ces options sélectionnent un Bot existant. Pour arrêter un Bot headless, consultez [Contrôler votre Klex Bot](/bot/guides/control-and-limits#stop-a-headless-bot).
