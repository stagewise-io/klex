> **Puis-je exécuter un Bot Klex sans Klex Cloud ?**

Oui. Un Bot Klex auto-hébergé peut fonctionner sans inscription au Cloud. Klex recommande un Bot hébergé par Cloud à la plupart des utilisateurs et recommande d’inscrire un Bot auto-hébergé à Klex Cloud pour une gestion plus complète.

<a id="choose-how-to-host-the-bot"></a>

## Choisir comment héberger le Bot

<a id="klex-cloud-hosted-bot"></a>

### Bot hébergé par Klex Cloud

Klex exécute le Bot dans son environnement hébergé. Les conversations et la mémoire du Bot sont stockées dans son répertoire de données dans cet environnement. Le tableau de bord Cloud permet de consulter l’activité et de gérer les MCP connectés.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Bot auto-hébergé inscrit à Klex Cloud

Vous exécutez le Bot dans un environnement que vous gérez et pouvez l’inscrire à Klex Cloud. Vous contrôlez ainsi davantage l’environnement du Bot tout en conservant la gestion Cloud. Ses conversations et sa mémoire restent dans son répertoire de données local. Le tableau de bord Cloud fournit une interface et un proxy inverse vers l’API Admin du Bot.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Bot auto-hébergé sans inscription au Cloud

L’inscription au Cloud n’est pas une exigence technique pour un Bot auto-hébergé. Klex la recommande car l’expérience autonome est moins complète.

<a id="self-hosted-cloud"></a>

### Cloud auto-hébergé

L’auto-hébergement du service Klex Cloud est réservé aux clients Enterprise.

<a id="manage-access-and-stop-a-bot"></a>

## Gérer les accès et arrêter un Bot

Dans le tableau de bord Cloud, vous pouvez consulter l’activité du Bot et connecter ou déconnecter des MCP. Pour les autres applications et comptes utilisés par le Bot, configurez les autorisations dans ces applications ou comptes. Pour arrêter un Bot auto-hébergé, fermez son application. Pour arrêter un Bot hébergé par Cloud, utilisez **Stop** dans le tableau de bord Cloud.
