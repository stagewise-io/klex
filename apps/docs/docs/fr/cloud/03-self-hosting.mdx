Klex Cloud auto-hébergé est disponible uniquement pour les clients Enterprise. Contactez Klex pour connaître les conditions de déploiement et la disponibilité.

Auto-héberger le Cloud est différent de l’exécution d’un Bot individuel dans votre propre environnement. Un Bot auto-hébergé peut être inscrit à Klex Cloud, mais cette inscription n’est pas une exigence technique. Consultez [Hébergé ou auto-hébergé](/fr/cloud/hosted-vs-local) pour les options d’hébergement des Bots.
