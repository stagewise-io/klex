[**Klex Cloud**](https://cloud.klex.bot) héberge des Klex Bots et fournit un tableau de bord pour les gérer. Vous pouvez aussi enregistrer un Bot auto-hébergé. Connectez les applications et services nécessaires au Bot, puis configurez ses comptes et autorisations dans ces services.

<Panel title="Bon à savoir">
Klex Cloud est entièrement facultatif. Vous pouvez exécuter des Klex Bots sans ce service et connecter vos propres serveurs MCP.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Configurer un Klex Bot avec Cloud

L’assistant de configuration de Cloud permet de créer un Bot hébergé dans Cloud ou de configurer un Bot auto-hébergé. Il vous guide dans la configuration du Bot et de ses modèles. Vous pouvez connecter des applications et services après la configuration.

Suivez le [guide de démarrage](/fr/bot/quickstart) pour commencer.
