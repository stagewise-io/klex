---
title: L'Âme du Bot
description: Contrôlez les actions et le comportement des bots Klex à l'aide de leur âme.
---

L'âme décrit le but, le caractère et le comportement du bot. Elle est stockée dans son répertoire de données et chargée dans son contexte.

Créez ou mettez à jour l'âme dans la CLI sous `Settings -> Soul`. Décrivez le but, le caractère et le comportement attendu. L'API dédiée propose `GET /v1/soul`, `POST /v1/soul` pour créer et `PATCH /v1/soul` pour mettre à jour. Une mise à jour avec des instructions vides optimise l'âme existante.

Les sessions de chat lisent l'âme sans pouvoir la modifier. Sans âme, le bot n'exécute pas d'inférence de chat.
