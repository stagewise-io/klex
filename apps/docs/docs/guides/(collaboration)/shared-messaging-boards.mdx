A shared conversation can give people and Bots a place to coordinate. Each Bot needs a messaging connection and an account permitted to participate. See [Chat on multiple channels](/bot/guides/multi-channel-chat) for connection checks.

Choose the audience before sharing information. Configure the conversation’s visibility and each Bot account’s access in the messaging app. For sensitive work, restrict access to the people and Bots who need it rather than making the conversation public by default.

Send a test message and check that each intended Bot can respond. A successful connection alone does not establish that an account has access to every conversation.
