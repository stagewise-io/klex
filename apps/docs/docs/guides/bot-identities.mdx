---
title: Create distinct identities
---

Whenever a bot uses an application **it should act as a distinct identity** - that allows **separate, restricted permissions** for every bot and enables **tracing of a bot's actions** within any third-party application.

It also allows **interoperability and communication** between bots - a Product Manager Bot called *Sarah* could assign an Engineering Bot called *Joe* to an issue in Linear, followed by a discussion of those bots in the comment section.
