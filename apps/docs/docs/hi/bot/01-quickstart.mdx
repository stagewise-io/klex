Klex अधिकांश उपयोगकर्ताओं के लिए क्लाउड-होस्टेड बॉट की सलाह देता है। आप अपने कंप्यूटर पर बॉट चला सकते हैं और चुन सकते हैं कि उसे Klex Cloud में नामांकित करना है या नहीं। आपको मॉडल प्रदाता की पहुँच चाहिए; Cloud सेटअप के लिए Klex Cloud खाता भी चाहिए।

<a id="अपना-बॉट-बनाना"></a>

## क्लाउड-होस्टेड बॉट बनाएँ

1. [Klex Cloud](https://cloud.klex.bot) में साइन इन करके बॉट बनाना शुरू करें।
2. क्लाउड होस्टिंग चुनें और निर्देशों के अनुसार बॉट का नाम, [Soul](/bot/concepts/soul), प्रदाता और मॉडल सेट करें।
3. बॉट के लिए आवश्यक ऐप और कंप्यूटर कनेक्ट करें। पहुँच प्रबंधन के लिए [कनेक्शन](/bot/concepts/brain-and-computers) देखें।

कनेक्ट किए गए ऐप में बॉट को संदेश भेजकर जाँचें कि वह जवाब देता है। Cloud डैशबोर्ड में गतिविधि देख सकते हैं।

<a id="इंस्टॉलेशन"></a>

## सेल्फ़ होस्टिंग के लिए Klex इंस्टॉल करें

अपने कंप्यूटर पर बॉट चलाने के लिए टर्मिनल में Klex इंस्टॉल करें।

### Cloud के साथ सेटअप

Klex Cloud में सेल्फ़-होस्टेड बॉट का सेटअप शुरू करें और नामांकन निर्देशों का पालन करें। बॉट आपके कंप्यूटर पर चलता है और Cloud प्रबंधन इंटरफ़ेस देता है।

### स्टैंडअलोन सेटअप

Cloud में नामांकन के बिना बॉट चलाने के लिए इंटरैक्टिव ऐप शुरू करें।

```sh
klex --no-cloud
```

1. बॉट बनाने के लिए `a` दबाएँ और उसका नाम दर्ज करें।
2. **Settings → Providers & Endpoints** में मॉडल प्रदाता सेट करें। **Model Selection** में एक मान्य चैट मॉडल चुनें।
3. **Settings → Soul** खोलें और बॉट के व्यक्तित्व और काम का वर्णन करने वाला Soul बनाएँ।
4. **Settings → MCP Servers** में आवश्यक सर्वर कनेक्ट करें। जुड़े ऐप में बॉट के खाते की अनुमतियाँ सेट करें।

बाहरी चैनल से इवेंट प्राप्त करने के लिए ऐसा MCP सर्वर कनेक्ट करें जो संबंधित रिसोर्स अपडेट या Klex के [पुश नोटिफ़िकेशन एक्सटेंशन](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) का समर्थन करता हो।
