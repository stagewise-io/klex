Klex Bot MCP (मॉडल कॉन्टेक्स्ट प्रोटोकॉल) से जुड़े बाहरी वातावरणों में काम करता है। MCP सर्वर पूरे कंप्यूटर या GitHub और Google Workspace जैसे ऐप को उपलब्ध करा सकता है। कंप्यूटर भी MCP से ही जुड़ते हैं।

Bot का अपना वातावरण उसे चालू रखता है और उसकी मेमोरी संभालता है। जुड़े हुए कंप्यूटर और ऐप्स वे वातावरण हैं जहाँ वह काम करता है।

<a id="choose-what-to-connect"></a>

## चुनें कि क्या कनेक्ट करना है

- **कंप्यूटर** एक जुड़ा हुआ वातावरण देते हैं जहाँ Bot काम कर सकता है।
- **ऐप्स** MCP सर्वर के ज़रिए ऐप का वातावरण उपलब्ध कराते हैं।

Klex कई बिल्ट-इन MCP सर्वर देता है। आप अन्य MCP सर्वर भी कनेक्ट कर सकते हैं। कौन से वातावरण कनेक्ट करने हैं, यह इस बात पर निर्भर करता है कि आप Bot से क्या काम करवाना चाहते हैं।

<a id="manage-a-bots-access"></a>

## Bot का एक्सेस प्रबंधित करें

Bot को उसके काम के लिए ज़रूरी ऐप्स और कंप्यूटर से जोड़ें। ज़्यादातर MCP के लिए, Bot अपने खाते या पहचान के ज़रिए काम करता है और उसके लिए तय की गई अनुमतियों का इस्तेमाल करता है।

<Tabs syncKey="hosting" hash={false}>
<Tab title="Cloud-होस्टेड">

Klex Cloud में अपना Bot खोलें। उसके ऐप कनेक्शन प्रबंधित करने के लिए **Connectors** और जुड़े हुए कंप्यूटर प्रबंधित करने के लिए **Computers** का इस्तेमाल करें। आप उसकी **Activity** भी देख सकते हैं।

</Tab>
<Tab title="सेल्फ-होस्टेड">

Klex ऐप में सर्वर कनेक्शन प्रबंधित करने के लिए **Settings → MCP Servers** का इस्तेमाल करें। चरणों के लिए [MCP और Klex Bots](/bot/concepts/mcp#add-a-remote-server-in-the-self-hosted-app) देखें। स्थानीय डायग्नोस्टिक्स देखने के लिए **Settings → Logs** का इस्तेमाल करें।

</Tab>
</Tabs>

Bot के खातों और जुड़े हुए ऐप्स की अनुमतियाँ सीधे उन खातों और ऐप्स में सेट करें। सर्वर कनेक्ट करना और किसी खाते को एक्सेस देना अलग फैसले हैं। Bot किन चीज़ों तक पहुँच सकता है और क्या कर सकता है, यह तय करते समय दोनों जाँचें।

पूरी जानकारी के लिए [Klex Bots कैसे काम करते हैं](/bot/concepts/how-bots-work) देखें। चैट और मेमोरी कहाँ रखी जाती हैं, इसके लिए [डेटा डायरेक्टरी](/bot/concepts/data-directory) देखें।
