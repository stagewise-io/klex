## Soul बनाना और अपडेट करना

बॉट की Admin API से निर्देशों के आधार पर Soul बनाएँ या अपडेट करें। नया Soul बनाने के लिए `POST /v1/soul`, मौजूदा Soul अपडेट करने के लिए `PATCH /v1/soul`, और उसे पढ़ने के लिए `GET /v1/soul` इस्तेमाल करें। पहुँच और सुरक्षा की जानकारी के लिए [लोकल Admin API तक पहुँच](/bot/guides/observability#access-the-local-admin-api) देखें।

Soul बनाने में कॉन्फ़िगर किए गए चैट मॉडल इस्तेमाल होते हैं और सफल होने पर परिणाम सहेजा जाता है। उदाहरण के लिए, निर्देशों में बॉट का काम, पसंदीदा लहजा और निर्णय लेने का तरीका बता सकते हैं। तैयार Soul की जाँच करें और ज़रूरत हो तो उसे अपडेट करें। बॉट को नया काम भेजने से पहले Soul सहेजें।

## संग्रह और पहुँच

Soul बॉट की [डेटा डायरेक्टरी](/bot/concepts/data-directory) में सहेजा जाता है। बॉट की Admin API Soul पढ़ सकती है और व्यवस्थापक के निर्देशों से नया या अपडेट किया गया Soul बना सकती है। सामान्य सत्र में Soul लिखने का कोई टूल नहीं है।

## अगर बॉट का Soul नहीं है

सामान्य काम करने के लिए बॉट को खाली न होने वाला Soul चाहिए। इसके बिना वह नया काम छोड़ देता है और सत्र के इतिहास में नई जोड़ी गई सामग्री हटा देता है। छोड़ा गया काम कतार में नहीं रखा जाता। नया इनपुट भेजने से पहले Soul बनाएँ।
