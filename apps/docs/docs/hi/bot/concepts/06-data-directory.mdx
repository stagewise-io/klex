हर Klex बॉट अपनी बातचीत और मेमोरी अपनी डेटा डायरेक्टरी में सहेजता है। क्लाउड-होस्टेड बॉट के लिए यह डायरेक्टरी क्लाउड वातावरण में होती है। सेल्फ़-होस्टेड बॉट के लिए यह उसका डेटा रखने वाले स्थानीय फ़ोल्डर में होती है।

व्यवस्थापक बॉट की Admin API से बातचीत और मेमोरी तक पहुँच सकते हैं। Klex Cloud कंसोल प्रत्येक बॉट की Admin API के लिए रिवर्स प्रॉक्सी और फ़्रंटएंड के रूप में काम करता है।

## सेल्फ़-होस्टेड बॉट खोजें

सेल्फ़-होस्टेड Klex 0.30.1 ऐप को इंटरैक्टिव रूप से शुरू करने पर डिफ़ॉल्ट रूप से `~/.klex/agents` में बॉट खोजे जाते हैं। `KLEX_HOME` सेट होने पर उस पथ का `agents` फ़ोल्डर इस्तेमाल होता है। `--data-dir` से डायरेक्टरी सीधे चुन सकते हैं; यह विकल्प `KLEX_DATA_DIR` से प्राथमिकता पाता है।

उदाहरण के लिए, ज्ञात डेटा डायरेक्टरी वाला बॉट खोलने के लिए:

```sh
klex --data-dir /path/to/bot
```

उदाहरण के पथ को बॉट की वास्तविक डायरेक्टरी से बदलें। टर्मिनल स्क्रीन के बिना बॉट बनाने और सेट करने के लिए [त्वरित शुरुआत](/bot/quickstart) देखें।

## डेटा सुरक्षित रखें

डायरेक्टरी में सेटिंग और क्रेडेंशियल जैसी संवेदनशील जानकारी हो सकती है। ऑपरेटिंग सिस्टम की अनुमतियों से पहुँच सीमित करें और बनाई गई प्रतियों की भी सुरक्षा करें। Unix फ़ाइल मोड वाले सिस्टम पर Klex 0.30.1 डायरेक्टरी बनाते समय केवल स्वामी की पहुँच वाली अनुमतियों का अनुरोध करता है; वह मौजूदा डायरेक्टरी की अनुमतियाँ नहीं बदलता। Windows एक्सेस कंट्रोल लिस्ट का उपयोग करता है।

डेटा हटाने या स्थानांतरित करने से पहले अपनी बैकअप और पुनर्स्थापन प्रक्रिया जाँचें। यह पेज समर्थित माइग्रेशन या पुनर्स्थापन प्रक्रिया, डेटा रखने की अवधि या तीसरे पक्ष के डेटा प्रबंधन का वर्णन नहीं करता।
