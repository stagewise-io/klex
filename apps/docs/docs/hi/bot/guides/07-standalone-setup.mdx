आप Klex Cloud में नामांकन के बिना सेल्फ़-होस्टेड बॉट चला सकते हैं।

## Klex इंस्टॉल करें

टर्मिनल में Klex इंस्टॉल करें:

**macOS, Linux या WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

## बॉट को इंटरैक्टिव तरीके से बनाएँ

ऐप शुरू करें:

```sh
klex --no-cloud
```

1. बॉट बनाने के लिए `a` दबाएँ और उसका नाम दर्ज करें।
2. **Settings → Providers & Endpoints** में मॉडल प्रदाता कॉन्फ़िगर करें। **Model Selection** में चैट मॉडल चुनें।
3. **Settings → Soul** खोलें और बॉट के व्यक्तित्व और काम का वर्णन करने वाला Soul बनाएँ।
4. **Settings → MCP Servers** में बॉट के लिए आवश्यक सर्वर कनेक्ट करें। कनेक्ट किए गए ऐप में उसके खाते की अनुमतियाँ सेट करें।

बाहरी चैनल से इवेंट पाने के लिए ऐसा सर्वर कनेक्ट करें जो संबंधित MCP Events, लाइव रिसोर्स या Klex के [पुश-नोटिफ़िकेशन एक्सटेंशन](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) का समर्थन करता हो। MCP Events के लिए watch ज़रूरी है और लाइव रिसोर्स के अपडेट पाने के लिए रिसोर्स खुला होना चाहिए। कुछ सर्वरों के लिए कनेक्ट की गई सेवा में अलग से सेटअप भी ज़रूरी होता है।

## चयन मेनू के बिना बॉट बनाएँ

इंटरैक्टिव चयन मेनू के बिना स्टैंडअलोन बॉट बनाने के लिए नाम दें:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

टर्मिनल UI के बिना चलाने के लिए `--headless` जोड़ें। बॉट के काम करने से पहले प्रदाता, चैट मॉडल और Soul कॉन्फ़िगर करें। नए बॉट को इंटरैक्टिव तरीके से कॉन्फ़िगर करने के लिए `--headless` हटाएँ और ऊपर दी गई सेटिंग इस्तेमाल करें। हेडलेस कॉन्फ़िगरेशन के लिए Admin API इस्तेमाल करें; इसकी [स्थानीय पहुँच और सुरक्षा सीमाएँ](/bot/guides/observability#access-the-local-admin-api) देखें। बॉट बनाने के साथ `--data-dir` या `KLEX_DATA_DIR` इस्तेमाल नहीं कर सकते; ये मौजूदा बॉट चुनते हैं। हेडलेस बॉट रोकने के लिए [अपने Klex बॉट को नियंत्रित करें](/bot/guides/control-and-limits#stop-a-headless-bot) देखें।
