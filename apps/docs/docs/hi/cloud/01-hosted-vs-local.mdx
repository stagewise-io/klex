> **क्या मैं Klex Cloud के बिना Klex Bot चला सकता हूँ?**

हाँ। सेल्फ़-होस्टेड Klex Bot Cloud में नामांकन के बिना चल सकता है। Klex अधिकांश उपयोगकर्ताओं के लिए Cloud-होस्टेड Bot की सिफ़ारिश करता है और अधिक पूर्ण प्रबंधन अनुभव के लिए सेल्फ़-होस्टेड Bot को Klex Cloud में नामांकित करने की सिफ़ारिश करता है।

<a id="choose-how-to-host-the-bot"></a>

## Bot होस्ट करने का तरीका चुनें

<a id="klex-cloud-hosted-bot"></a>

### Klex Cloud-होस्टेड Bot

Klex अपने होस्टेड परिवेश में Bot चलाता है। Bot की चैट और मेमोरी उस परिवेश में उसकी डेटा डायरेक्टरी में रखी जाती हैं। आप गतिविधि देखने और कनेक्ट किए गए MCP प्रबंधित करने के लिए Cloud डैशबोर्ड इस्तेमाल कर सकते हैं।

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Klex Cloud में नामांकित सेल्फ़-होस्टेड Bot

आप अपने प्रबंधित परिवेश में Bot चलाते हैं और उसे Klex Cloud में नामांकित कर सकते हैं। इससे Cloud प्रबंधन बनाए रखते हुए Bot कहाँ चलता है, इस पर अधिक नियंत्रण मिलता है। Bot की चैट और मेमोरी उसकी स्थानीय डेटा डायरेक्टरी में रहती हैं। Cloud डैशबोर्ड Bot की Admin API के लिए फ़्रंटएंड और रिवर्स प्रॉक्सी देता है।

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Cloud नामांकन के बिना सेल्फ़-होस्टेड Bot

सेल्फ़-होस्टेड Bot के लिए Cloud नामांकन तकनीकी आवश्यकता नहीं है। स्वतंत्र अनुभव कम पूर्ण होने के कारण Klex नामांकन की सिफ़ारिश करता है।

<a id="self-hosted-cloud"></a>

### सेल्फ़-होस्टेड Cloud

Klex Cloud सेवा की सेल्फ़-होस्टिंग केवल Enterprise ग्राहकों के लिए उपलब्ध है।

<a id="manage-access-and-stop-a-bot"></a>

## पहुँच प्रबंधित करें और Bot रोकें

Cloud डैशबोर्ड में आप Bot की गतिविधि देख सकते हैं और MCP कनेक्ट या डिस्कनेक्ट कर सकते हैं। Bot द्वारा उपयोग किए जाने वाले अन्य ऐप्स और खातों की अनुमतियाँ उनमें सेट करें। सेल्फ़-होस्टेड Bot रोकने के लिए उसका ऐप बंद करें। Cloud-होस्टेड Bot रोकने के लिए Cloud डैशबोर्ड में **Stop** इस्तेमाल करें।
