सेल्फ़-होस्ट किया गया Klex Cloud केवल Enterprise ग्राहकों के लिए उपलब्ध है। डिप्लॉयमेंट की ज़रूरतों और उपलब्धता के लिए Klex से संपर्क करें।

Cloud को सेल्फ़-होस्ट करना अपने परिवेश में एक अलग Bot चलाने से अलग है। सेल्फ़-होस्ट किए गए Bot को Klex Cloud में नामांकित किया जा सकता है, लेकिन तकनीकी रूप से नामांकन ज़रूरी नहीं है। Bot की होस्टिंग के विकल्पों के लिए [होस्टेड और सेल्फ़-होस्टेड](/hi/cloud/hosted-vs-local) देखें।
