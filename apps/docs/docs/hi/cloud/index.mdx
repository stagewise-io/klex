[**Klex Cloud**](https://cloud.klex.bot), Klex Bots को होस्ट करता है और उन्हें प्रबंधित करने के लिए डैशबोर्ड देता है। आप अपना स्वयं-होस्ट किया हुआ Bot भी पंजीकृत कर सकते हैं। Bot के लिए ज़रूरी ऐप और सेवाएँ जोड़ें और उनमें उसके खाते और अनुमतियाँ कॉन्फ़िगर करें।

<Panel title="जानना उपयोगी है">
Klex Cloud पूरी तरह वैकल्पिक है। आप इसके बिना Klex Bots चला सकते हैं और अपने MCP सर्वर जोड़ सकते हैं।
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Cloud से Klex Bot सेट करें

Cloud सेटअप विज़ार्ड से आप Cloud पर होस्ट किया गया Bot बना सकते हैं या स्वयं-होस्ट किया हुआ Bot सेट कर सकते हैं। यह Bot और उसके मॉडल कॉन्फ़िगर करने में मार्गदर्शन करता है। सेटअप के बाद आप ऐप और सेवाएँ जोड़ सकते हैं।

शुरू करने के लिए [क्विकस्टार्ट](/hi/bot/quickstart) देखें।
