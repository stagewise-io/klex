一緒に働く Klex ボットを作成しましょう。Klex はほとんどのユーザーに Cloud ホスティングを推奨していますが、自分のコンピューターでボットを実行することもできます。

## Cloud でのセットアップ

1. [Klex Cloud](https://cloud.klex.bot) にログインし、**New bot** を選択します。
2. ボットに仕事を与えるか、提案された仕事を選び、名前と外見をカスタマイズします。
3. **Create bot in cloud** を選択します。
4. 性格の特徴を確認し、**Models & Computer** に進みます。
5. AI プロバイダーを接続し、ボットが使用するモデルを選ぶか、別のボットからモデル設定をインポートします。ボットが接続されたらセットアップを完了します。
6. ボットのチャットを開いて始めます。

ボットの仕事に必要なアプリやコンピューターを接続できます。対応する MCP サーバーは、ボットが仕事を始めるきっかけとなるメッセージやアプリのイベントも届けられます。詳しくは [MCP と Klex ボット](/bot/concepts/mcp)を参照してください。

## セルフホストのセットアップ

1. [Klex Cloud](https://cloud.klex.bot) にログインし、**New bot** を選択して、ボットの仕事と外見を選びます。
2. **Or run it on your own computer**、次に **Set up on your computer** を選択します。Klex Cloud が表示するコマンドをすべてコピーし、ボットを実行するコンピューターのターミナルに貼り付けて実行します。
3. セットアップの案内に従って、ボットの性格とモデルを設定します。

ボットが働けるように、コンピューターで実行したままにしてください。再起動するには、ターミナルで次のコマンドを実行し、ボットを選択します。

```sh
klex
```

### Cloud を使わずに実行する

Cloud への登録は任意です。Klex アプリで直接ボットを設定するには、[スタンドアロン設定ガイド](/bot/guides/standalone-setup)に従ってください。このガイドでは、[選択メニューを使わずにボットを作成する方法](/bot/guides/standalone-setup#create-a-bot-without-the-picker)も説明しています。
