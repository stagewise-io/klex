Klex ボットは、活動中のセッションや[記憶](/bot/concepts/memory)を管理する独自の環境で動作します。ボットは [MCP](/bot/concepts/mcp) で接続された外部のコンピューターやアプリで作業します。

<a id="技術的基盤"></a>
<a id="メインセッション"></a>

## 通常のセッション

Klex 0.30.1 では、通常のセッションから接続済みの MCP サーバーにアクセスできます。ボットはこのセッションで受信イベントを処理し、接続先で作業できます。実行できる操作は、接続先とその権限によって異なります。

<a id="ユーティリティセッション"></a>

## 独立したタスク

ボットは内部タスクを独立したセッションで処理できます。例えば、複雑な問題について相談を依頼し、その結果を作業の参考にできます。複数の依頼が同時に処理されることや、決まった時間内に完了することは前提にしないでください。

<a id="ゴッドセッション"></a>

## God Messages

[God Messages](/bot/concepts/god-messages) は、通常の会話とは別のセッションで処理される管理指示です。例えば、[Soul（魂）](/bot/concepts/soul)の変更を依頼できます。Klex 0.30.1 では、管理者は Soul の設定画面または Admin API からも Soul を作成・更新できます。

ボットの環境や接続先については、[Klex ボットの仕組み](/bot/concepts/how-bots-work)を参照してください。
