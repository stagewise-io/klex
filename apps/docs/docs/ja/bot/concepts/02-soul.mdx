---
title: ボットの魂
description: 魂を使って Klex ボットの行動と振る舞いを制御します。
---

魂はボットの目的、性格、振る舞いを簡潔に記述します。データディレクトリに保存され、コンテキストに読み込まれます。

CLI の `Settings -> Soul` で魂を作成または更新し、目的、性格、期待する振る舞いを指定します。専用 API は `GET /v1/soul`、作成用の `POST /v1/soul`、更新用の `PATCH /v1/soul` を提供します。更新時に指示を空にすると、既存の魂を最適化します。

チャットセッションは魂を読み取るだけで、編集できません。魂がない場合、ボットはチャット推論を実行しません。
