Klex ボットのメモリーは**スキルと学習内容**を扱い、ボットの過去の活動から関連するコンテキストを取得できます。メモリーは、ボットの動作を維持するアクティブなセッションとともに、ボット自身の環境で管理されます。

ボットはバックグラウンドで記憶の呼び出しを要求でき、要求しなくても関連するコンテキストが提示されることがあります。呼び出した情報は不完全または誤っていることがあるため、重要な内容は確認してください。コンテキストのヒントは検索の手掛かりになりますが、アクセス制御ではありません。

<a id="where-chats-and-memory-are-stored"></a>

## チャットとメモリーの保存場所

チャットとメモリーは、ボットのデータディレクトリに保存されます。

- **クラウドホストのボット**の場合、ディレクトリはホストされた環境内にあります。
- **セルフホストのボット**の場合、ボットのデータに使用するローカルフォルダー内にあります。

クラウドホストのボットのデータは、メモリーを含め、転送中も保存時もすべて暗号化されます。

<a id="how-administrators-access-them"></a>

## 管理者のアクセス方法

管理者は、ボットの Admin API を通じてチャットとメモリーにアクセスできます。Klex Cloud ダッシュボードは、各ボットの Admin API のフロントエンドおよびリバースプロキシとして機能します。保存場所について詳しくは、[データディレクトリ](/bot/concepts/data-directory)を参照してください。
