メモリーは、Klex ボットが学んだことを生かし、過去の仕事のコンテキストを活用するのに役立ちます。学習した手順や事前に設定された手順を含む**スキル**と、ボットの活動から得た関連知識を組み合わせます。

ボットはスキルを使って慣れたタスクを処理し、プロジェクトの用語や過去の決定など、役立つコンテキストを呼び出せます。バックグラウンドで記憶の呼び出しを要求でき、作業中に関連するコンテキストが提示されることもあります。再利用できる手順については、[Agent Skills](/bot/concepts/agent-skills)を参照してください。

<a id="where-chats-and-memory-are-stored"></a>

## チャットとメモリーの保存場所

チャットとメモリーは、ボットのデータディレクトリに保存されます。

- **クラウドホストのボット**の場合、ディレクトリはホストされた環境内にあります。
- **セルフホストのボット**の場合、ボットのデータに使用するローカルフォルダー内にあります。

クラウドホストのボットのデータは、メモリーを含め、転送中も保存時もすべて暗号化されます。

## チャットとスキルの確認

管理者はボットの Admin API を通じてチャットとスキルを確認できます。Klex Cloud ダッシュボードは、各ボットの Admin API のフロントエンドおよびリバースプロキシとして機能します。保存場所について詳しくは、[データディレクトリ](/bot/concepts/data-directory)を参照してください。
