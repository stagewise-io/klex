各 Klex ボットは、会話と記憶を独自のデータディレクトリに保存します。クラウドホストのボットでは、このディレクトリはクラウド環境にあります。セルフホストのボットでは、そのデータを保存するローカルフォルダーにあります。

管理者は、ボットの Admin API を通じて会話と記憶にアクセスできます。Klex Cloud コンソールは、各ボットの Admin API のリバースプロキシとフロントエンドとして機能します。

## セルフホストのボットを探す

セルフホストの Klex 0.30.1 アプリの対話型起動では、デフォルトで `~/.klex/agents` 内のボットを探します。`KLEX_HOME` が設定されている場合は、そのパス内の `agents` フォルダーを使用します。`--data-dir` でディレクトリを直接指定することもできます。このオプションは `KLEX_DATA_DIR` より優先されます。

例えば、データディレクトリが分かっているボットを開くには、次を実行します。

```sh
klex --data-dir /path/to/bot
```

例のパスを実際のディレクトリに置き換えてください。ターミナル画面なしでボットを作成・設定する方法は、[クイックスタート](/bot/quickstart)を参照してください。

## データを保護する

ディレクトリには、設定や認証情報などの機密情報が含まれる場合があります。OS の権限でアクセスを制限し、作成したコピーも保護してください。Unix ファイルモードを使用するシステムでは、Klex 0.30.1 はディレクトリの作成時に所有者のみがアクセスできる権限を要求します。既存のディレクトリの権限は変更しません。Windows はアクセス制御リストを使用します。

データを削除・移動する前に、バックアップと復元の手順を確認してください。このページでは、サポートされる移行・復元手順、保存期間、第三者によるデータ処理は説明していません。
