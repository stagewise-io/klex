Klex ボットは、設定されたプロバイダーのモデルを使用します。Klex は OpenAI、Anthropic、Google Gemini、ローカルの Ollama、互換性のあるカスタムエンドポイントなど、さまざまな種類のプロバイダーをサポートしています。利用できるモデルは、プロバイダーとアカウントによって異なります。

プロバイダーは Klex が接続するサービスまたはエンドポイントで、モデルはそのプロバイダーを通じて利用できる個々のモデルです。プロバイダーを設定しても、すべてのタスクのモデルが自動的に選択されるわけではありません。

<a id="configure-models"></a>

## モデルの設定

<Tabs syncKey="hosting" hash={false}>
<Tab title="クラウドホスト">

1. Klex Cloud でボットを開き、**Models** を選択します。ボットが接続されている必要があり、モデルの変更には管理者アクセスが必要です。
2. プロバイダーが接続されていない場合は、**Add a provider** を選択し、プロバイダーを選んで設定を完了します。必要な設定とサインイン手順はプロバイダーによって異なります。
3. モデルのプリセットを選ぶか、モデル表で用途ごとにモデルを選択します。チャット、メモリー、コンパクション用のモデルを含め、選択内容を確認します。

</Tab>
<Tab title="セルフホスト">

セルフホストの Klex アプリで操作します。

1. **Settings → Providers & Endpoints** を開き、`a` を押してプロバイダーの種類を選択します。必要な設定を入力し、サインイン手順を完了します。
2. **Settings → Model Selection** を開き、**Chat** を選択して、設定済みのプロバイダーからモデルを追加します。通常の会話と Soul の生成にはチャットモデルが必要です。
3. 他の用途も確認し、必要に応じて互換性のあるモデルを追加します。この画面では、メモリー、相談、画像入力、音声入力、音声用のモデルを選択できます。

</Tab>
</Tabs>

モデルを自動的に検出するプロバイダーもあれば、モデル情報を手動で追加する必要があるプロバイダーもあります。利用できるモデルや対応する機能は、プロバイダーとモデルによって異なります。

<a id="choosing-models-for-different-tasks"></a>

## タスクに応じたモデルの選択

同じモデルを複数の用途に使うことも、用途ごとに異なるモデルを選ぶこともできます。必要な入力にモデルが対応しているか、プロバイダーの費用と応答時間も考慮してください。利用前にプロバイダーの利用条件と料金を確認してください。

チャット用のモデルは優先順位を付けて複数設定できます。モデルでエラーが発生した場合、Klex は設定済みの別のチャットモデルに切り替えることができます。モデルの操作画面で順序を確認してください。

<a id="instincts-and-model-usage"></a>

## Instincts とモデルの使用量

Klex は生成ステップの前にコンテキストを分類するため、**Instincts** モデルを使用できます。Instincts モデルが設定されていない場合は、利用可能な Chat モデルを分類に使用します。これらの呼び出しにより、モデルの使用量と費用が増えることがあります。料金を確認し、使用量を監視してください。

<Tabs syncKey="hosting" hash={false}>
<Tab title="クラウドホスト">

ボットの **Models** セクションを開き、モデル表で **Quick Decisions** 用のモデルを選択します。これが Instincts モデルです。

</Tab>
<Tab title="セルフホスト">

**Settings → Model Selection** で Instincts モデルを選択します。

</Tab>
</Tabs>

dynamic effort はデフォルトでシャドーモードで動作します。メインモデルの設定を変更せずに、推奨される推論の effort を評価します。シャドーモードでの分類でもモデルが使用され、費用が発生することがあります。
