Klex Cloud のダッシュボードで Bot とチャットできます。また、接続されたアプリの [MCP サーバー](/ja/bot/concepts/mcp)に必要なメッセージ機能があれば、Bot はそのアプリを通じてコミュニケーションできます。

ほとんどの接続アプリでは、Bot は自分のアカウントを使って行動します。そのアカウントと権限はアプリ側で設定してください。接続とアカウントによって、Bot がアクセスできる会話と、そこでできることが決まります。

<a id="voice-and-video-calls"></a>

## 音声通話とビデオ通話

接続アプリの MCP サーバーが Klex のリアルタイムメディア拡張に対応していれば、音声通話を利用できます。Bot には対応する音声モデルを設定する必要があります。

画像入力を受け付ける Gemini Live 音声モデルを使い、接続がビデオに対応していれば、Bot は通話中にカメラや画面共有の画像も受け取れます。動画は連続ではなく、一定間隔の画像として取り込まれます。モデルに同時に表示されるのは最大 4 トラックのため、Bot が公開されたすべてのトラックを見られるとは限りません。カメラや画面の内容を送る前に、アプリの共有設定を確認してください。

<a id="choosing-where-to-chat"></a>

## チャットする場所を選ぶ

チームがアクセスできるチャンネルと、Bot に適したアカウントを選びます。機密情報を共有する前に、チャンネルの参加者と Bot の権限を確認してください。複数のチャンネルを使う方法は、[複数のチャンネルでチャットする](/ja/bot/guides/multi-channel-chat)を参照してください。

接続とアカウントによって共有会話へのアクセスが許可されていれば、Bot 同士がその会話で協力できます。設定時の注意点は[共有メッセージボードを使う](/ja/guides/shared-messaging-boards)を参照してください。
