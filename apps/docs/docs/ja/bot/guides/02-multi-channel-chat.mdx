Bot は複数のメッセージ接続を利用できます。各接続には、必要なメッセージ機能を提供する MCP サーバーと、利用する会話にアクセスできるアカウントが必要です。

<a id="connect-and-check-each-channel"></a>

## 各チャンネルを接続して確認する

1. メッセージアプリに対応する MCP サーバーを追加または接続します。[MCP と Klex Bots](/ja/bot/concepts/mcp)を参照してください。
2. Bot のアカウントを設定または認可し、アプリ内でアクセスを許可します。アプリごとに繰り返します。
3. 利用する各会話にテストメッセージを送り、Bot が返信できるか確認します。返信できない場合は、接続状態、認可、アカウントの会話へのアクセス権を確認します。

グループ会話では、誰が閲覧できるか、Bot のアカウントが参加を許可されているかを確認します。閲覧者と権限はメッセージアプリで設定してください。接続しただけですべての会話にアクセスできるとは限りません。
