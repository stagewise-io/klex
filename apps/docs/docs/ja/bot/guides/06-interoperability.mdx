Klex Bot と他のエージェントは、両方がアクセスでき、必要な操作をサポートする共有サービスを通じて連携できます。たとえば、共通の会話でメッセージを交換したり、同じプロジェクトのリソースを使って作業したりできます。

Klex Bot には、必要な機能を提供する MCP サーバーを接続し、サービス内の Bot アカウントの権限を設定します。他のエージェントはそれぞれの手順で設定し、各エージェントに必要なコンテキストを提供してください。

<a id="try-a-shared-workflow"></a>

## 共有ワークフローを試す

1. 両方のエージェントが利用できるサービスを選び、適切な共通の会話またはリソースへのアクセスをそれぞれのアカウントに付与します。
2. 各エージェントに別々のタスクを割り当て、作業の引き継ぎ方法と結果の報告先を指定します。
3. 機密性のないデータでテストします。共有コンテンツを誰が閲覧できるか、どちらかのアカウントに必要以上の権限がないかを含めて結果を確認します。

利用できる連携と動作は、サービス、MCP サーバー、他のエージェントによって異なります。[Klex Bot を連携させる](/ja/guides/bot-collaboration)と [Klex Bot を安全に使う](/ja/guides/secure-bot-usage)も参照してください。
