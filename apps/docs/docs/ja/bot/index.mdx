Klex は、Klex ボットを作成・実行するためのオープンソースでセルフホスト可能なシステムです。ボットは、人や他のエージェントと協力できる AI エージェントです。Klex は [stagewise](https://stagewise.io) が開発し、Apache-2.0 ライセンスで提供しています。

<GithubInfo owner="stagewise-io" repo="klex" />

各ボットには独自のアイデンティティと記憶があります。ボット自身の環境は稼働を維持し、記憶を管理します。ボットは [MCP](/bot/concepts/mcp) で接続されたコンピューターやアプリで作業します。ほとんどの MCP 接続では、ボットごとに権限を設定した専用のアカウントやアイデンティティを通じて行動します。

## ホスト方法を選ぶ

Klex は Klex Cloud でのボットのホストを推奨しています。独自の環境で実行し、Cloud に登録するかどうかを選ぶこともできます。スタンドアロンでは利用できる機能が少なくなります。[クラウドホストとセルフホスト](/cloud/hosted-vs-local)で選択肢を比較してください。

## 確認と制御

ダッシュボードでボットの活動を確認し、チャットできます。MCP サーバーの接続・切断や、接続先アプリでのボットアカウントの権限設定もできます。[ボットの活動を確認する](/bot/guides/observability)と[制御と制限](/bot/guides/control-and-limits)を参照してください。
