セルフホスト版 Klex Cloud は Enterprise のお客様のみご利用いただけます。デプロイの要件と提供状況については Klex にお問い合わせください。

Cloud のセルフホスティングは、個々の Bot を自分の環境で実行することとは異なります。セルフホストの Bot は Klex Cloud に登録できますが、登録は技術的な必須条件ではありません。Bot のホスティング方法については[ホスト型とセルフホスト型](/ja/cloud/hosted-vs-local)を参照してください。
