[**Klex Cloud**](https://cloud.klex.bot) は Klex Bot をホストし、管理用のダッシュボードを提供します。セルフホストの Bot を登録することもできます。Bot に必要なアプリやサービスを接続し、それぞれのアカウントと権限を設定してください。

<Panel title="知っておきたいこと">
Klex Cloud は完全に任意です。Cloud を使わずに Klex Bot を実行し、独自の MCP サーバーに接続できます。
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Cloud で Klex Bot を設定する

Cloud のセットアップウィザードでは、Cloud ホストの Bot を作成するか、セルフホストの Bot を設定できます。ウィザードが Bot とモデルの設定を案内します。アプリやサービスは設定後に接続できます。

まず[クイックスタート](/ja/bot/quickstart)をご覧ください。
