単一の Klex ボットは単一のアイデンティティと一つの意識インスタンスとして機能し、マルチタスクの量に制限があります。しかし、これはボットが単一の内部会話で構成されていることを意味するものではありません。

それどころか、Klex ボットのアーキテクチャは並列化を使用しており、[グローバルワークスペース理論（GWT）](https://en.wikipedia.org/wiki/Global_workspace_theory)が想定する人間の脳の動作方式とほぼ類似しています。

## 技術的基盤

単一の Klex ボットは、同時に動作する可変数の**セッション**を持ちます。各セッションは LLM エージェントと内部環境間の会話であり、自動コンテキスト圧縮のおかげで任意の長期間動作できます。開いているセッションのうち一つだけが環境にアクセスし、外部世界と相互作用して振る舞いを表現できます（GWT の「照らされたメインステージ」）。

他のセッションは異なる目的を持ち、例えば受信シグナルのフィルタリングや記憶の更新・統合などを行います。それらはメインセッションから独立して動作しますが、コンテキストを渡すことでメインセッションに影響を与えることができます。

### メインセッション

メインセッションはボットの実際の振る舞いとアクションを表します。このセッションのみが MCP にアクセスでき、環境への接続との相互作用が可能になります。ただし、記憶の作成や統合などのタスクは処理せず、外部世界からの受信イベントやリマインダーやToDoなどの内部トリガーに基づく実際の作業に純粋に集中できます。

### ユーティリティセッション

ユーティリティセッションは外部世界にアクセスできませんが、ボットのデータディレクトリと相互作用できます。既存のセッションを分析して新しい記憶を構築し、廃止された記憶を削除し、スキル（手続き的記憶）を微調整し、ボットの経験を記憶内のエンティティにリンクするなどのタスクを処理します。

### ゴッドセッション

ゴッドセッションは、外部世界へのアクセスが制限された専用セッションであり、管理 API 経由でのみ使用できます。専用の[ゴッドメッセージ](/concepts/god-messages)以外の外部世界からの入力を受け取らず、ボットに[魂](/concepts/soul)の作成や更新を命令するなど、昇格された権限を必要とする管理タスクを実行することを目的としています。
