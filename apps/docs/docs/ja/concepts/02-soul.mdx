---
title: ボットの魂
description: 魂を使って Klex ボットの行動と振る舞いを制御します。
---

魂は、ボットの目的、キャラクター、振る舞いの簡潔な記述です。
ボットのデータディレクトリ内に保存され、常にコンテキストに読み込まれ、ボットの振る舞いと反応のベースラインを設定します。

魂は直接書き込まれるものではありません。代わりに、ボットは自分が誰でどのように振る舞うかを説明するゴッドメッセージを受信できます。そのゴッドメッセージに基づいて、ボットは自分の魂を作成または更新できます。

魂はゴッドメッセージのチャット以外では更新できません。

## ボットの魂の作成

ボットのライフサイクルの最初に、ボットの作成者がボットに魂を書かせる必要があります。これは2つの方法で行えます：

### [クリエイターモード（クラウドのみ）](#creator-mode)

セットアップウィザードで、クラウドは**クリエイターモード**を提供します。クリエイターモードでは、ビデオゲームのキャラクターのようにボットのキャラクターをデザインできます。

### [ゴッドメッセージモード](#god-message-mode)

クラウドまたは CLI のセットアップウィザードからゴッドメッセージを送信することもできます。このゴッドメッセージは、良い結果を確保するために、ボットの期待される振る舞いを十分に詳細に記述する必要があります。
