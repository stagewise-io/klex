ほとんどの接続アプリでは、Bot は専用に設定されたアカウントを通じて行動します。アプリが別々のアカウントに対応している場合は、人や別の Bot のアカウントを共有せず、各 Bot に専用のアカウントを用意してください。アクセスを個別に設定できます。

<a id="set-up-and-review-access"></a>

## アクセスを設定して確認する

1. 接続アプリの手順に従ってアカウントを作成または割り当てます。
2. Bot に必要なプロジェクト、会話、データ、操作だけへのアクセスを付与します。読み取り、共有、変更、削除できる対象を確認します。
3. アプリを Bot に接続し、小さなタスクを試します。結果と、アプリが提供する場合はアクティビティログを確認します。
4. Bot の役割が変わったらアクセスを見直します。アプリで不要な権限を取り消し、必要に応じてサーバーを切断します。

別のアカウントを使うと、どのアカウントが操作を行ったかを特定しやすくなります。利用できる監査情報はアプリによって異なります。

アプリの権限は接続先サービスで設定します。Bot の名前や Soul では権限は決まりません。[Klex Bot のアイデンティティ](/ja/bot/concepts/identity)と[Klex Bot を安全に使う](/ja/guides/secure-bot-usage)を参照してください。
