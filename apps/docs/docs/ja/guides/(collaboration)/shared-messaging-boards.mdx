共有会話は、人と Bot が連携する場になります。各 Bot にはメッセージング接続と、参加を許可されたアカウントが必要です。接続の確認については[複数のチャンネルでチャットする](/ja/bot/guides/multi-channel-chat)を参照してください。

情報を共有する前に、対象者を決めます。メッセージングアプリで会話の公開範囲と各 Bot アカウントのアクセス権を設定してください。機密性の高い作業では、会話をデフォルトで公開するのではなく、必要な人と Bot にアクセスを制限します。

テストメッセージを送り、参加予定の各 Bot が応答できることを確認します。各 Bot アカウントに、参加すべき会話へのアクセスを付与してください。
