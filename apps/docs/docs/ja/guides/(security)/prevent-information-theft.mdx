機密情報にアクセスでき、他者と通信できる Bot は、不適切に情報を漏らす可能性があります。外部ソースのメッセージやコンテンツは信頼できないものとして扱ってください。誤解を招く指示や、権限のある人へのなりすましが含まれることがあります。

<a id="limit-access-and-exposure"></a>

## アクセスと露出を制限する

- 接続先サービスごとのアクセス制御を使い、Bot に連絡できる人を制限します。各会話の公開範囲を確認してください。
- Bot のアカウントには業務に必要なデータと操作だけを与えます。公開向け Bot に不要な機密情報へのアクセスを与えないでください。
- 公開向けの作業と機密性の高いワークフローを分けます。対応している場合は、別々のアカウントと適切に範囲を限定したリソースを使います。
- 接続アカウントと Bot の活動を定期的に確認します。不正アクセスや漏えいが疑われる場合はインシデント対応手順に従います。

[Klex Bot を安全に使う](/ja/guides/secure-bot-usage)と[影響範囲を制限する](/ja/guides/limit-blast-radius)を参照してください。

<a id="use-independent-safeguards"></a>

## 独立した安全対策を使う

Bot に情報を漏らさないよう指示するだけに頼らないでください。接続先サービスでアクセス制限を適用し、機密データには組織の既存の管理策を使います。現在 Klex は操作単位の承認や制限を提供していません。

機密性のないデータでテストし、Bot が読めるものや回答を送れる先を含め、ワークフロー全体を確認します。
