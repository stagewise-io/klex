会社ハンドブックは、組織について一貫した情報を Bot に提供できます。対象とする顧客、用語、Bot の業務に関係する原則などを記載できます。

ハンドブックは文書でも社内サイトでも構いません。ただし、必要とする各 Bot に、そのソースを読み取れる接続とアクセス権のあるアカウントが必要です。利用できる機能は MCP サーバーと接続先サービスによって異なります。

<a id="share-it-safely"></a>

## 安全に共有する

- 各 Bot に必要な資料だけへのアクセスを許可します。機密性の高い手順や認証情報は、適切にアクセスを制限したソースに保管します。
- 担当者と見直し日を記載し、内容の正確さを維持します。古い指示は削除します。
- 小さなタスクでハンドブックを使うよう Bot に依頼し、結果と使用したソースを確認します。

接続先サービスで権限を設定し、影響の大きい作業は独立したレビューを行います。[Klex Bot を安全に使う](/ja/guides/secure-bot-usage)を参照してください。
