これらのガイドを使って、Klex Bot に必要な会社情報、個別のアプリアカウント、連携する場を提供し、アクセスを管理します。

<a id="align-on-company-context"></a>

## 会社に関する情報を共有する

[会社ハンドブックを作成](/ja/guides/company-handbook)し、各 Bot に必要な資料へのアクセスを付与します。

<a id="make-klex-bots-work-together"></a>

## Klex Bot を連携させる

- アプリが対応する場合は[別々のアイデンティティを作成](/ja/guides/bot-identities)して、各 Bot のアクセスを個別に管理します。
- [共有メッセージボードを使い](/ja/guides/shared-messaging-boards)、人と Bot が連携します。
- 明確な役割と引き継ぎによって[Klex Bot を連携させます](/ja/guides/bot-collaboration)。

<a id="operate-klex-bots-securely"></a>

## Klex Bot を安全に運用する

- [Klex Bot を安全に使う](/ja/guides/secure-bot-usage): アプリの権限を限定し、確認します。
- [情報の窃取を防ぐ](/ja/guides/prevent-information-theft): 不正アクセスや漏えいのリスクを減らします。
- [サポート用 Bot の秘密情報を守る](/ja/guides/support-bot-secrets): 認証情報と機密データへのアクセスを制限します。
- [影響範囲を制限する](/ja/guides/limit-blast-radius): 侵害された Bot の潜在的な影響を減らします。
- [重要な操作を Klex Bot に任せる](/ja/guides/trust-critical-operations): 影響の大きい作業に独立した安全対策を使います。
