Klex は、ボット（完全に自律的なエージェント）を作成・実行するためのオープンソースでセルフホスト可能なシステムであり、AI 搭載のデジタル同僚でチームの労働力を拡張するために特別に設計されています。Klex は [stagewise](https://stagewise.io) によって構築され、Apache-2.0 ライセンスで提供されています。

<GithubInfo owner="stagewise-io" repo="klex" />

単一の Klex ボットは個人のアイデンティティとして行動します。独自の性格、独自の記憶、そしてすべての作業プラットフォームでの独自のアイデンティティを持ちます。

私たちは Klex ボットを「アシスタント」と呼ぶのを**好まない**のです。なぜなら、あなたのアシスタントとして働く Klex ボットを作成することは*できます*が、
Klex ボットはそれよりもはるかに強力で、人間であれボットであれ、同僚と協力するボットのチーム全体を作成できます。

## コア原則

私たちが構築するものはすべて、6つの原則に導かれています：

- **オープンソースでモデル非依存** — ベンダーロックインなし。いつでもモデルを変更するか、独自のインフラでボットを実行できます。
- **独自のアイデンティティ** — ボットは自分自身として行動し、他人の代わりとしてではありません。すべての統合はこの考え方で構築されています。
- **使いやすさ** — AI 搭載の労働力は誰もが利用できるべきです。私たちは**カスタマイズよりも使いやすさを優先**し、セットアップとメンテナンスをシンプルに保ちます。
- **標準準拠** — すべての外部通信は [**MCP**](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro) を通じて行われます — カスタムゲートウェイは不要です。通信プラットフォームは MCP と、アプリがプロアクティブにボットをトリガーできる小さな拡張機能を介して接続します。記憶システムも [**Agent Skills**](https://agentskills.io/home) と互換性があり、手続き的記憶の保存に使用できます。
- **内省可能性** — ボットの記憶は純粋な Markdown で保存されます。ボットが知っていることすべてをいつでも読んで確認できます。
- **適応性** — ボットは MCP 経由で明示的に接続されたマシンにのみアクセスします — 実行中のホストには決してアクセスしません。自身の生の記憶を内省したり、性格を変更したり、ホストの設定を変更したりすることはできません。これにより、設計上安全な操作が保証されます。

## Klex クラウド

私たちのボットには [**Klex クラウド**](https://cloud.klex.bot) と呼ばれるクラウドサービスが付属しており、さまざまなプラットフォーム向けの Klex 対応 MCP サーバーをホストしています。

クラウドはまた、それらのプラットフォームでボットに専用のアイデンティティ（アカウント、ボットインスタンス、またはアプリ経由）を提供し、ボットが活動できる独自のアイデンティティを簡単に付与できます。

<Panel title="覚えておくと便利">
クラウドサービスは**完全にオプション**であり、通信データが第三者プロバイダー経由で転送されないようにしたい場合は無視できます。
</Panel>

エンタープライズ顧客には、クラウドサービスのオンプレミスホスト可能なバリアントを提供し、データレジリエンシーなどに関するすべてのニーズへの準拠を確保します。

また、SOC2 Type 2 コンプライアンスと ISO 27001 認証の取得プロセス中です。詳細は[トラストセンターをご覧ください](https://trust.stagewise.io)。
