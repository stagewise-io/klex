## 설치

Klex 봇은 자체 호스팅됩니다. 즉, 나중에 봇의 기억 저장 및 실행 환경으로 사용할 머신에 Klex 애플리케이션을 다운로드해야 합니다.

<Panel title="알아두면 좋습니다">
봇은 시스템의 파일에 자동으로 접근**하지 않습니다**. 대신, 호스트는 봇의 사고와 기억 저장 및 검색이 이루어지는 장소로만 작용합니다.

**컴퓨터 사용** 또는 개발을 위한 샌드박스나 전체 머신을 포함한 외부 세계와의 모든 상호작용은 MCP를 통해 컴퓨터를 명시적으로 연결해야 합니다.
</Panel>

Klex를 설치하려면 시스템 셸에서 다음 스크립트를 실행하세요：

<Tabs param="install">
  <Tab title="macOS">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Linux">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Windows">`irm https://klex.bot/install.ps1 | iex`</Tab>
  <Tab title="WSL">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
</Tabs>

## 봇 만들기

<Tabs inline param="bot-setup">

<Tab title="클라우드 지원 (권장)" syncKey="cloud">
  <Steps>
  <Step title="Klex 클라우드에 가입">
    [Klex 클라우드](https://cloud.klex.bot)에 접속하여 가입하세요. 왼쪽 사이드바에서 Bots 패널을 선택하고 `Set up a Klex Bot`을 클릭하세요.
  </Step>
  <Step title="Klex 시작">
    마법사의 가이드를 따라 Klex 앱을 설치하고 시작하세요.
  </Step>
  <Step title="새 봇 만들기">
    Klex 앱에서 옵션 목록의 `Create a new Bot`을 선택하고 Enter를 누르세요.
  </Step>
  <Step title="봇 이름 지정">
    이 봇이 사용할 이름을 입력하세요. 봇은 이것이 자신의 이름임을 알게 됩니다.
  </Step>
  <Step title="봇을 클라우드에 등록">
    클라우드 마법사의 지시에 따라 이 봇을 Klex 클라우드 조직에 연결하세요.
  </Step>
  <Step title="모델 제공자 및 모델 선택 구성">
    클라우드 마법사가 봇이 사용할 모델 제공자와 모델을 구성하라는 메시지를 표시합니다.
    <Panel title="알아두면 좋습니다">
      제공자 자격 증명은 안전하게 전송되어 봇을 호스트하는 머신의 봇 자체 구성에 저장되며, 클라우드에는 **저장되지 않습니다**.
    </Panel>
    <Panel title="알아두면 좋습니다">
    Klex는 다양한 구독, 자사 제공자, 로컬 LLM 제공자 및 범용 API 제공자를 지원합니다.

    [모델 제공자](/concepts/model-providers) 및 [모델 선택](/concepts/model-selection)에 대해 더 알아보세요.
    </Panel>
  </Step>
  <Step title="봇에 영혼 부여">
    다음 단계에서 마법사가 봇의 영혼을 디자인하라고 요청합니다. 두 가지 옵션이 있습니다: [크리에이터 모드](/concepts/soul#creator-mode)(*권장!*)와 [갓 메시지 모드](/concepts/soul#god-message-mode).

    [영혼에 대해 더 알아보세요](/concepts/soul).
  </Step>
  <Step title="MCP 연결">봇에 MCP에 대한 접근 권한을 부여하세요. **Klex 클라우드**가 각 통합 앱에서 봇을 위한 전용 계정을 쉽게 생성할 수 있도록 도와주지만, 물론 다른 MCP도 연결할 수 있습니다.</Step>
</Steps>
</Tab>

<Tab title="독립형" syncKey="standalone">
<Panel title="중요">
Klex 클라우드 없이 Klex 봇을 사용하려면, 봇을 사전에 트리거할 수 있는 MCP를 최소 하나 연결해야 합니다.
이는 MCP가 다음 중 **하나 이상을** 구현**해야 함**을 의미합니다：

- 변경 알림이 있는 개별 MCP 리소스로서의 대화
- 당사의 [MCP 확장](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications)에 따른 푸시 알림
</Panel>

<Steps>
  <Step title="Klex 시작">
    다음 명령으로 CLI를 시작하세요：`klex --no-cloud`
  </Step>
  <Step title="새 봇 만들기">
    옵션 목록에서 `Create a new Bot`을 선택하고 Enter를 누르세요.
  </Step>
  <Step title="봇 이름 지정">
    이 봇이 사용할 이름을 입력하세요. 봇은 이것이 자신의 이름임을 알게 됩니다.
  </Step>
  <Step title="모델 제공자 구성">
    `Settings -> Model Providers`로 이동하여 사용할 각 모델 제공자에 대한 제공자 인스턴스를 생성하세요.
    <Panel title="알아두면 좋습니다">
    Klex는 다양한 구독, 자사 제공자, 로컬 LLM 제공자 및 범용 API 제공자를 지원합니다.
    
    [모델 제공자에 대해 더 알아보세요](/concepts/model-providers)。
    </Panel>
  </Step>
  <Step title="모델 선택 구성">
    `Settings -> Model Selection`으로 이동하여 봇의 각 사용 사례에 대한 모델을 구성하세요.
    <Panel title="알아두면 좋습니다">
    "Chat"에 대한 유효한 모델을 구성해야 하지만, 저렴한 사용과 전체 기능을 보장하기 위해 모든 기능을 구성하는 것을 강력히 권장합니다.

    [모델 선택에 대해 더 알아보세요](/concepts/model-selection)。
    </Panel>
  </Step>
  <Step title="봇에 영혼 부여">
    `Settings -> God messages`로 이동하여 `God message`를 보내세요. 갓 메시지의 내용은 봇의 영혼이 어떠해야 하는지(작업, 성격 등)를 설명해야 합니다.

    [영혼에 대해 더 알아보세요](/concepts/soul)。
  </Step>
  <Step title="MCP 연결">`Settings -> MCPs`로 이동하여 MCP를 연결하고 봇에 외부 세계에 대한 접근 권한을 부여하세요。</Step>
</Steps>

</Tab>

</Tabs>
