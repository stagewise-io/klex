함께 일할 Klex 봇을 만들어 보세요. Klex는 대부분의 사용자에게 Cloud 호스팅을 권장하지만, 자신의 컴퓨터에서 봇을 실행할 수도 있습니다.

## 클라우드 호스팅 설정

1. [Klex Cloud](https://cloud.klex.bot)에 로그인하고 **New bot**을 선택합니다.
2. 봇에게 업무를 지정하거나 추천 업무를 선택하고, 이름과 외모를 설정합니다.
3. **Create bot in cloud**를 선택합니다.
4. 성격 특성을 확인한 다음 **Models & Computer**로 이동합니다.
5. AI 제공업체를 연결하고 봇이 사용할 모델을 선택하거나 다른 봇의 모델 설정을 가져옵니다. 봇이 연결되면 설정을 완료합니다.
6. 봇의 채팅을 열어 시작합니다.

봇의 업무에 필요한 앱과 컴퓨터를 연결할 수 있습니다. 지원되는 MCP 서버는 봇이 작업을 시작하는 계기가 되는 메시지와 앱 이벤트도 전달할 수 있습니다. 자세한 내용은 [MCP와 Klex 봇](/bot/concepts/mcp)을 참고하세요.

## 셀프 호스팅 설정

1. [Klex Cloud](https://cloud.klex.bot)에 로그인하고 **New bot**을 선택한 다음 봇의 업무와 외모를 선택합니다.
2. **Or run it on your own computer**를 선택한 다음 **Set up on your computer**를 선택합니다. Klex Cloud에서 제공하는 명령어 전체를 복사하여 봇을 실행할 컴퓨터의 터미널에 붙여 넣고 실행합니다.
3. 설정 안내에 따라 봇의 성격과 모델을 구성합니다.

봇이 일할 수 있도록 컴퓨터에서 계속 실행해 두세요. 다시 시작하려면 터미널에서 다음 명령어를 실행하고 봇을 선택합니다.

```sh
klex
```

### Cloud 없이 실행하기

Cloud 등록은 선택 사항입니다. Klex 앱에서 직접 봇을 설정하려면 [독립 실행 설정 가이드](/bot/guides/standalone-setup)를 참고하세요. 이 가이드에는 [선택 메뉴 없이 봇을 만드는 방법](/bot/guides/standalone-setup#create-a-bot-without-the-picker)도 설명되어 있습니다.
