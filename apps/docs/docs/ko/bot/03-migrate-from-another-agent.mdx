기존 에이전트의 업무와 유용한 지식을 Klex Bot으로 이전하세요. 먼저 에이전트가 하는 일과 알고 있는 내용, 사용하는 리소스를 모으세요.

<a id="prepare-the-workflow"></a>

## 핵심 정보 모으기

현재 에이전트에 인계 문서를 요청하세요. 아래 프롬프트를 출발점으로 삼아 이전할 업무에 맞게 조정하세요.

~~~text
당신의 업무를 새 AI 에이전트로 이전하려고 합니다. 새 에이전트와 관리자가 업무를 계속하는 데 사용할 수 있는 인계 문서 하나를 작성하세요.

명확한 제목과 실용적인 세부 정보를 사용해 다음을 포함하세요.

1. 역할과 우선순위: 목적, 책임, 선호하는 작업 방식, 함께 일하는 사람이나 팀.
2. 지식과 맥락: 학습한 중요한 사실, 용어, 결정, 선호 사항과 관련 배경. 근거 정보를 찾을 수 있는 곳을 표시하세요.
3. 일과와 일정: 반복 작업, 시간과 시간대, 트리거, 예상 결과물과 결과를 보낼 곳.
4. 일반적인 절차: 단계별 워크플로, 의사결정 지점, 인계, 예시, 결과 확인 방법.
5. 스킬과 학습: 재사용 가능한 절차, 과거 업무의 교훈, 흔한 문제와 대처 방법.
6. 연결과 접근: 각 워크플로에 필요한 앱, 계정, 리소스와 기능. 자격 증명을 포함하지 말고 필요한 접근 권한을 설명하세요.
7. 진행 중인 업무: 현재 작업, 미결 결정, 마감일과 각각의 다음 행동.

사용 가능한 정보를 사용하세요. 추측하지 말고 접근할 수 없거나 확실하지 않은 내용을 표시하세요. 비밀번호, 토큰, API 키 또는 기타 비밀을 포함하지 마세요. 무엇을 공유할지 제가 결정할 수 있도록 민감한 정보를 표시하세요. 인계 내용을 구조화된 문서 하나로 반환하세요.
~~~

문서의 정확성과 민감한 정보를 검토하세요. 이전 에이전트가 접근할 수 없었던 다른 곳에 저장된 일정이나 지시 등을 추가하세요.

<a id="set-up-your-klex-bot"></a>

## Klex Bot 설정

1. [Klex Bot을 만드세요](/ko/bot/quickstart). 인계 문서로 업무와 성격을 설명하세요.
2. 인계 문서의 관련 내용을 Bot에 제공하고 맡을 업무를 알려 주세요. 재사용 가능한 절차에는 [Agent Skills](/ko/bot/concepts/agent-skills)를 사용하세요.
3. 업무에 필요한 [앱과 컴퓨터를 연결](/ko/bot/concepts/brain-and-computers)하고 각 서비스에서 Bot 계정의 접근 권한을 설정하세요.
4. 연결된 일정 관리 서비스로 반복 업무를 설정하세요. [반복 작업 자동화](/ko/bot/guides/recurring-tasks)를 참고하세요.

<a id="test-before-switching-over"></a>

## 인계 확인

대표적인 작업을 시험하고 결과를 검토하세요. Bot이 리소스에 접근하고 올바른 곳에 보고하며 예약된 업무를 받는지 확인하세요. 새 워크플로가 작동하면 더 이상 필요하지 않은 이전 에이전트의 접근 권한과 일정을 제거하세요.
