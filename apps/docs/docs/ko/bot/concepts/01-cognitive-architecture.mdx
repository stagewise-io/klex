Klex 봇은 활성 세션과 [메모리](/bot/concepts/memory)를 관리하는 환경에서 실행됩니다. 봇은 [MCP](/bot/concepts/mcp)로 연결된 외부 컴퓨터와 앱에서 작업합니다.

<a id="기술적-기반"></a>
<a id="메인-세션"></a>
<a id="the-technical-foundation"></a>
<a id="main-session"></a>

## 일반 세션

일반 세션은 연결된 MCP 서버에 접근할 수 있습니다. 봇은 수신 이벤트를 처리하고 연결된 환경에서 작업할 수 있습니다. 가능한 작업은 연결과 그 권한에 따라 달라집니다.

<a id="유틸리티-세션"></a>
<a id="utility-sessions"></a>

## 별도 작업

봇은 내부 작업에 별도 세션을 사용할 수 있습니다. 예를 들어 복잡한 문제에 대한 자문을 요청하고 그 결과를 작업에 참고할 수 있습니다.

<a id="갓-세션"></a>
<a id="god-session"></a>
<a id="god-messages"></a>

봇의 환경과 연결에 대한 자세한 내용은 [Klex 봇의 작동 방식](/bot/concepts/how-bots-work)을 참고하세요.
