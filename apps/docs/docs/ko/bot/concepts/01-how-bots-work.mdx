Klex Bot은 고유한 정체성과 메모리를 가진 자율 에이전트입니다. Bot 환경에서 실행되며 MCP(Model Context Protocol)를 통해 연결된 다른 환경에서 작업합니다.

Bot 자체 환경은 Bot의 실행과 메모리를 관리합니다. 작업은 연결된 컴퓨터와 앱에서 이루어집니다. 메모리에는 스킬과 학습 내용이 저장되며, Bot은 각각의 MCP 연결을 통해 컴퓨터와 앱에 연결됩니다.

<a id="where-the-bot-runs"></a>

## Bot이 실행되는 곳

Cloud에서 호스팅하는 Bot을 사용하거나 직접 관리하는 환경에서 Bot을 실행할 수 있습니다. Klex는 Cloud 호스팅을 권장합니다. 직접 호스팅하는 Bot도 Klex Cloud에 등록할 수 있습니다. 직접 호스팅하는 Bot에 Cloud 등록이 기술적으로 필수는 아니지만, 단독으로 사용할 때는 기능이 더 제한됩니다. [호스팅과 직접 호스팅 비교](/ko/cloud/hosted-vs-local)를 참고하세요.

<a id="how-the-bot-works-with-computers-and-apps"></a>

## Bot이 컴퓨터와 앱에서 작업하는 방식

Bot은 외부 환경에 접근하기 위해 MCP 서버에 연결합니다. 외부 환경은 전체 컴퓨터일 수도 있고 GitHub나 Google Workspace 같은 앱일 수도 있습니다.

대부분의 MCP에서 Bot은 자신의 계정이나 정체성을 통해 작업합니다. 이 정체성은 Bot마다 설정하며 권한과 접근 권한을 부여할 수 있습니다. 연결과 접근 방식은 [연결](/ko/bot/concepts/brain-and-computers)을 참고하세요.

<a id="what-the-bot-remembers"></a>

## Bot이 기억하는 것

메모리는 Bot이 경험을 바탕으로 작업하는 데 도움을 줍니다. Bot은 반복 작업에 스킬과 학습 내용을 사용하고, 과거 활동에서 관련 맥락을 떠올릴 수 있습니다. 자세한 내용은 [메모리](/ko/bot/concepts/memory)를, 저장 및 관리자 접근은 [데이터 디렉터리](/ko/bot/concepts/data-directory)를 참고하세요.
