Soul은 봇의 성격, 소통 방식, 역할과 우선순위를 설명합니다. [메모리](/bot/concepts/memory)와는 별개이며 일반 세션의 컨텍스트에 포함됩니다.

## Soul 만들기 및 업데이트

봇의 Admin API에 지시를 보내 Soul을 만들거나 업데이트합니다. 처음부터 만들려면 `POST /v1/soul`, 기존 Soul을 업데이트하려면 `PATCH /v1/soul`을 사용합니다. Soul을 읽으려면 `GET /v1/soul`을 사용합니다. 접근 방법과 보안 안내는 [로컬 Admin API 접근](/bot/guides/observability#access-the-local-admin-api)을 참고하세요.

Soul 생성에는 설정된 채팅 모델이 사용되며 생성에 성공하면 결과가 저장됩니다. 예를 들어 지시에 봇의 역할, 선호하는 말투, 의사결정 방식을 설명할 수 있습니다. 생성된 Soul을 확인하고 필요한 경우 업데이트하세요. 봇에 새 작업을 보내기 전에 Soul을 저장하세요.

## 저장 및 접근

Soul은 봇의 [데이터 디렉터리](/bot/concepts/data-directory)에 저장됩니다. 봇의 Admin API는 Soul을 읽고 관리자의 지시에 따라 새로 만들거나 업데이트할 수 있습니다. 일반 세션에는 Soul을 쓰는 도구가 없습니다.

## Soul이 없는 경우

봇이 일반 작업을 처리하려면 내용이 있는 Soul이 필요합니다. Soul이 없으면 새 작업을 건너뛰고 세션 기록에 새로 추가된 내용을 버립니다. 건너뛴 작업은 대기열에 보관되지 않습니다. 새 입력을 보내기 전에 Soul을 만드세요.
