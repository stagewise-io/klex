---
title: 봇의 영혼
description: 영혼을 사용하여 Klex 봇의 행동과 태도를 제어합니다.
---

영혼은 봇의 목적, 성격, 행동을 간결하게 설명합니다. 데이터 디렉토리에 저장되며 컨텍스트에 로드됩니다.

CLI의 `Settings -> Soul`에서 영혼을 생성하거나 업데이트하고 목적, 성격, 예상 행동을 설명하세요. 전용 API는 `GET /v1/soul`, 생성용 `POST /v1/soul`, 업데이트용 `PATCH /v1/soul`을 제공합니다. 업데이트 지침을 비워 두면 기존 영혼을 최적화합니다.

채팅 세션은 영혼을 읽기만 하며 편집할 수 없습니다. 영혼이 없으면 봇은 채팅 추론을 실행하지 않습니다.
