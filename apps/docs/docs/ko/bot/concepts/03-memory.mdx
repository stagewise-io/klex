메모리는 Klex Bot이 학습한 내용을 바탕으로 과거 업무의 맥락을 활용하도록 돕습니다. 학습하거나 미리 설정된 절차를 포함한 **스킬**과 Bot의 활동에서 얻은 관련 지식을 결합합니다.

Bot은 스킬을 사용해 익숙한 작업을 처리하고, 프로젝트 용어나 이전 결정처럼 유용한 과거 맥락을 떠올릴 수 있습니다. 백그라운드에서 기억 검색을 요청할 수 있으며, 작업 중 관련 맥락이 나타날 수도 있습니다. 재사용 가능한 절차는 [Agent Skills](/bot/concepts/agent-skills)를 참고하세요.

<a id="where-chats-and-memory-are-stored"></a>

## 채팅과 메모리는 어디에 저장되나요?

채팅과 메모리는 Bot의 데이터 디렉터리에 저장됩니다.

- **Cloud 호스팅 Bot**의 디렉터리는 호스팅 환경에 있습니다.
- **셀프 호스팅 Bot**의 디렉터리는 Bot 데이터에 사용하는 로컬 폴더에 있습니다.

메모리를 포함한 모든 Cloud 호스팅 Bot 데이터는 전송 중과 저장 시에 암호화됩니다.

## 채팅과 스킬 확인

관리자는 Bot의 Admin API를 통해 채팅과 스킬을 확인할 수 있습니다. Klex Cloud 대시보드는 각 Bot의 Admin API를 위한 프런트엔드이자 리버스 프록시입니다. 저장 위치에 관한 자세한 내용은 [데이터 디렉터리](/bot/concepts/data-directory)를 참고하세요.
