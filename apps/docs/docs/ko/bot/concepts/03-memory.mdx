Klex Bot 메모리는 **스킬과 학습 내용**을 지원하며 Bot의 과거 활동에서 관련 맥락을 가져올 수 있습니다. 메모리는 Bot의 작동을 유지하는 활성 세션과 함께 Bot 자체 환경에서 관리됩니다.

Bot은 백그라운드에서 기억 검색을 요청할 수 있으며, 요청하지 않아도 관련 맥락이 나타날 수 있습니다. 검색된 정보는 불완전하거나 틀릴 수 있으므로 중요한 내용은 확인하세요. 맥락 힌트는 검색을 안내할 수 있지만 접근 제어 수단은 아닙니다.

<a id="where-chats-and-memory-are-stored"></a>

## 채팅과 메모리는 어디에 저장되나요?

채팅과 메모리는 Bot의 데이터 디렉터리에 저장됩니다.

- **Cloud 호스팅 Bot**의 디렉터리는 호스팅 환경에 있습니다.
- **셀프 호스팅 Bot**의 디렉터리는 Bot 데이터에 사용하는 로컬 폴더에 있습니다.

메모리를 포함한 모든 Cloud 호스팅 Bot 데이터는 전송 중과 저장 시에 암호화됩니다.

<a id="how-administrators-access-them"></a>

## 관리자는 어떻게 접근하나요?

관리자는 Bot의 Admin API를 통해 채팅과 메모리에 접근할 수 있습니다. Klex Cloud 대시보드는 각 Bot의 Admin API를 위한 프런트엔드이자 리버스 프록시입니다. 저장 위치에 관한 자세한 내용은 [데이터 디렉터리](/bot/concepts/data-directory)를 참고하세요.
