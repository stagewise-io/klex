Agent Skill은 반복 작업에 사용할 수 있는 재사용 가능한 지침입니다. 예를 들어 프로젝트 진행 상황 보고서를 작성하는 방법을 설명할 수 있습니다. 스킬의 설명은 지침을 적용할 시점을 Bot에 알려 주고, 본문에는 절차가 담깁니다.

Klex는 Bot이 사용 가능한 스킬을 찾을 수 있도록 합니다. Bot은 작업에 해당하는 절차를 불러올 수 있습니다.

<a id="where-skills-come-from"></a>

## 스킬의 출처

스킬은 여러 곳에서 제공됩니다.

- **Template Skills**는 Bot Templates에 포함되어 제공됩니다.
- **Learned Skills**는 Bot의 경험을 통해 발전합니다.
- **Uploaded Skills**는 사용자가 동작이나 지식을 추가하기 위해 제공합니다.

각 Bot은 스킬을 자신의 [데이터 디렉터리](/bot/concepts/data-directory)에 저장합니다. 스킬은 `learning/project-status`와 같이 네임스페이스와 이름으로 식별합니다.

백그라운드 메모리 프로세스는 활동을 검토하고 유용한 교훈을 스킬로 만들 수 있습니다. 이후 활동을 처리하면서 학습된 스킬을 수정하거나 삭제할 수도 있습니다. 모든 대화에서 스킬이 만들어지는 것은 아닙니다.

각 스킬은 `skills/{namespace}/{name}/` 아래의 `SKILL.md` 파일로 저장됩니다. 파일에는 이름, 설명과 Markdown 본문이 포함됩니다. 스킬의 `references/` 폴더에 참조 파일을 둘 수도 있습니다.

## 스킬 검토 및 관리

<Tabs syncKey="hosting" hash={false}>
<Tab title="클라우드 호스팅">

Cloud에서 Uploaded Skills를 관리하는 기능은 곧 제공될 예정입니다. Cloud에서 사용자가 관리할 수 있는 스킬은 Uploaded Skills뿐입니다.

</Tab>
<Tab title="셀프 호스팅">

스킬을 검토하려면 Bot의 Admin API를 사용하세요. 로컬 액세스와 보안상 제한 사항은 [Bot 활동 검토하기](/bot/guides/observability#access-the-local-admin-api)를 참조하세요.

</Tab>
</Tabs>

Bot의 Admin API로 스킬 목록과 내용을 조회하고 스킬을 수정하거나 삭제할 수 있습니다. 목록을 조회하려면 `GET /v1/skills`를, 개별 스킬을 읽으려면 `GET /v1/skills/{namespace}/{name}`을 사용하세요. 같은 경로에서 `PATCH`와 `DELETE`도 지원합니다. 참조 파일에는 별도의 API 경로가 있습니다. 메모리 엔터티가 스킬을 참조하면 삭제가 실패할 수 있습니다.

학습된 스킬의 정확성을 검토하세요. 관리자가 수정한 스킬을 포함해 메모리 프로세스가 시간이 지나면서 학습된 스킬을 수정하거나 삭제할 수 있습니다. 수정해도 이후 변경이 차단되지는 않습니다.
