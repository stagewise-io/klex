Bot은 여러 메시징 연결을 사용할 수 있습니다. 각 연결에는 필요한 메시징 기능을 제공하는 MCP 서버와 사용할 대화에 접근할 수 있는 계정이 필요합니다.

<a id="connect-and-check-each-channel"></a>

## 각 채널 연결 및 확인

1. 메시징 앱에 맞는 MCP 서버를 추가하거나 연결합니다. [MCP와 Klex Bots](/ko/bot/concepts/mcp)를 참조하세요.
2. Bot 계정을 설정하거나 인증하고 메시징 앱에서 접근 권한을 부여합니다. 각 앱에 대해 반복합니다.
3. 사용할 각 대화에 테스트 메시지를 보내고 Bot이 응답할 수 있는지 확인합니다. 응답하지 못하면 연결 상태, 인증 및 해당 대화에 대한 계정의 접근 권한을 확인합니다.

그룹 대화에서는 누가 대화를 볼 수 있는지, Bot 계정이 참여할 수 있는지 확인합니다. 메시징 앱에서 공개 대상과 권한을 설정하세요. 연결만으로 모든 대화에 접근할 수 있다고 가정하지 마세요.
