Klex Bot과 다른 에이전트는 둘 다 접근할 수 있고 필요한 작업을 지원하는 공유 서비스를 통해 협업할 수 있습니다. 예를 들어 공유 대화에서 메시지를 주고받거나 같은 프로젝트 리소스를 이용해 작업할 수 있습니다.

Klex Bot에는 필요한 기능을 제공하는 MCP 서버를 연결하고 서비스에서 Bot 계정의 권한을 설정하세요. 다른 에이전트는 해당 설정 절차에 따라 구성하고, 각 에이전트에 필요한 맥락을 제공하세요.

<a id="try-a-shared-workflow"></a>

## 공유 워크플로 시도하기

1. 두 에이전트가 사용할 수 있는 서비스를 선택하고 각 계정에 적절한 동일한 대화 또는 리소스에 대한 접근 권한을 부여합니다.
2. 각 에이전트에 서로 다른 작업을 맡기고 작업을 인계하는 방법과 결과를 보고할 위치를 지정합니다.
3. 민감하지 않은 데이터로 테스트합니다. 공유 콘텐츠를 볼 수 있는 사람과 어느 계정에 필요한 것보다 많은 권한이 있는지를 포함해 결과를 확인합니다.

사용 가능한 연동과 동작은 서비스, MCP 서버, 다른 에이전트에 따라 다릅니다. [Klex Bot 함께 작업하기](/ko/guides/bot-collaboration)와 [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)를 참고하세요.
