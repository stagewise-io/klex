Klex Bot은 연결된 컴퓨터에서 파일을 다루고 명령을 실행하며, 데스크톱을 사용할 수 있으면 그래픽 앱도 사용할 수 있습니다. Bot은 두뇌이고 컴퓨터는 Bot이 쓰는 도구입니다. 하나의 Bot이 여러 컴퓨터를 사용할 수 있고, 하나의 컴퓨터를 여러 Bot에 할당할 수 있습니다.

Klex Cloud에서 관리형 컴퓨터를 선택하거나 MCP 서버 `@klex/machine`으로 내 컴퓨터를 연결하세요. Bot이 사용할 수 있는 도구는 컴퓨터와 그 구성에 따라 달라집니다.

<a id="before-you-connect"></a>

## 연결하기 전에

컴퓨터를 연결하면 Bot에 상당한 접근 권한이 부여됩니다. `@klex/machine`은 실행 중인 운영체제 사용자의 권한으로 파일을 읽고 변경하며 shell 명령을 실행할 수 있습니다. 작업 디렉터리는 샌드박스가 아닙니다. 절대 경로에도 접근할 수 있습니다. 데스크톱은 해당 사용자가 보고 사용할 수 있는 모든 것을 노출할 수 있습니다.

가능하면 권한이 제한된 전용 계정이나 격리된 컴퓨터를 사용하세요. 불필요한 자격 증명과 민감한 데이터를 제거하고 신뢰하는 Bot과 사람에게만 접근을 허용하세요. 중요한 작업은 별도로 검토하세요. [제어와 제한](/ko/bot/guides/control-and-limits)을 참조하세요.

<a id="use-a-managed-computer"></a>

## 관리형 컴퓨터 사용하기

Bot의 **Computers** 섹션에서 **Add computer**를 선택한 다음 **Set up a computer**를 선택하세요. **Cloud computer**를 선택하고 크기와 인터넷 접근 설정을 고른 뒤 가격을 확인하고 **Create computer**를 선택하세요. Cloud에서 상태와 연결 오류를 확인하세요. 할당만으로 컴퓨터의 연결이 보장되지는 않습니다.

관리형 컴퓨터는 파일 및 shell 도구뿐 아니라 그래픽 작업을 위한 데스크톱도 제공할 수 있습니다. 화면을 사용할 수 있으면 Cloud에서 볼 수 있습니다. 관리자가 제어권을 가져온 후 Bot에 다시 돌려줄 수 있습니다. 사람이 제어하는 동안 Bot의 데스크톱 입력은 차단됩니다. 화면과 도구의 이용 여부는 컴퓨터가 사용 가능하고 데스크톱 지원이 활성화되어 있는지에 달려 있습니다.

<a id="connect-your-own-computer-to-cloud"></a>

## 내 컴퓨터를 Cloud에 연결하기

컴퓨터에 Node.js 24 이상이 필요합니다. 조직 관리자는 Cloud에서 컴퓨터를 설정하고 등록된 Bot에 할당할 수 있습니다.

1. Cloud에서 Bot의 **Computers** 섹션을 열고 **Add computer**, **Set up a computer** 순으로 선택하세요.
2. **Your own computer**를 선택하고 설정 안내를 따르세요. Cloud에서 설치 및 등록 명령을 제공합니다. 등록 코드는 비밀로 취급하고 채팅으로 공유하거나 저장소에 커밋하지 마세요.
3. 연결할 컴퓨터에서 명령을 실행하세요. 등록하면 machine 프로세스가 시작되므로 계속 실행해 두세요.
4. 컴퓨터가 연결되고 Bot에 할당되었는지 확인하세요. 할당되지 않았다면 Bot의 **Computers** 섹션에서 추가하세요. 같은 컴퓨터를 다른 Bot에도 각각 할당할 수 있습니다.

프로세스는 Cloud로 나가는 연결을 만듭니다. 프로세스가 중지되면 컴퓨터는 오프라인으로 표시됩니다. 등록만으로 백그라운드 서비스가 설치되지는 않습니다. 터미널을 닫거나 컴퓨터를 재시작하면 프로세스가 중지됩니다. 등록 후 같은 운영체제 사용자로 `klex-machine`을 실행하면 저장된 ID로 다시 시작할 수 있습니다. 기본값이 `~/.klex-machine`인 ID 디렉터리는 비공개로 유지하세요.

내 컴퓨터에서도 호환되는 데스크톱을 사용할 수 있습니다. macOS에서는 로그인된 세션과 화면 기록 및 손쉬운 사용 권한이 필요합니다. Windows에서는 로그인된 대화형 세션이 필요합니다. Linux의 데스크톱 지원은 작동하는 디스플레이와 필요한 데스크톱 도구에 따라 달라집니다. 데스크톱이 없는 컴퓨터에서도 파일 및 shell 도구를 제공할 수 있습니다.

<a id="keep-a-linux-computer-connected"></a>

### Linux 컴퓨터의 연결 유지하기

Linux 관리자는 부팅 시 `klex-machine`을 시작하고 실패 시 재시작하는 systemd 서비스를 구성할 수 있습니다. 서비스는 의도한 비특권 사용자로 실행하고 그 사용자의 기존 machine ID를 사용해야 합니다. 백그라운드 서비스만으로는 데스크톱 세션이 제공되지 않습니다.

서비스를 활성화하기 전에 검토하세요. ID 디렉터리를 보호하고 특별한 이유가 없다면 서비스를 root로 실행하지 마세요.

<a id="connect-locally-without-cloud"></a>

## Cloud 없이 로컬로 연결하기

같은 컴퓨터의 독립형 Bot을 위해 서버를 로컬 모드로 실행하세요.

```sh
# npm 또는 pnpm으로 한 번 설치합니다. Node.js 24 이상이 필요합니다.
npm install -g @klex/machine
klex-machine serve --mode local --cwd /path/to/workspace --port 3123
```

Bot의 MCP 서버 설정에 로컬 서버 URL `http://127.0.0.1:3123/mcp`를 추가하세요. Bot이 사용하는 동안 프로세스를 계속 실행하세요.

로컬 모드에는 인증이 없고 기본적으로 loopback 인터페이스를 사용합니다. 리스너를 네트워크에 노출하지 마세요. 접근할 수 있는 사람은 누구나 운영체제 사용자의 권한으로 서버를 사용할 수 있습니다. `--cwd`는 시작 디렉터리를 변경할 뿐 접근 경계를 제한하지 않습니다.

<a id="disconnect-a-computer"></a>

## 컴퓨터 연결 해제하기

Cloud에서 Bot의 컴퓨터 연결에 있는 **Disconnect**를 사용하면 해당 Bot의 할당을 취소할 수 있습니다. 컴퓨터는 조직에 남고 다른 할당된 Bot은 계속 접근할 수 있습니다. 내 컴퓨터의 machine 프로세스를 통한 접근을 중지하려면 `klex-machine`을 중지하고 Cloud 할당 및 로컬 자격 증명도 검토하세요.
