Klex는 Klex 봇을 만들고 실행하기 위한 오픈 소스 셀프 호스팅 시스템입니다. 봇은 사람 및 다른 에이전트와 협업할 수 있는 AI 에이전트입니다. Klex는 [stagewise](https://stagewise.io)가 개발했으며 Apache-2.0 라이선스로 제공됩니다.

<GithubInfo owner="stagewise-io" repo="klex" />

각 봇은 고유한 정체성과 메모리를 가집니다. 봇의 자체 환경은 봇의 실행을 유지하고 메모리를 관리합니다. 봇은 [MCP](/bot/concepts/mcp)로 연결된 컴퓨터와 앱에서 작업합니다. 대부분의 MCP 연결에서 봇은 봇별로 권한이 설정된 전용 계정이나 정체성을 통해 활동합니다.

## 시작하기

- [봇 만들기](/bot/quickstart): 권장되는 클라우드 호스팅 설정부터 시작합니다.
- [Klex 봇의 작동 방식](/bot/concepts/how-bots-work): 봇의 환경, 메모리, 연결에 대해 알아봅니다.
- [연결](/bot/concepts/brain-and-computers): 컴퓨터와 앱을 선택하고 봇의 접근을 관리합니다.
- [자주 묻는 질문](/bot/faq): 일반적인 질문에 대한 답변을 확인합니다.

<a id="klex-클라우드"></a>

## 호스팅 방식 선택

Klex는 Klex Cloud에서 봇을 호스팅하는 방식을 권장합니다. 자체 환경에서 실행하고 Cloud 등록 여부를 선택할 수도 있습니다. 독립 실행에는 제공되는 기능이 더 적습니다. [클라우드 호스팅과 셀프 호스팅](/cloud/hosted-vs-local)에서 옵션을 비교하세요.

## 검토와 제어

대시보드에서 봇의 활동을 확인하고 채팅할 수 있습니다. MCP 서버를 연결하거나 연결을 해제하고, 연결된 앱에서 봇 계정의 권한을 설정할 수도 있습니다. [봇 활동 확인](/bot/guides/observability)과 [제어 및 제한](/bot/guides/control-and-limits)을 참고하세요.
