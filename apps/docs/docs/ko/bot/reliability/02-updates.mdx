Klex를 업데이트할 때 일반적으로 새 Bot을 만들 필요는 없습니다. Bot의 설정, 채팅 및 기억은 해당 [데이터 디렉터리](/bot/concepts/data-directory)와 연결됩니다.

## Bot 업데이트 및 보호

<Tabs syncKey="hosting" hash={false}>
<Tab title="클라우드 호스팅">

Klex Cloud는 클라우드 호스팅 Bot의 런타임을 관리합니다. 변경 후 대시보드에서 Bot을 열어 상태와 활동을 확인하세요. 클라우드 데이터에 대한 내용은 [데이터 및 개인정보 보호](/cloud/data-privacy)를 참조하세요.

</Tab>
<Tab title="셀프 호스팅">

<a id="update-a-self-hosted-installation"></a>

업데이트 전에 릴리스 노트에서 해당 버전의 지침을 확인하세요. 업데이트 후에는 Bot이 시작되는지, 연결이 작동하는지, 중요한 워크플로가 여전히 예상대로 수행되는지 확인하세요. Klex는 시작 시 지원되는 로컬 데이터를 확인하고 필요한 경우 마이그레이션합니다.

설치 관리자로 관리되는 설치의 경우 대화형 앱에서 사용 가능한 업데이트를 제공할 수 있습니다. 업데이트 배너에서 `u`를 누르면 설치하고 재시작합니다. 활성 세션이 있으면 앱이 중단을 경고하고 `u`를 다시 누르도록 요청합니다.

자동 업데이트는 기본적으로 꺼져 있습니다. 관리되는 설치에서 활성화하려면 `--auto-update`로 Klex를 시작하거나 `KLEX_AUTO_UPDATE=1`을 설정하세요. `--no-auto-update`는 환경 변수 설정보다 우선하여 자동 업데이트를 끕니다. 대화형 및 헤드리스 모드에서 사용할 수 있으며, 다른 설치 유형은 이 업데이트 프로그램을 사용하지 않습니다.

Klex는 Bot을 시작하기 전과 실행 중에 주기적으로 업데이트를 확인합니다. 실행 중 업데이트를 설치하면 새 작업을 일시 중지하고 현재 작업이 끝나기를 기다린 후 재시작합니다. 작업이 진행 중인 상태에서 기다리는 시간은 최대 10분이며, 실시간 통화가 진행 중이면 타이머가 일시 중지됩니다. 작업이 제시간에 끝나지 않으면 중단될 수 있습니다. 모든 작업이 완료되었다고 가정하지 말고 업데이트 후 로그와 Bot을 확인하세요.

<a id="protect-self-hosted-data"></a>

### 데이터 백업

수동 업데이트 전에 [셀프 호스팅 Bot을 중지](/bot/guides/control-and-limits#stop-a-bot)하고 데이터 디렉터리를 안전하게 백업하세요. 자동 업데이트가 꺼져 있다면 설치 관리자로 관리되는 대화형 설치를 다시 시작하고 업데이트 배너를 사용하세요. 자동 업데이트를 켠 경우에는 대신 Bot이 중지된 상태에서 정기적으로 백업하도록 계획하세요. 디렉터리에 민감한 정보가 포함될 수 있으므로 백업에 대한 접근을 제한하고 조직의 백업 및 복구 절차를 따르세요.

호환성을 확인하지 않았다면 업데이트된 데이터 디렉터리를 이전 Klex 버전으로 열지 마세요. 업데이트에 실패하면 보고된 오류를 조사하고 Bot 데이터를 변경하거나 삭제하기 전에 릴리스 노트 또는 Klex 지원팀에 문의하세요.
