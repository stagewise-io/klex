자체 호스팅 Klex Cloud는 Enterprise 고객만 사용할 수 있습니다. 배포 요구 사항과 이용 가능 여부는 Klex에 문의하세요.

Cloud를 자체 호스팅하는 것은 개별 Bot을 자신의 환경에서 실행하는 것과 다릅니다. 자체 호스팅 Bot을 Klex Cloud에 등록할 수 있지만, 등록은 기술적 필수 조건이 아닙니다. Bot 호스팅 옵션은 [호스팅과 자체 호스팅](/ko/cloud/hosted-vs-local)을 참고하세요.
