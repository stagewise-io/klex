[**Klex Cloud**](https://cloud.klex.bot)는 Klex Bot을 호스팅하고 관리용 대시보드를 제공합니다. 자체 호스팅 Bot을 등록할 수도 있습니다. Bot에 필요한 앱과 서비스를 연결하고 해당 서비스에서 계정과 권한을 설정하세요.

<Panel title="알아두기">
Klex Cloud는 완전히 선택 사항입니다. Cloud 없이 Klex Bot을 실행하고 자체 MCP 서버를 연결할 수 있습니다.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Cloud로 Klex Bot 설정하기

Cloud 설정 마법사에서 Cloud 호스팅 Bot을 만들거나 자체 호스팅 Bot을 설정할 수 있습니다. 마법사가 Bot과 모델 설정을 안내합니다. 설정 후 앱과 서비스를 연결할 수 있습니다.

[빠른 시작](/ko/bot/quickstart)을 따라 시작하세요.

## Enterprise와 신뢰

Enterprise 고객에게는 자체 시설에서 호스팅할 수 있는 Cloud 서비스 버전을 제공합니다. 규정 준수 정보는 [Trust Center](https://trust.stagewise.io)를 확인하세요.
