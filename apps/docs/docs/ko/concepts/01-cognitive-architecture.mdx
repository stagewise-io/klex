단일 Klex 봇은 단일 정체성과 하나의 의식 인스턴스로 작용하며, 멀티태스킹 양에 제한이 있습니다. 하지만 이것이 봇이 단일 내부 대화로 구성된다는 것을 의미하지는 않습니다.

오히려, Klex 봇의 아키텍처는 [글로벌 작업 공간 이론(GWT)](https://en.wikipedia.org/wiki/Global_workspace_theory)이 인간 뇌의 작동 방식을 구상하는 것과 대략적으로 유사한 방식으로 병렬화를 사용합니다.

## 기술적 기반

단일 Klex 봇은 동시에 작동하는 가변 수의 **세션**을 가집니다. 각 세션은 LLM 에이전트와 내부 환경 간의 대화이며, 자동 컨텍스트 압축 덕분에 임의로 긴 시간 동안 작동할 수 있습니다. 열려 있는 세션 중 하나만 환경에 접근할 수 있고 외부 세계와 상호작용하여 행동을 표현할 수 있습니다(GWT의 "조명된 메인 무대").

다른 세션은 다른 목적을 수행합니다. 예를 들어 수신 신호 필터링이나 기억 업데이트 및 통합 등입니다. 이들은 메인 세션과 독립적으로 작동하지만, 컨텍스트를 전달하여 메인 세션에 영향을 줄 수 있습니다.

### 메인 세션

메인 세션은 봇의 실제 행동과 동작을 나타냅니다. 이 세션만 MCP에 접근할 수 있어 환경에 대한 연결과 상호작용할 수 있습니다. 하지만 기억 생성이나 통합과 같은 작업은 처리하지 않으며, 외부 세계의 수신 이벤트나 알림이나 할 일과 같은 내부 트리거에 기반한 실제 작업에 순수하게 집중할 수 있습니다.

### 유틸리티 세션

유틸리티 세션은 외부 세계에 접근할 수 없지만 봇의 데이터 디렉토리와 상호작용할 수 있습니다. 기존 세션을 분석하여 새 기억을 구축하고, 더 이상 사용되지 않는 기억을 삭제하고, 스킬(절차적 기억)을 미세 조정하고, 봇의 경험을 기억 내 엔티티에 연결하는 등의 작업을 처리합니다.

### 갓 세션

갓 세션은 외부 세계에 대한 접근이 제한된 전용 세션이며 관리 API를 통해서만 사용할 수 있습니다. 전용 [갓 메시지](/concepts/god-messages) 외에는 외부 세계로부터의 입력을 받지 않으며, 봇에게 [영혼](/concepts/soul)을 생성하거나 업데이트하도록 명령하는 것과 같이 상승된 권한이 필요한 관리 작업을 수행하는 것이 목적입니다.
