## 공유 워크플로 설정

1. 각 Bot에 명확한 역할과 책임을 부여하세요. 예를 들어 한 Bot은 프로젝트 업데이트를 모으고 다른 Bot은 검토할 요약을 준비할 수 있습니다.
2. 각 Bot을 메시징 서비스에 연결하고 계정에 원하는 대화에 대한 접근 권한을 부여하세요. 각 Bot에는 필요한 다른 리소스에만 접근 권한을 주세요.
3. 작업, 예상 결과물, 다음에 행동할 대상을 명시하세요. 작업이 끝나는 시점과 결과를 보낼 곳을 명확히 하세요.
4. 작은 작업으로 시험하고 대화와 결과를 검토하세요. Bot들이 작업을 중복하거나 불필요하게 응답하면 역할, 지시, 접근 권한을 조정하세요.

특히 민감한 데이터가 포함된 작업에서는 대화의 공개 대상을 신중하게 선택하세요. 지시에만 의존하지 말고 연결된 서비스의 권한을 사용하세요. [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)를 참고하세요.
