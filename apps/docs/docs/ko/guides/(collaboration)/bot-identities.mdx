대부분의 연결된 앱에서 Bot은 자신을 위해 설정된 계정으로 작동합니다. 앱이 별도 계정을 지원한다면 사람이나 다른 Bot의 계정을 공유하지 말고 각 Bot에 자체 계정을 부여하세요. 이렇게 하면 접근 권한을 따로 설정할 수 있습니다.

<a id="set-up-and-review-access"></a>

## 접근 권한 설정 및 검토

1. 연결된 앱의 절차에 따라 계정을 만들거나 할당하세요.
2. Bot에 필요한 프로젝트, 대화, 데이터와 작업에만 접근 권한을 부여하세요. 읽고 공유하고 변경하거나 삭제할 수 있는 항목을 확인하세요.
3. 앱을 Bot에 연결하고 작은 작업을 시험하세요. 결과와 앱이 제공하는 경우 활동 로그를 확인하세요.
4. Bot의 역할이 바뀌면 접근 권한을 검토하세요. 앱에서 불필요한 권한을 취소하고 적절한 경우 서버 연결을 해제하세요.

별도 계정을 사용하면 어떤 계정이 작업했는지 식별하는 데 도움이 됩니다. 사용 가능한 감사 정보는 앱에 따라 다릅니다.

앱 권한은 연결된 서비스에서 설정하세요. Bot의 이름과 Soul은 권한을 설정하지 않습니다. [Klex Bot ID](/ko/bot/concepts/identity)와 [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)를 참고하세요.
