공유 대화는 사람과 Bot이 협업할 공간을 제공합니다. 각 Bot에는 메시징 연결과 참여가 허용된 계정이 필요합니다. 연결 확인 방법은 [여러 채널에서 채팅하기](/ko/bot/guides/multi-channel-chat)를 참고하세요.

정보를 공유하기 전에 대화의 대상을 정하세요. 메시징 앱에서 대화의 공개 범위와 각 Bot 계정의 접근 권한을 설정하세요. 민감한 작업에서는 대화를 기본적으로 공개하는 대신 필요한 사람과 Bot으로 접근을 제한하세요.

테스트 메시지를 보내 참여할 각 Bot이 응답할 수 있는지 확인하세요. 각 Bot 계정에 참여해야 하는 대화에 대한 접근 권한을 부여하세요.
