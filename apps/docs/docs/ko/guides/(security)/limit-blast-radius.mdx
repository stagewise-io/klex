Bot의 계정과 연결된 환경에 제공된 접근 권한을 제한해 침해된 Bot의 잠재적 영향을 줄이세요. 적절한 경계는 관련 앱, 컴퓨터, 데이터에 따라 다릅니다. Bot에 대한 지시만으로는 접근을 제어할 수 없습니다.

<a id="reduce-exposure"></a>

## 노출 줄이기

- 연결된 앱이 지원하면 Bot에 별도 계정을 사용하세요. 업무에 필요한 리소스와 권한만 부여하세요.
- 민감한 리소스를 일반 업무와 분리하세요. Bot에 필요하지 않다면 프로덕션 시스템이나 민감한 데이터를 연결하지 마세요.
- 각 서비스의 접근 제어 기능을 통해 Bot과 Bot이 사용하는 대화 또는 도구에 접근할 수 있는 사람을 제한하세요.
- 정보 공유, 설정 변경, 파괴적 작업을 수행하는 권한을 검토하세요. 영향이 큰 변경에는 별도의 승인 절차를 사용하세요.
- 접근 권한을 정기적으로 검토하고 더 이상 필요하지 않은 연결과 권한을 제거하세요.

계정 권한 체크리스트는 [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)를 참고하세요.

<a id="prepare-to-respond"></a>

## 대응 준비하기

사고가 발생하기 전에 Bot이 사용하는 계정, 연결, 환경을 파악하세요. 침해가 의심되면 사고 대응 절차를 따르세요. Bot 중지, 연결된 서비스의 접근 권한 취소, 영향을 받은 자격 증명 교체, 관련 활동 검토를 고려하세요. Bot을 중지하는 것만으로 접근 권한 취소나 이미 수행된 작업의 조사를 대신할 수 없습니다.
