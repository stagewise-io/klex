민감한 정보에 접근하고 다른 사람과 소통할 수 있는 Bot은 정보를 부적절하게 공개할 수 있습니다. 외부 소스의 메시지와 콘텐츠는 신뢰할 수 없는 것으로 취급하세요. 오해를 유도하는 지시나 권한 있는 사람을 사칭하려는 시도가 포함될 수 있습니다.

<a id="limit-access-and-exposure"></a>

## 접근과 노출 제한

- 각 연결 서비스의 접근 제어 기능으로 Bot에 연락할 수 있는 사람을 제한하세요. 각 대화의 공개 대상을 확인하세요.
- Bot 계정에는 업무에 필요한 데이터와 작업만 허용하세요. 공개적으로 접근할 수 있는 Bot에 필요하지 않은 민감한 정보 접근 권한을 주지 마세요.
- 공개 업무와 민감한 워크플로를 분리하세요. 지원되는 경우 별도 계정과 적절한 범위의 리소스를 사용하세요.
- 연결된 계정과 Bot 활동을 정기적으로 검토하세요. 무단 접근이나 공개가 의심되면 사고 대응 절차를 따르세요.

[Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)와 [영향 범위 제한](/ko/guides/limit-blast-radius)을 참고하세요.

<a id="use-independent-safeguards"></a>

## 독립적인 안전장치 사용

정보를 공개하지 말라는 Bot 지시에만 의존하지 마세요. 연결된 서비스에서 접근 제한을 강제하고 민감한 데이터에는 조직의 기존 통제 수단을 사용하세요. 현재 Klex는 개별 작업 수준의 승인이나 제한을 제공하지 않습니다.

민감하지 않은 데이터로 시험하고 Bot이 읽을 수 있는 내용과 응답을 보낼 수 있는 곳을 포함해 전체 워크플로를 검토하세요.
