회사 핸드북은 Bot에게 조직에 관한 일관된 맥락을 제공할 수 있습니다. 고객, 용어, 업무에 필요한 원칙 등을 설명할 수 있습니다.

핸드북은 문서나 내부 웹사이트일 수 있습니다. 단, 이를 필요로 하는 각 Bot에 해당 소스를 읽을 수 있는 연결과 접근 권한이 있는 계정이 있어야 합니다. 사용 가능한 기능은 MCP 서버와 연결된 서비스에 따라 다릅니다.

<a id="share-it-safely"></a>

## 안전하게 공유하기

- 각 Bot에 필요한 자료에만 접근 권한을 부여하세요. 민감한 절차와 자격 증명은 적절히 접근이 제한된 소스에 보관하세요.
- 담당자와 검토 날짜를 적어 내용을 정확하게 유지하세요. 오래된 지침은 삭제하세요.
- Bot에게 작은 작업에 핸드북을 사용하도록 요청한 뒤 결과와 사용한 소스를 검토하세요.

연결된 서비스의 권한을 설정하고 중요한 결과를 가져오는 작업은 독립적으로 검토하세요. [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage)를 참고하세요.
