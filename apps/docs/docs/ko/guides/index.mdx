이 가이드를 활용해 Klex Bot에 필요한 회사 맥락, 별도 앱 계정, 협업 공간을 제공하고 접근 권한을 관리하세요.

<a id="align-on-company-context"></a>

## 회사 맥락 공유

[회사 핸드북을 만들고](/ko/guides/company-handbook) 각 Bot에 필요한 자료에 대한 접근 권한을 부여하세요.

<a id="make-klex-bots-work-together"></a>

## Klex Bot 함께 일하게 하기

- 앱이 지원하는 경우 [별도 ID를 만들어](/ko/guides/bot-identities) 각 Bot의 접근 권한을 따로 관리하세요.
- [공유 메시지 보드를 사용해](/ko/guides/shared-messaging-boards) 사람과 Bot이 협업하세요.
- 명확한 역할과 인계로 [Klex Bot이 함께 일하게 하세요](/ko/guides/bot-collaboration).

<a id="operate-klex-bots-securely"></a>

## Klex Bot 안전하게 운영하기

- [Klex Bot 안전하게 사용하기](/ko/guides/secure-bot-usage): 앱 권한을 제한하고 검토합니다.
- [정보 도난 방지](/ko/guides/prevent-information-theft): 무단 접근과 공개의 위험을 줄입니다.
- [지원 Bot의 비밀 보호](/ko/guides/support-bot-secrets): 자격 증명과 민감한 데이터 접근을 제한합니다.
- [영향 범위 제한](/ko/guides/limit-blast-radius): 침해된 Bot의 잠재적 영향을 줄입니다.
- [중요한 작업을 Klex Bot에 맡기기](/ko/guides/trust-critical-operations): 영향이 큰 작업에 독립적인 안전장치를 사용합니다.
