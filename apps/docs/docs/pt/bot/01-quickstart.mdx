Crie um bot Klex para trabalhar consigo. O Klex recomenda o alojamento no Cloud para a maioria dos utilizadores; também pode executar um bot no seu computador.

## Configuração alojada no Cloud

1. Inicie sessão no [Klex Cloud](https://cloud.klex.bot) e selecione **New bot**.
2. Atribua um trabalho ao bot ou escolha um dos sugeridos, e personalize o seu nome e aspeto.
3. Selecione **Create bot in cloud**.
4. Reveja os seus traços de caráter e avance para **Models & Computer**.
5. Ligue um fornecedor de IA e escolha os modelos que o bot deve usar, ou importe a configuração de modelos de outro bot. Termine a configuração quando o bot estabelecer ligação.
6. Abra o chat do bot para começar.

Pode ligar as aplicações e os computadores de que o bot precisa para trabalhar. Os servidores MCP compatíveis também podem enviar mensagens e eventos das aplicações que levem o bot a trabalhar. Consulte [MCP e bots Klex](/bot/concepts/mcp) para mais detalhes.

## Configuração auto-hospedada

1. Inicie sessão no [Klex Cloud](https://cloud.klex.bot), selecione **New bot** e escolha o trabalho e o aspeto do bot.
2. Selecione **Or run it on your own computer** e depois **Set up on your computer**. Copie o comando completo fornecido pelo Klex Cloud, cole-o num terminal do computador onde o bot será executado e execute-o.
3. Siga as instruções para configurar o caráter e os modelos do bot.

Mantenha o bot em execução no seu computador para que possa trabalhar. Para o reiniciar, execute o seguinte comando num terminal e selecione o bot:

```sh
klex
```

### Executar sem o Cloud

A inscrição no Cloud é opcional. Para configurar um bot diretamente na aplicação Klex, siga o [guia de configuração independente](/bot/guides/standalone-setup). O guia também explica como [criar um bot sem o menu de seleção](/bot/guides/standalone-setup#create-a-bot-without-the-picker).
