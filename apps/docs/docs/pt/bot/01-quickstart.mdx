O Klex recomenda um bot alojado na nuvem para a maioria dos utilizadores. Também pode executar um bot no seu computador, com ou sem inscrição no Klex Cloud. Precisa de acesso a um fornecedor de modelos; para a configuração na nuvem precisa ainda de uma conta Klex Cloud.

<a id="criar-o-seu-bot"></a>

## Criar um bot alojado na nuvem

1. Inicie sessão no [Klex Cloud](https://cloud.klex.bot) e comece a criar um bot.
2. Escolha o alojamento na nuvem e siga os passos para dar um nome ao bot, definir a sua [alma](/bot/concepts/soul) e configurar fornecedores e modelos.
3. Ligue as aplicações ou computadores de que o bot precisa. Consulte [Ligações](/bot/concepts/brain-and-computers) para gerir o seu acesso.

Envie uma mensagem ao bot numa aplicação ligada para verificar se responde. Pode consultar a sua atividade no painel Cloud.

<a id="instalação"></a>

## Instalar o Klex para auto-hospedagem

Para executar o bot no seu computador, instale o Klex num terminal:

  <Tab title="macOS">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Linux">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>

### Configuração com apoio do Cloud

Inicie a configuração de um bot auto-hospedado no Klex Cloud e siga as instruções de inscrição. O bot é executado no seu computador; o Cloud fornece uma interface de administração.

### Configuração independente

Para executar o bot sem o inscrever no Cloud, inicie a aplicação interativa:

```sh
klex --no-cloud
```

1. Prima `a` para criar um bot e introduza o seu nome.
2. Em **Settings → Providers & Endpoints**, configure um fornecedor de modelos. Em **Model Selection**, selecione um modelo válido para chat.
3. Abra **Settings → Soul** e crie uma alma que descreva o caráter e o trabalho do bot.
4. Em **Settings → MCP Servers**, ligue os servidores de que o bot precisa. Configure as permissões das suas contas nas aplicações ligadas.

Para receber eventos de um canal externo, ligue um servidor MCP que suporte as atualizações de recursos correspondentes ou a [extensão de notificações push](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) do Klex.

## Criar um bot auto-hospedado sem o menu de seleção

Para o inscrever no Cloud, obtenha um token de inscrição do Klex Cloud. Forneça-o ao processo como `KLEX_CLOUD_ENROLLMENT_TOKEN` através do procedimento de gestão de segredos aprovado. Depois execute:

```sh
klex --create-bot
```

Trate o token como um segredo: não o inclua em scripts, argumentos da linha de comandos ou no histórico do terminal e limite o acesso ao ambiente do processo. Acrescente `--headless` para executar o bot sem interface de terminal.

Para um bot independente, indique antes um nome:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Configure o fornecedor, o modelo e as ligações antes de usar o bot. `--create-bot` não pode ser combinado com `--data-dir` nem com `KLEX_DATA_DIR`: estas opções indicam um bot existente.

Se a inscrição no Cloud falhar, o diretório do novo bot é mantido e o seu caminho é apresentado. Forneça o token em `KLEX_CLOUD_ENROLLMENT_TOKEN` e tente novamente com `klex --data-dir PATH`. Substitua `PATH` pelo diretório apresentado, em vez de criar outro bot.
