Um Agent Skill é um conjunto reutilizável de instruções para uma tarefa recorrente. Por exemplo, um skill pode descrever como preparar uma atualização sobre o estado de um projeto. A descrição indica quando as instruções se aplicam e o conteúdo explica o procedimento.

O Klex permite ao Bot descobrir os skills disponíveis e indica-lhe que carregue um skill adequado antes de agir. Um skill orienta o Bot: não garante um resultado específico nem substitui as permissões das contas.

<a id="where-skills-come-from"></a>

## De onde vêm os skills

Um Bot pode aprender skills a partir da sua atividade. Os skills também podem vir de outras fontes, como modelos. Cada Bot guarda os seus skills no seu próprio [diretório de dados](/bot/concepts/data-directory). Cada skill é identificado por um espaço de nomes e um nome, como `learning/project-status`.

Quando o Bot comprime o contexto ativo de uma conversa, pode analisar a atividade retirada e transformar as lições úteis em skills. A aprendizagem acontece em segundo plano e pode demorar; uma conversa não produz necessariamente um skill.

Cada skill é guardado num ficheiro `SKILL.md` em `skills/{namespace}/{name}/`. O ficheiro contém um nome, uma descrição e um corpo em Markdown.

<a id="review-and-manage-skills"></a>

## Rever e gerir os skills

A Admin API do Bot permite listar os skills, consultar o seu conteúdo, editá-los ou eliminá-los. Use `GET /v1/skills` para os listar e `GET /v1/skills/{namespace}/{name}` para ler um. O mesmo caminho suporta `PATCH` e `DELETE`.

Reveja a exatidão dos skills aprendidos. A aprendizagem pode atualizá-los ou eliminá-los ao longo do tempo, incluindo os que uma pessoa administradora editou. Uma edição não impede alterações posteriores a um skill aprendido.
