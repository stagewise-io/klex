God Messages são diretrizes administrativas processadas em uma sessão dedicada, separada das conversas habituais do Bot. Elas podem solicitar alterações na [alma](/bot/concepts/soul) do Bot.

No aplicativo Klex auto-hospedado, abra **Settings → God Messages** para escrever e enviar uma mensagem. Por exemplo, uma pessoa administradora pode pedir ao Bot que atualize sua alma para refletir uma mudança de função.

God Messages não são a única forma de gerenciar uma alma: a tela **Soul** nas configurações e a Admin API também permitem criá-la ou atualizá-la a partir de instruções.
