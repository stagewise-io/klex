Você pode distribuir o trabalho independente entre vários Bots. Por exemplo, peça a um Bot para revisar as issues abertas de um projeto e a outro para resumir as atualizações de um projeto diferente. Dê a cada Bot sua própria tarefa, as conexões e permissões necessárias e um local claro para comunicar o resultado.

<a id="coordinate-and-review"></a>

## Coordenar e revisar

- Divida o trabalho para que os Bots não editem o mesmo recurso sem saber. Se as tarefas se sobrepuserem, defina quem é responsável por cada alteração e como os conflitos serão resolvidos.
- Use uma conversa compartilhada para as transferências, se as contas de mensagens dos Bots tiverem acesso. Consulte [Como fazer Klex Bots trabalharem juntos](/pt/guides/bot-collaboration).
- Comece com um teste pequeno. Revise os resultados, o trabalho duplicado, os acessos e o uso do provedor de modelos antes de aumentar a carga de trabalho.
