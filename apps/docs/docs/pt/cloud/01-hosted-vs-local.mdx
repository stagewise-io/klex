> **Posso executar um Bot Klex sem o Klex Cloud?**

Sim. Um Bot Klex auto-hospedado pode funcionar sem inscrição no Cloud. A Klex recomenda um Bot hospedado no Cloud para a maioria dos usuários e recomenda inscrever um Bot auto-hospedado no Klex Cloud para uma gestão mais completa.

<a id="choose-how-to-host-the-bot"></a>

## Escolher como hospedar o Bot

<a id="klex-cloud-hosted-bot"></a>

### Bot hospedado no Klex Cloud

A Klex executa o Bot em seu ambiente hospedado. As conversas e a memória do Bot são armazenadas no diretório de dados dele nesse ambiente. Você pode usar o painel do Cloud para ver atividades e gerenciar MCPs conectados.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Bot auto-hospedado inscrito no Klex Cloud

Você executa o Bot em um ambiente que gerencia e pode inscrevê-lo no Klex Cloud. Isso dá mais controle sobre onde o Bot opera, mantendo a gestão pelo Cloud. As conversas e a memória permanecem no diretório de dados local do Bot. O painel do Cloud oferece uma interface e um proxy reverso para a Admin API do Bot.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Bot auto-hospedado sem inscrição no Cloud

A inscrição no Cloud não é uma exigência técnica para um Bot auto-hospedado. A Klex recomenda a inscrição porque a experiência independente é menos completa.

<a id="self-hosted-cloud"></a>

### Cloud auto-hospedado

A auto-hospedagem do serviço Klex Cloud está disponível apenas para clientes Enterprise.

<a id="manage-access-and-stop-a-bot"></a>

## Gerenciar acesso e parar um Bot

No painel do Cloud, você pode revisar a atividade do Bot e conectar ou desconectar MCPs. Para outros aplicativos e contas usados pelo Bot, configure as permissões nesses aplicativos ou contas. Para parar um Bot auto-hospedado, feche seu aplicativo. Para parar um Bot hospedado no Cloud, use **Stop** no painel do Cloud.
