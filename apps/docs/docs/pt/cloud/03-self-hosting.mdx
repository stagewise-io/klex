O Klex Cloud auto-hospedado está disponível apenas para clientes Enterprise. Entre em contato com a Klex para saber os requisitos de implantação e a disponibilidade.

Auto-hospedar o Cloud é diferente de executar um Bot individual no seu próprio ambiente. Um Bot auto-hospedado pode ser inscrito no Klex Cloud, mas a inscrição não é uma exigência técnica. Consulte [Hospedado ou auto-hospedado](/pt/cloud/hosted-vs-local) para conhecer as opções de hospedagem do Bot.
