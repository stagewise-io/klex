O [**Klex Cloud**](https://cloud.klex.bot) hospeda Klex Bots e oferece um painel para gerenciá-los. Você também pode registrar um Bot auto-hospedado. Conecte os aplicativos e serviços necessários ao Bot e configure suas contas e permissões nesses serviços.

<Panel title="Bom saber">
O Klex Cloud é totalmente opcional. Você pode executar Klex Bots sem ele e conectar seus próprios servidores MCP.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Configurar um Klex Bot com o Cloud

O assistente de configuração do Cloud permite criar um Bot hospedado no Cloud ou configurar um Bot auto-hospedado. Ele orienta a configuração do Bot e de seus modelos. Você pode conectar aplicativos e serviços após a configuração.

Siga o [guia de início rápido](/pt/bot/quickstart) para começar.
