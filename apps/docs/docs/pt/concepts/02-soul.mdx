---
title: A Alma do Bot
description: Controle como os bots Klex atuam e se comportam usando a sua alma.
---

A alma descreve o propósito, o carácter e o comportamento do bot. É armazenada no diretório de dados e carregada no contexto.

Crie ou atualize a alma na CLI em `Settings -> Soul`. Descreva o propósito, o carácter e o comportamento esperado. A API dedicada oferece `GET /v1/soul`, `POST /v1/soul` para criar e `PATCH /v1/soul` para atualizar. Uma atualização com instruções vazias otimiza a alma existente.

As sessões de chat apenas leem a alma e não a podem editar. Sem alma, o bot não executa inferência de chat.
