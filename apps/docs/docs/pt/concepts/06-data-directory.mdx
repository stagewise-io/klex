---
title: Diretório de dados
description: Os bots Klex armazenam todas as suas memórias, informações de personagem e configuração num único diretório.
---

O diretório de dados é o local onde cada bot armazena as suas memórias e configuração.

É apenas acessível à aplicação Klex, mas **não** ao próprio bot Klex.
Os bots Klex não têm acesso ao sistema de ficheiros e, em vez disso, obtêm acesso curado a partes da sua memória e outras informações.

Isto previne fugas de informação ou manipulação maliciosa destes ficheiros.
