Na maioria dos aplicativos conectados, um Bot age por meio de uma conta configurada para ele. Quando o aplicativo permite contas separadas, dê a cada Bot sua própria conta em vez de compartilhar a conta de uma pessoa ou de outro Bot. Assim, você pode configurar os acessos separadamente.

<a id="set-up-and-review-access"></a>

## Configurar e revisar o acesso

1. Crie ou atribua uma conta usando o processo do aplicativo conectado.
2. Conceda acesso apenas aos projetos, conversas, dados e ações necessários ao Bot. Verifique o que a conta pode ler, compartilhar, alterar ou excluir.
3. Conecte o aplicativo ao Bot e teste uma tarefa pequena. Verifique o resultado e, quando o aplicativo os fornecer, os registros de atividade.
4. Revise o acesso quando a função do Bot mudar. Revogue permissões desnecessárias no aplicativo e desconecte o servidor quando apropriado.

Uma conta distinta pode ajudar a identificar qual conta executou uma ação. Os detalhes de auditoria disponíveis dependem do aplicativo.

Configure as permissões no serviço conectado; o nome e a Soul do Bot não as definem. Consulte [Identidade de um Bot Klex](/pt/bot/concepts/identity) e [Usar Bots Klex com segurança](/pt/guides/secure-bot-usage).
