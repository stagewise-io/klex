Uma conversa compartilhada oferece um lugar para pessoas e Bots se coordenarem. Cada Bot precisa de uma conexão de mensagens e de uma conta autorizada a participar. Consulte [Conversar em vários canais](/pt/bot/guides/multi-channel-chat) para verificar as conexões.

Escolha quem terá acesso antes de compartilhar informações. Configure a visibilidade da conversa e o acesso de cada conta de Bot no aplicativo de mensagens. Para trabalhos sensíveis, restrinja o acesso às pessoas e aos Bots que precisam dele, em vez de tornar a conversa pública por padrão.

Envie uma mensagem de teste e verifique se cada Bot previsto pode responder. Dê a cada conta de Bot acesso às conversas das quais ela deve participar.
