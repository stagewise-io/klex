Создайте бота Klex, который будет работать вместе с вами. Для большинства пользователей Klex рекомендует размещение в Cloud, но вы также можете запустить бота на собственном компьютере.

## Настройка в Cloud

1. Войдите в [Klex Cloud](https://cloud.klex.bot) и выберите **New bot**.
2. Задайте боту работу или выберите предложенную, затем настройте его имя и внешний вид.
3. Выберите **Create bot in cloud**.
4. Проверьте черты характера и перейдите к **Models & Computer**.
5. Подключите поставщика ИИ и выберите модели для бота или импортируйте настройки моделей другого бота. Завершите настройку, когда бот подключится.
6. Откройте чат бота, чтобы начать работу.

Вы можете подключить приложения и компьютеры, необходимые боту для работы. Поддерживаемые MCP-серверы также могут доставлять сообщения и события приложений, которые побуждают бота к работе. Подробнее см. в разделе [MCP и боты Klex](/bot/concepts/mcp).

## Настройка на собственном компьютере

1. Войдите в [Klex Cloud](https://cloud.klex.bot), выберите **New bot**, затем задайте боту работу и внешний вид.
2. Выберите **Or run it on your own computer**, затем **Set up on your computer**. Скопируйте команду целиком из Klex Cloud, вставьте её в терминал на компьютере, где будет работать бот, и выполните.
3. Следуйте инструкциям, чтобы настроить характер и модели бота.

Чтобы бот мог работать, оставьте его запущенным на компьютере. Для повторного запуска выполните в терминале следующую команду и выберите бота:

```sh
klex
```

### Запуск без Cloud

Регистрация в Cloud необязательна. Чтобы настроить бота непосредственно в приложении Klex, следуйте [руководству по автономной настройке](/bot/guides/standalone-setup). В нём также описано, как [создать бота без меню выбора](/bot/guides/standalone-setup#create-a-bot-without-the-picker).
