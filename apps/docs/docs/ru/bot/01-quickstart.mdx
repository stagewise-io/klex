Для большинства пользователей Klex рекомендует облачное размещение бота. Также можно запустить бота на собственном компьютере с регистрацией в Klex Cloud или без неё. Вам понадобится доступ к поставщику моделей; для облачной настройки также нужна учётная запись Klex Cloud.

<a id="создание-вашего-бота"></a>

## Создание облачного бота

1. Войдите в [Klex Cloud](https://cloud.klex.bot) и начните создание бота.
2. Выберите облачное размещение и следуйте инструкциям: задайте имя бота, определите его [душу](/bot/concepts/soul), настройте поставщиков и модели.
3. Подключите приложения или компьютеры, необходимые боту. Информацию об управлении доступом см. в разделе [Подключения](/bot/concepts/brain-and-computers).

Отправьте боту сообщение в подключённом приложении, чтобы проверить ответ. Его активность можно просмотреть в панели Cloud.

<a id="установка"></a>

## Установка Klex для самостоятельного размещения

Чтобы запустить бота на собственном компьютере, установите Klex в терминале:

<Tabs param="install">
  <Tab title="macOS">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Linux">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Windows">`irm https://klex.bot/install.ps1 | iex`</Tab>
  <Tab title="WSL">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
</Tabs>

### Настройка с помощью Cloud

Начните настройку самостоятельно размещённого бота в Klex Cloud и следуйте инструкциям по регистрации. Бот работает на вашем компьютере; Cloud предоставляет интерфейс администрирования.

### Автономная настройка

Чтобы запустить бота без регистрации в Cloud, откройте интерактивное приложение:

```sh
klex --no-cloud
```

1. Нажмите `a`, чтобы создать бота, и введите его имя.
2. В **Settings → Providers & Endpoints** настройте поставщика моделей. В **Model Selection** выберите действительную модель для чата.
3. Откройте **Settings → Soul** и создайте душу, описывающую характер и работу бота.
4. В **Settings → MCP Servers** подключите необходимые боту серверы. Настройте права его учётных записей в подключённых приложениях.

Чтобы получать события из внешнего канала, подключите MCP-сервер, поддерживающий соответствующие обновления ресурсов или [расширение push-уведомлений](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) Klex.

## Создание самостоятельно размещённого бота без меню выбора

Для регистрации в Cloud получите токен регистрации Klex Cloud. Передайте его процессу как `KLEX_CLOUD_ENROLLMENT_TOKEN`, используя утверждённый способ управления секретами. Затем выполните:

```sh
klex --create-bot
```

Считайте токен секретом: не включайте его в скрипты, аргументы командной строки или историю терминала и ограничьте доступ к окружению процесса. Добавьте `--headless`, чтобы запустить бота без терминального интерфейса.

Для автономного бота вместо этого укажите имя:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Перед использованием бота настройте поставщика, модель и подключения. `--create-bot` нельзя сочетать с `--data-dir` или `KLEX_DATA_DIR`: эти параметры указывают на существующего бота.

Если регистрация в Cloud не удалась, каталог нового бота сохраняется, а путь к нему выводится на экран. Передайте токен в `KLEX_CLOUD_ENROLLMENT_TOKEN` и повторите попытку с помощью `klex --data-dir PATH`. Замените `PATH` показанным каталогом вместо создания ещё одного бота.
