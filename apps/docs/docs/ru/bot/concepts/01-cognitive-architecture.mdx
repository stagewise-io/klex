Бот Klex работает в среде, которая управляет его активными сессиями и [памятью](/bot/concepts/memory). Бот работает на внешних компьютерах и в приложениях, подключённых через [MCP](/bot/concepts/mcp).

## Обычная сессия

Обычная сессия имеет доступ к подключённым MCP-серверам. В ней бот обрабатывает входящие события и может работать в подключённых средах. Доступные действия зависят от подключений и их разрешений.

<a id="служебные-сессии"></a>
<a id="utility-sessions"></a>

## Отдельные задачи

Бот может использовать отдельные сессии для внутренних задач. Например, он может запросить консультацию по сложному вопросу и учесть её результат в своей работе.
