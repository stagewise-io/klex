Klex Bot работает во внешних средах, подключённых через MCP (Model Context Protocol). Сервер MCP может предоставлять доступ ко всему компьютеру или к приложению, например GitHub или Google Workspace. Компьютеры тоже подключаются через MCP.

Собственная среда Bot поддерживает его работу и управляет его памятью. Задачи он выполняет на подключённых компьютерах и в приложениях.

<a id="choose-what-to-connect"></a>

## Что подключить

- **Компьютеры** предоставляют подключённую среду, в которой Bot может работать.
- **Приложения** предоставляют доступ к своей среде через сервер MCP.

Klex предлагает ряд встроенных серверов MCP. Можно подключать и другие серверы MCP. Выбор сред зависит от задач, которые должен выполнять Bot.

<a id="manage-a-bots-access"></a>

## Управление доступом Bot

Подключите приложения и компьютеры, необходимые Bot для работы. Для большинства MCP он действует через собственную учётную запись или идентичность с разрешениями, настроенными для этого Bot.

<Tabs syncKey="hosting" hash={false}>
<Tab title="Облачный хостинг">

Откройте своего Bot в Klex Cloud. Управляйте подключениями приложений в разделе **Connectors**, а подключёнными компьютерами в разделе **Computers**. В разделе **Activity** также можно просмотреть его активность.

</Tab>
<Tab title="Собственный хостинг">

В приложении Klex управляйте подключениями серверов в разделе **Settings → MCP Servers**. Порядок действий описан в разделе [MCP и Klex Bots](/bot/concepts/mcp#add-a-remote-server-in-the-self-hosted-app). Локальную диагностику можно посмотреть в разделе **Settings → Logs**.

</Tab>
</Tabs>

Настройте разрешения учётных записей Bot и подключённых приложений непосредственно в этих учётных записях и приложениях. Подключение сервера и предоставление доступа учётной записи — отдельные решения. Проверяйте оба, определяя, к чему Bot может получить доступ и что он может делать.

Общий обзор см. в разделе [Как работают Klex Bots](/bot/concepts/how-bots-work). О хранении чатов и памяти см. в разделе [директория данных](/bot/concepts/data-directory).
