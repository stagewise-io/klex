Душа описывает личность, манеру общения, назначение и приоритеты бота. Она отличается от его [памяти](/bot/concepts/memory) и входит в контекст обычной сессии.

## Создание и обновление души

Отправьте инструкции через Admin API бота, чтобы создать или обновить душу. Для создания с нуля используйте `POST /v1/soul`, для обновления существующей души — `PATCH /v1/soul`, а для чтения — `GET /v1/soul`. Информацию о доступе и безопасности см. в разделе [Доступ к локальному Admin API](/bot/guides/observability#access-the-local-admin-api).

Для создания души используются настроенные модели чата; результат сохраняется после успешной генерации. Например, в инструкциях можно описать работу бота, предпочтительный тон и подход к принятию решений. Проверьте созданную душу и при необходимости обновите её. Сохраните душу, прежде чем отправлять боту новые задачи.

## Хранение и доступ

Душа хранится в [каталоге данных](/bot/concepts/data-directory) бота. Admin API бота может читать душу и создавать новую или обновлённую душу по инструкциям администратора. В обычной сессии нет инструмента для записи души.

## Если у бота нет души

Для выполнения обычных задач боту необходима непустая душа. Без неё он пропускает новые задачи и отбрасывает недавно добавленную историю сессии; пропущенные задачи не ставятся в очередь. Создайте душу, прежде чем отправлять новые данные.
