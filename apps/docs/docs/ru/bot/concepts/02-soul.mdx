---
title: Душа Бота
description: Управляйте действиями и поведением ботов Klex с помощью их души.
---

Душа кратко описывает назначение, характер и поведение бота. Она хранится в каталоге данных и загружается в контекст.

Создайте или обновите душу в CLI через `Settings -> Soul`, описав назначение, характер и ожидаемое поведение. Выделенный API предоставляет `GET /v1/soul`, `POST /v1/soul` для создания и `PATCH /v1/soul` для обновления. Обновление с пустыми инструкциями оптимизирует существующую душу.

Чат-сессии только читают душу и не могут её редактировать. Без души бот не выполняет вывод модели в чате.
