Душа описывает личность, манеру общения, работу и приоритеты бота. Она отличается от его [памяти](/bot/concepts/memory) и входит в контекст обычной сессии.

## Создание и обновление души

В самостоятельно размещённом приложении Klex откройте **Settings → Soul**. Здесь можно просмотреть сохранённую душу, создать или обновить её по инструкциям либо создать заново. Генерация использует настроенные модели чата и сохраняет успешно созданные результаты. Обычные сессии остаются на паузе, пока душа не сохранена.

Например, в инструкциях можно описать работу бота, предпочтительный тон и подход к принятию решений. Проверьте созданную душу и обновите её, если она не соответствует вашим ожиданиям.

Klex также поддерживает [God Messages](/bot/concepts/god-messages) для запроса изменений души. Это не единственный способ её создать или обновить.

## Хранение и доступ

Душа хранится в [каталоге данных](/bot/concepts/data-directory) бота. В Klex Admin API бота может читать душу и создавать новую или обновлённую душу по административным инструкциям. В обычной сессии нет инструмента для записи души.
