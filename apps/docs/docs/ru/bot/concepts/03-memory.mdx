Память помогает Klex Bot опираться на усвоенные знания и использовать контекст прошлой работы. Она объединяет **навыки**, включая изученные и заранее настроенные процедуры, с полезными знаниями из деятельности бота.

Бот может использовать навыки для привычных задач и вспоминать прошлый контекст, когда это полезно, например терминологию проекта или прежнее решение. Он может запросить воспоминание в фоновом режиме, а подходящий контекст может появиться и во время работы. Подробнее о процедурах для повторного использования см. в разделе [Agent Skills](/bot/concepts/agent-skills).

<a id="where-chats-and-memory-are-stored"></a>

## Где хранятся чаты и память?

Чаты и память хранятся в каталоге данных бота:

- У **бота, размещённого в Cloud**, каталог находится в среде хостинга.
- У **самостоятельно размещённого бота** каталог находится в локальной папке, используемой для данных бота.

Все данные ботов, размещённых в Cloud, включая память, шифруются при передаче и хранении.

## Просмотр чатов и навыков

Администраторы могут просматривать чаты и навыки через Admin API бота. Панель Klex Cloud служит фронтендом и обратным прокси для Admin API каждого бота. Подробнее о хранении см. в разделе [каталог данных](/bot/concepts/data-directory).
