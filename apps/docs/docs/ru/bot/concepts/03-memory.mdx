Память Klex Bot поддерживает **навыки и усвоенные знания** и может извлекать подходящий контекст из прошлой деятельности бота. Она управляется в собственной среде бота, вместе с активными сессиями, которые поддерживают его работу.

Бот может запросить воспоминание в фоновом режиме; подходящий контекст может появиться и без запроса. Воспоминания могут быть неполными или ошибочными, поэтому проверяйте важные сведения. Подсказка о контексте помогает направить поиск, но не является средством контроля доступа.

<a id="where-chats-and-memory-are-stored"></a>

## Где хранятся чаты и память?

Чаты и память хранятся в каталоге данных бота:

- У **бота, размещённого в Cloud**, каталог находится в среде хостинга.
- У **самостоятельно размещённого бота** каталог находится в локальной папке, используемой для данных бота.

Все данные ботов, размещённых в Cloud, включая память, шифруются при передаче и хранении.

<a id="how-administrators-access-them"></a>

## Как администраторы получают доступ?

Администраторы могут получить доступ к чатам и памяти через Admin API бота. Панель Klex Cloud служит фронтендом и обратным прокси для Admin API каждого бота. Подробнее о хранении см. в разделе [каталог данных](/bot/concepts/data-directory).
