Каждый бот Klex хранит разговоры и память в своём каталоге данных. У бота, размещённого в Cloud, каталог находится в облачной среде. У самостоятельно размещённого бота он находится в локальной папке, используемой для его данных.

Администраторы могут обращаться к разговорам и памяти через Admin API бота. Панель Klex Cloud служит обратным прокси и интерфейсом для Admin API каждого бота.

## Поиск самостоятельно размещённого бота

В самостоятельно размещённом приложении Klex 0.30.1 интерактивный запуск по умолчанию ищет ботов в `~/.klex/agents`. Если задан `KLEX_HOME`, используется папка `agents` по этому пути. С помощью `--data-dir` можно выбрать каталог напрямую; этот параметр имеет приоритет над `KLEX_DATA_DIR`.

Например, чтобы открыть бота, каталог данных которого вам уже известен:

```sh
klex --data-dir /path/to/bot
```

Замените пример пути реальным каталогом бота. Чтобы создать и настроить бота без терминального интерфейса, см. [быстрый старт](/bot/quickstart).

## Защита данных

Каталог может содержать конфиденциальные сведения, в том числе конфигурацию и учётные данные. Ограничьте доступ с помощью разрешений операционной системы и защитите создаваемые копии. В системах с файловыми режимами Unix Klex 0.30.1 запрашивает права только для владельца при создании каталога; права существующих каталогов он не меняет. Windows использует списки управления доступом.

Перед удалением или перемещением данных проверьте свои процедуры резервного копирования и восстановления. Эта страница не описывает поддерживаемую процедуру миграции или восстановления, правила хранения либо обработку данных третьими сторонами.
