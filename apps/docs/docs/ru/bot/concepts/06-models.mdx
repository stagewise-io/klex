Klex Bot использует модели настроенных вами провайдеров. Klex поддерживает разные типы провайдеров, в том числе OpenAI, Anthropic, Google Gemini, локальную Ollama и совместимые пользовательские конечные точки. Доступные модели зависят от провайдера и вашей учётной записи.

Провайдер — это сервис или конечная точка, к которой подключается Klex. Модель — конкретная модель, доступная через этого провайдера. Настройка провайдера не выбирает модели для всех задач автоматически.

<a id="configure-models"></a>

## Настройка моделей

<Tabs syncKey="hosting" hash={false}>
<Tab title="Облачный хостинг">

1. В Klex Cloud откройте своего Bot и выберите **Models**. Для изменения моделей Bot должен быть подключён, а у вас должны быть права администратора.
2. Если провайдер ещё не подключён, выберите **Add a provider**, укажите провайдера и завершите настройку. Необходимые параметры и шаги входа зависят от провайдера.
3. Выберите предустановленный набор моделей или укажите модели для каждой задачи в таблице. Проверьте выбранные модели, включая модели для чата, памяти и сжатия контекста.

</Tab>
<Tab title="Собственный хостинг">

В приложении Klex на собственном хостинге:

1. Откройте **Settings → Providers & Endpoints**, нажмите `a` и выберите тип провайдера. Укажите необходимые параметры и при необходимости выполните вход.
2. Откройте **Settings → Model Selection**, выберите **Chat** и добавьте модель настроенного провайдера. Модель чата нужна для обычного общения и создания Soul.
3. Проверьте остальные задачи и при необходимости добавьте совместимые модели. На экране можно выбрать модели для памяти, консультаций, обработки изображений и аудио, а также голоса.

</Tab>
</Tabs>

Некоторые провайдеры обнаруживают модели автоматически, для других сведения о модели нужно добавить вручную. Доступность и поддерживаемые возможности зависят от провайдера и модели.

<a id="choosing-models-for-different-tasks"></a>

## Выбор моделей для разных задач

Одну модель можно использовать для нескольких задач или выбрать разные модели для разных видов работы. Учитывайте поддержку необходимых входных данных, стоимость и задержку у провайдера. Перед использованием ознакомьтесь с условиями и ценами провайдера.

Для чата можно настроить упорядоченный список моделей. При ошибке модели Klex может перейти к другой настроенной модели чата. Проверьте порядок с помощью элементов управления моделями.

<a id="instincts-and-model-usage"></a>

## Instincts и использование моделей

Klex может использовать модель **Instincts** для классификации контекста перед этапом генерации. Если модель Instincts не настроена, для классификации используются доступные модели Chat. Эти вызовы могут увеличить использование моделей и расходы. Проверьте стоимость и следите за использованием.

<Tabs syncKey="hosting" hash={false}>
<Tab title="Облачный хостинг">

Откройте раздел **Models** своего Bot и выберите модель для **Quick Decisions** в таблице. Это модель Instincts.

</Tab>
<Tab title="Собственный хостинг">

Выберите модель Instincts в **Settings → Model Selection**.

</Tab>
</Tabs>

По умолчанию динамическая настройка усилия рассуждения работает в теневом режиме: она оценивает рекомендуемый уровень усилия, не меняя настройки основной модели. Теневая классификация всё равно может использовать модель и приводить к расходам.
