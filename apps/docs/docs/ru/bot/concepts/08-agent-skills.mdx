Agent Skill — это набор инструкций для повторяющейся задачи, который можно использовать многократно. Например, Skill может описывать подготовку отчёта о состоянии проекта. Описание сообщает Bot, когда применимы инструкции, а основной текст содержит порядок действий.

Klex позволяет Bot находить доступные Skills и загружать подходящую для задачи процедуру.

<a id="where-skills-come-from"></a>

## Откуда берутся Skills

Skills могут поступать из разных источников:

- **Template Skills** поставляются с Bot Templates.
- **Learned Skills** формируются на основе опыта Bot.
- **Uploaded Skills** предоставляются пользователями и содержат инструкции о поведении или знания.

Каждый Bot хранит свои Skills в собственной [директории данных](/bot/concepts/data-directory). Skill определяется пространством имён и названием, например `learning/project-status`.

Фоновый процесс памяти анализирует активность и может превращать полезные уроки в Skills. При обработке последующей активности он может обновлять или удалять Learned Skills; не каждый разговор приводит к созданию Skill.

Каждая Skill хранится в файле `SKILL.md` в каталоге `skills/{namespace}/{name}/`. Файл содержит название, описание и основной текст в формате Markdown. У Skill также могут быть справочные файлы в папке `references/`.

<a id="review-and-manage-skills"></a>

## Проверка и управление Skills

<Tabs syncKey="hosting" hash={false}>
<Tab title="Размещённый в Cloud">

Управление Uploaded Skills через Cloud появится в ближайшее время. Uploaded Skills будут единственным типом Skills, которым пользователи смогут управлять через Cloud.

</Tab>
<Tab title="Самостоятельно размещённый">

Для проверки Skills используйте Admin API Bot. О локальном доступе и его ограничениях безопасности см. [Проверка активности Bot](/bot/guides/observability#access-the-local-admin-api).

</Tab>
</Tabs>

Admin API Bot позволяет получить список Skills и их содержимое, а также редактировать или удалять их. Используйте `GET /v1/skills` для получения списка и `GET /v1/skills/{namespace}/{name}` для чтения одной Skill. Тот же полный путь поддерживает `PATCH` и `DELETE`. Для справочных файлов есть отдельные маршруты API. Удаление может завершиться ошибкой, если на Skill ссылается сущность памяти.

Проверяйте точность Learned Skills. Процесс памяти может со временем обновлять или удалять их, в том числе Skills, отредактированные администратором. Редактирование не защищает Learned Skill от последующих изменений.
