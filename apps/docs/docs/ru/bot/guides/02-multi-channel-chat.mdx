Bot может использовать несколько подключений для обмена сообщениями. Для каждого нужны сервер MCP с необходимыми возможностями обмена сообщениями и учетная запись с доступом к нужным беседам.

<a id="connect-and-check-each-channel"></a>

## Подключите и проверьте каждый канал

1. Добавьте или подключите соответствующий сервер MCP для приложения. См. [MCP и Klex Bots](/ru/bot/concepts/mcp).
2. Настройте или авторизуйте учетную запись Bot и предоставьте ей доступ в приложении. Повторите для каждого приложения.
3. Отправьте тестовое сообщение в каждую нужную беседу и проверьте, может ли Bot ответить. Если нет, проверьте состояние подключения, авторизацию и доступ учетной записи к беседе.

Для групповой беседы проверьте, кто ее видит и разрешено ли учетной записи Bot участвовать. Настройте аудиторию и разрешения в приложении. Не предполагайте, что подключение дает доступ ко всем беседам.
