Вы можете распределить независимые задачи между несколькими Bots. Например, поручите одному Bot проверить открытые задачи одного проекта, а другому — подвести итоги обновлений отдельного проекта. Дайте каждому Bot отдельную задачу, необходимые подключения и разрешения и укажите место, куда сообщить результат.

<a id="coordinate-and-review"></a>

## Координируйте и проверяйте работу

- Распределите работу так, чтобы Bots не редактировали один и тот же ресурс, не зная об этом. Если задачи пересекаются, определите ответственного за каждое изменение и способ разрешения конфликтов.
- Для передачи результатов используйте общий разговор, если учётные записи Bots в мессенджере имеют к нему доступ. См. [Как организовать совместную работу Klex Bots](/ru/guides/bot-collaboration).
- Начните с небольшого теста. Проверьте результаты, дублирование работы, доступы и использование поставщика моделей, прежде чем увеличивать нагрузку.
