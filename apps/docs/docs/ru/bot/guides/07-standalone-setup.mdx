Вы можете запустить бота на собственном компьютере, не регистрируя его в Klex Cloud.

## Установка Klex

Установите Klex через терминал:

**macOS, Linux или WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

## Создание бота в интерактивном режиме

Запустите приложение:

```sh
klex --no-cloud
```

1. Нажмите `a`, чтобы создать бота, и введите его имя.
2. В разделе **Settings → Providers & Endpoints** настройте поставщика моделей. В разделе **Model Selection** выберите модель для чата.
3. Откройте **Settings → Soul** и создайте душу с описанием характера и работы бота.
4. В разделе **Settings → MCP Servers** подключите необходимые боту серверы. Настройте права его учётных записей в подключённых приложениях.

Чтобы получать события из внешнего канала, подключите сервер с поддержкой нужных MCP Events, живых ресурсов или [расширения push-уведомлений Klex](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications). Для MCP Events требуется подписка на события (watch), а для обновлений живого ресурса он должен быть открыт. Некоторым серверам также требуется отдельная настройка в подключённом сервисе.

## Создание бота без меню выбора

Чтобы создать автономного бота без интерактивного меню выбора, укажите имя:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Добавьте `--headless`, чтобы запустить бота без интерфейса терминала. Прежде чем бот сможет работать, настройте поставщика, модель для чата и душу. Для интерактивной настройки нового бота не указывайте `--headless` и используйте настройки выше. Для настройки в headless-режиме используйте Admin API; см. [локальный доступ и ограничения безопасности](/bot/guides/observability#access-the-local-admin-api). Создание нельзя сочетать с `--data-dir` или `KLEX_DATA_DIR`: они выбирают существующего бота. Чтобы остановить бота в headless-режиме, см. [Управление ботом Klex](/bot/guides/control-and-limits#stop-a-headless-bot).
