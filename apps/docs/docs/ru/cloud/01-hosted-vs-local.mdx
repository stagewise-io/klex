> **Можно ли запустить бота Klex без Klex Cloud?**

Да. Самостоятельно размещённый бот Klex может работать без подключения к Cloud. Klex рекомендует большинству пользователей бота в Cloud, а для более полного управления рекомендует подключить самостоятельно размещённого бота к Klex Cloud.

<a id="choose-how-to-host-the-bot"></a>

## Выберите способ размещения бота

<a id="klex-cloud-hosted-bot"></a>

### Бот в Klex Cloud

Klex запускает бота в своей облачной среде. Чаты и память бота хранятся в его каталоге данных в этой среде. В панели Cloud можно просматривать активность и управлять подключёнными MCP.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Самостоятельно размещённый бот, подключённый к Klex Cloud

Вы запускаете бота в управляемой вами среде и можете подключить его к Klex Cloud. Это даёт больше контроля над местом работы бота, сохраняя управление через Cloud. Чаты и память остаются в локальном каталоге данных бота. Панель Cloud предоставляет интерфейс и обратный прокси к Admin API бота.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Самостоятельно размещённый бот без подключения к Cloud

Подключение к Cloud не является техническим требованием для самостоятельно размещённого бота. Klex рекомендует подключение, поскольку автономная работа предоставляет менее полный набор возможностей.

<a id="self-hosted-cloud"></a>

### Самостоятельно размещённый Cloud

Самостоятельное размещение сервиса Klex Cloud доступно только клиентам Enterprise.

<a id="manage-access-and-stop-a-bot"></a>

## Управление доступом и остановка бота

В панели Cloud можно просматривать активность бота и подключать или отключать MCP. Разрешения других приложений и учётных записей бота настраивайте в них. Чтобы остановить самостоятельно размещённого бота, закройте его приложение. Чтобы остановить бота в Cloud, используйте **Stop** в панели Cloud.
