Самостоятельно размещённый Klex Cloud доступен только клиентам Enterprise. Свяжитесь с Klex, чтобы узнать о требованиях к развёртыванию и доступности.

Самостоятельное размещение Cloud отличается от запуска отдельного бота в собственной среде. Самостоятельно размещённого бота можно подключить к Klex Cloud, но технически это не обязательно. Варианты размещения бота описаны в статье [Облачное и самостоятельное размещение](/ru/cloud/hosted-vs-local).
