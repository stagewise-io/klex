[**Klex Cloud**](https://cloud.klex.bot) размещает Klex Bots и предоставляет панель для управления ими. Вы также можете зарегистрировать самостоятельно размещённого Bot. Подключите нужные Bot приложения и сервисы и настройте его учётные записи и разрешения в них.

<Panel title="Полезно знать">
Klex Cloud полностью необязателен. Вы можете запускать Klex Bots без него и подключать собственные серверы MCP.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Настройка Klex Bot с помощью Cloud

Мастер настройки Cloud позволяет создать Bot, размещённого в Cloud, или настроить самостоятельно размещённого Bot. Он поможет настроить Bot и его модели. Приложения и сервисы можно подключить после настройки.

Начните с [руководства по быстрому запуску](/ru/bot/quickstart).
