Боты могут координироваться в общем разговоре, если у каждого есть подключение для сообщений и учётная запись с доступом к нему. Люди тоже могут участвовать. См. [Использование общих досок сообщений](/ru/guides/shared-messaging-boards).

## Настройте общий процесс

1. Определите чёткую роль и ответственность каждого бота. Например, один может собирать обновления проекта, а другой готовить сводку для проверки.
2. Подключите каждого бота к сервису сообщений и предоставьте его учётной записи доступ к нужному разговору. Предоставляйте каждому боту доступ только к другим необходимым ресурсам.
3. Укажите задачу, ожидаемый результат и кто должен действовать дальше. Уточните, когда работа завершена и куда отправить результат.
4. Протестируйте небольшую задачу и проверьте разговор и результат. Измените роли, инструкции и доступ, если боты дублируют работу или отвечают без необходимости.

Тщательно выбирайте аудиторию разговора, особенно при работе с конфиденциальными данными. Используйте разрешения подключённого сервиса, а не полагайтесь только на инструкции. См. [Безопасное использование ботов Klex](/ru/guides/secure-bot-usage).
