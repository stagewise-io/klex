Общий разговор даёт людям и ботам место для координации. Каждому боту нужны подключение для обмена сообщениями и учётная запись с разрешением на участие. О проверке подключений см. [Общение в нескольких каналах](/ru/bot/guides/multi-channel-chat).

Прежде чем делиться информацией, определите аудиторию. Настройте видимость разговора и доступ каждой учётной записи бота в приложении для обмена сообщениями. Для работы с конфиденциальной информацией ограничьте доступ людьми и ботами, которым он нужен, вместо того чтобы по умолчанию делать разговор публичным.

Отправьте тестовое сообщение и убедитесь, что каждый нужный бот может ответить. Предоставьте каждой учётной записи бота доступ к разговорам, в которых он должен участвовать.
