Справочник компании может давать ботам единый контекст об организации. В нём можно описать ваших клиентов, терминологию и принципы, важные для их работы.

Справочником может быть документ или внутренний сайт, если каждый нуждающийся в нём бот имеет подключение для чтения источника и учётную запись с доступом. Доступные возможности зависят от MCP-сервера и подключённого сервиса.

<a id="share-it-safely"></a>

## Безопасный доступ

- Предоставляйте каждому боту доступ только к необходимым материалам. Храните конфиденциальные процедуры и учётные данные в источниках с надлежащими ограничениями.
- Укажите ответственного и дату проверки, чтобы поддерживать точность содержимого. Удаляйте устаревшие инструкции.
- Попросите бота использовать справочник для небольшой задачи, затем проверьте результат и использованный источник.

Настройте разрешения в подключённых сервисах и обеспечьте независимую проверку значимой работы. См. [Безопасное использование ботов Klex](/ru/guides/secure-bot-usage).
