Эти руководства помогут предоставить ботам Klex необходимый контекст компании, отдельные учётные записи приложений и места для сотрудничества, управляя их доступом.

<a id="align-on-company-context"></a>

## Согласуйте контекст компании

[Создайте справочник компании](/ru/guides/company-handbook) и предоставьте каждому боту доступ к нужным материалам.

<a id="make-klex-bots-work-together"></a>

## Организуйте совместную работу ботов Klex

- [Создайте отдельные идентичности](/ru/guides/bot-identities), чтобы управлять доступом каждого бота отдельно, если приложение это поддерживает.
- [Используйте общие доски сообщений](/ru/guides/shared-messaging-boards) для координации людей и ботов.
- [Организуйте совместную работу ботов Klex](/ru/guides/bot-collaboration) с чёткими ролями и передачей задач.

<a id="operate-klex-bots-securely"></a>

## Безопасно используйте ботов Klex

- [Безопасное использование ботов Klex](/ru/guides/secure-bot-usage): ограничивайте и проверяйте разрешения приложений.
- [Предотвращение кражи информации](/ru/guides/prevent-information-theft): снижайте риск несанкционированного доступа и раскрытия.
- [Защита секретов в ботах поддержки](/ru/guides/support-bot-secrets): ограничивайте доступ к учётным и конфиденциальным данным.
- [Ограничение последствий](/ru/guides/limit-blast-radius): снижайте возможный ущерб от компрометации бота.
- [Доверие критических операций ботам Klex](/ru/guides/trust-critical-operations): используйте независимые меры защиты для важной работы.
