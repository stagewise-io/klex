Для більшості користувачів Klex рекомендує бота, розміщеного в хмарі. Ви також можете запустити бота на власному комп’ютері, з реєстрацією в Klex Cloud або без неї. Вам потрібен доступ до постачальника моделей; для хмарного налаштування також потрібен обліковий запис Klex Cloud.

<a id="створення-вашого-бота"></a>

## Створення бота в хмарі

1. Увійдіть у [Klex Cloud](https://cloud.klex.bot) і почніть створення бота.
2. Оберіть хмарний хостинг і дотримуйтеся кроків, щоб назвати бота, визначити його [душу](/bot/concepts/soul) та налаштувати постачальників і моделі.
3. Підключіть застосунки або комп’ютери, потрібні боту. Див. [Підключення](/bot/concepts/brain-and-computers), щоб керувати доступом.

Надішліть боту повідомлення в підключеному застосунку, щоб перевірити відповідь. Його активність можна переглянути на панелі Cloud.

<a id="встановлення"></a>

## Встановлення Klex для самостійного хостингу

Щоб запустити бота на власному комп’ютері, встановіть Klex із термінала:

<Tabs param="install">
  <Tab title="macOS">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Linux">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
  <Tab title="Windows">`irm https://klex.bot/install.ps1 | iex`</Tab>
  <Tab title="WSL">`curl -fsSL https://klex.bot/install.sh | sh`</Tab>
</Tabs>

### Налаштування за допомогою Cloud

Почніть налаштування самостійно розміщеного бота в Klex Cloud і дотримуйтеся інструкцій із реєстрації. Бот працює на вашому комп’ютері; Cloud надає інтерфейс керування.

### Автономне налаштування

Щоб запустити бота без реєстрації в Cloud, відкрийте інтерактивний застосунок:

```sh
klex --no-cloud
```

1. Натисніть `a`, щоб створити бота, і введіть його ім’я.
2. У **Settings → Providers & Endpoints** налаштуйте постачальника моделей. У **Model Selection** оберіть дійсну модель для чату.
3. Відкрийте **Settings → Soul** і створіть душу, яка описує характер і роботу бота.
4. У **Settings → MCP Servers** підключіть потрібні сервери. Налаштуйте дозволи облікових записів бота в підключених застосунках.

Щоб отримувати події із зовнішнього каналу, підключіть MCP-сервер, який підтримує відповідні оновлення ресурсів або [розширення push-повідомлень](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications) Klex.
