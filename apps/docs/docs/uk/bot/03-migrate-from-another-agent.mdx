Передайте роботу й корисні знання наявного агента боту Klex. Спочатку зберіть інформацію про те, що він робить, знає та які ресурси використовує.

<a id="prepare-the-workflow"></a>

## Зберіть найважливіше

Попросіть поточного агента підготувати документ передачі справ. Наведений промпт є відправною точкою; адаптуйте його до роботи, яку хочете передати.

~~~text
Я передаю вашу роботу новому ШІ-агенту. Створіть один документ передачі справ, який новий агент і його адміністратор можуть використати для продовження роботи.

Включіть наведене нижче з чіткими заголовками та практичними деталями:

1. Роль і пріоритети: ваше призначення, обов’язки, бажаний стиль роботи та люди або команди, з якими ви працюєте.
2. Знання й контекст: важливі факти, термінологія, рішення, вподобання та відповідна вивчена інформація. Вкажіть, де знайти підтверджувальні матеріали.
3. Рутини й розклади: повторювані завдання, час і часові пояси, тригери, очікувані результати та місця їх надсилання.
4. Типові процеси: покрокові робочі процеси, точки прийняття рішень, передача завдань, приклади та перевірка результатів.
5. Навички й висновки: повторно використовувані процедури, уроки попередньої роботи, типові проблеми та способи їх вирішення.
6. Підключення й доступ: застосунки, облікові записи, ресурси та можливості для кожного процесу. Опишіть потрібний доступ без облікових даних.
7. Незавершена робота: поточні завдання, рішення, що очікуються, терміни та наступна дія для кожного.

Використовуйте доступну інформацію. Позначайте те, до чого немає доступу або в чому ви не впевнені, замість припущень. Не включайте паролі, токени, ключі API та інші секрети. Позначте конфіденційну інформацію, щоб я вирішив, чим ділитися. Поверніть передачу справ як один структурований документ.
~~~

Перевірте точність документа та наявність конфіденційної інформації. Додайте те, до чого попередній агент не мав доступу, наприклад розклади чи інструкції, збережені в іншому місці.

<a id="set-up-your-klex-bot"></a>

## Налаштуйте бота Klex

1. [Створіть бота Klex](/uk/bot/quickstart). Використайте документ передачі справ для опису його роботи та характеру.
2. Надайте боту відповідний вміст документа та поясніть, яку роботу він має взяти. Для повторно використовуваних процедур використовуйте [Agent Skills](/uk/bot/concepts/agent-skills).
3. [Підключіть застосунки й комп’ютери](/uk/bot/concepts/brain-and-computers), потрібні для роботи, і налаштуйте доступ облікового запису бота в кожній службі.
4. Налаштуйте повторювану роботу через підключену службу планування. Див. [Автоматизація повторюваних завдань](/uk/bot/guides/recurring-tasks).

<a id="test-before-switching-over"></a>

## Перевірте передачу справ

Спробуйте типове завдання та перевірте результат. Переконайтеся, що бот має доступ до ресурсів, звітує в потрібне місце й отримує заплановану роботу. Коли новий процес запрацює, видаліть непотрібний доступ і розклади старого агента.
