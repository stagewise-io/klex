Klex Bot — автономний агент із власною ідентичністю та пам’яттю. Він працює у своєму середовищі, а завдання виконує в інших середовищах, підключених через MCP (Model Context Protocol).

Середовище Bot підтримує його роботу та керує його пам’яттю. Завдання він виконує на підключених комп’ютерах і в застосунках. Пам’ять містить навички та засвоєний досвід, а до кожного комп’ютера чи застосунку Bot підключається окремим з’єднанням MCP.

<a id="where-the-bot-runs"></a>

## Де працює Bot

Можна використовувати Bot, розміщений у Cloud, або запустити Bot у власному середовищі. Klex рекомендує хмарне розміщення; самостійно розміщений Bot також можна зареєструвати в Klex Cloud. Технічно така реєстрація необов’язкова, але можливості автономної роботи менш повні. Докладніше про [хмарне та самостійне розміщення](/uk/cloud/hosted-vs-local).

<a id="how-the-bot-works-with-computers-and-apps"></a>

## Як Bot працює з комп’ютерами та застосунками

Bot підключається до сервера MCP, щоб отримати доступ до зовнішнього середовища. Це може бути цілий комп’ютер або застосунок, наприклад GitHub чи Google Workspace.

Для більшості MCP Bot діє через власний обліковий запис або власну ідентичність. Її налаштовують для кожного Bot і можуть надати дозволи та права доступу. Модель підключення й доступу описано в розділі [Підключення](/uk/bot/concepts/brain-and-computers).

<a id="what-the-bot-remembers"></a>

## Що запам’ятовує Bot

Пам’ять допомагає Bot використовувати свій досвід. Він застосовує навички та засвоєний досвід для повторюваної роботи й може пригадувати потрібний контекст із попередньої діяльності. Докладніше про [пам’ять](/uk/bot/concepts/memory), а також про зберігання та доступ адміністраторів у розділі [Каталог даних](/uk/bot/concepts/data-directory).
