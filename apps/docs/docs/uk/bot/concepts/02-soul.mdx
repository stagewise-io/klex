## Створення та оновлення душі

Використовуйте Admin API бота, щоб створити або оновити душу за інструкціями. Надішліть `POST /v1/soul`, щоб створити душу з нуля, або `PATCH /v1/soul`, щоб оновити наявну. Для читання використовуйте `GET /v1/soul`. Поради щодо доступу та безпеки наведено в розділі [Доступ до локального Admin API](/bot/guides/observability#access-the-local-admin-api).

Для генерації душі використовуються налаштовані моделі чату; результат зберігається після успішної генерації. Наприклад, в інструкціях можна описати роботу бота, бажаний тон і підхід до ухвалення рішень. Перевірте створену душу й оновіть її за потреби. Збережіть душу, перш ніж надсилати боту нові завдання.

## Зберігання та доступ

Душа зберігається в [каталозі даних](/bot/concepts/data-directory) бота. Admin API бота може читати душу та створювати нову або оновлену душу за інструкціями адміністратора. У звичайній сесії немає інструмента для запису душі.

## Якщо бот не має душі

Для виконання звичайних завдань боту потрібна непорожня душа. Без неї він пропускає нові завдання й відкидає щойно додану історію сесії; пропущені завдання не ставляться в чергу. Створіть душу, перш ніж надсилати нові дані.
