## Створення та оновлення душі

У самостійно розміщеному застосунку Klex 0.30.1 відкрийте **Settings → Soul**. Тут можна переглянути збережену душу, створити або оновити її за інструкціями чи створити заново. Генерація використовує налаштовані моделі чату та зберігає успішно створені результати. Звичайні сесії залишаються на паузі, доки душу не збережено.

Наприклад, в інструкціях можна описати роботу бота, бажаний тон і підхід до ухвалення рішень. Перевірте створену душу й оновіть її, якщо вона не відповідає вашим очікуванням.

Klex також підтримує [God Messages](/bot/concepts/god-messages) для запиту змін душі. Це не єдиний спосіб її створити або оновити.

## Зберігання та доступ

Душа зберігається в [каталозі даних](/bot/concepts/data-directory) бота. У Klex 0.30.1 Admin API бота може читати душу та створювати нову або оновлену душу за адміністративними інструкціями. У звичайній сесії немає інструмента для запису душі.
