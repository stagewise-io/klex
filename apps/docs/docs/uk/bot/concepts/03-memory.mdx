Пам’ять Klex Bot зберігає **навички та засвоєні знання**. Вона керується у власному середовищі бота, поряд з активними сесіями, які забезпечують його роботу.

<a id="where-chats-and-memory-are-stored"></a>

## Де зберігаються чати й пам’ять?

Чати й пам’ять зберігаються в каталозі даних бота:

- Для **бота, розміщеного в Cloud**, каталог міститься в хостинговому середовищі.
- Для **самостійно розміщеного бота** каталог міститься в локальній папці, що використовується для даних бота.

Усі дані ботів, розміщених у Cloud, включно з пам’яттю, шифруються під час передавання та зберігання.

<a id="how-administrators-access-them"></a>

## Як адміністратори отримують доступ?

Адміністратори можуть отримати доступ до чатів і пам’яті через Admin API бота. Панель Klex Cloud є фронтендом і зворотним проксі для Admin API кожного бота. Докладніше про зберігання дивіться в розділі [каталог даних](/bot/concepts/data-directory).
