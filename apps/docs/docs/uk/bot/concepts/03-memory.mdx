Пам’ять допомагає Klex Bot спиратися на засвоєні знання та використовувати контекст попередньої роботи. Вона поєднує **навички**, зокрема засвоєні й попередньо налаштовані процедури, з відповідними знаннями з діяльності бота.

Бот може використовувати навички для знайомих завдань і пригадувати попередній контекст, коли це корисно, наприклад термінологію проєкту або попереднє рішення. Він може запитати пригадування у фоновому режимі, а відповідний контекст може з’явитися під час роботи. Докладніше про процедури для повторного використання дивіться в розділі [Agent Skills](/bot/concepts/agent-skills).

<a id="where-chats-and-memory-are-stored"></a>

## Де зберігаються чати й пам’ять?

Чати й пам’ять зберігаються в каталозі даних бота:

- Для **бота, розміщеного в Cloud**, каталог міститься в хостинговому середовищі.
- Для **самостійно розміщеного бота** каталог міститься в локальній папці, що використовується для даних бота.

Усі дані ботів, розміщених у Cloud, включно з пам’яттю, шифруються під час передавання та зберігання.

## Перегляд чатів і навичок

Адміністратори можуть переглядати чати й навички через Admin API бота. Панель Klex Cloud є фронтендом і зворотним проксі для Admin API кожного бота. Докладніше про зберігання дивіться в розділі [каталог даних](/bot/concepts/data-directory).
