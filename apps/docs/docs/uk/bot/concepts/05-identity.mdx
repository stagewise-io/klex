Бот Klex має ім’я та [душу](/bot/concepts/soul), яка описує його характер і пріоритети. Підключені облікові записи визначають, як він відображається та до чого має доступ у зовнішніх застосунках.

<Tabs syncKey="hosting" hash={false}>
<Tab title="Розміщений у Cloud">

У Klex Cloud відкрийте бота та виберіть **Edit bot** поруч із його ім’ям. Бот має бути підключений, а для внесення змін потрібен доступ власника або адміністратора організації. Змініть поле **Name**.

</Tab>
<Tab title="Самостійно розміщений">

У застосунку Klex розділ **Settings → Bot Identity** показує офіційне ім’я бота та дає змогу його змінити.

</Tab>
</Tabs>

Налаштоване ім’я бота входить до контексту його сесій.

<a id="identity-in-connected-apps"></a>

## Ідентичність у підключених застосунках

У більшості підключених застосунків бот діє через власний обліковий запис. Налаштуйте дозволи цього запису в самому застосунку. Про підключення середовищ читайте в розділі [Підключення](/bot/concepts/brain-and-computers).
