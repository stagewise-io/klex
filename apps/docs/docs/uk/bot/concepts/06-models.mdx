Klex Bot використовує моделі налаштованих вами провайдерів. Klex підтримує різні типи провайдерів, зокрема OpenAI, Anthropic, Google Gemini, локальний Ollama та сумісні користувацькі endpoints. Доступні моделі залежать від провайдера та вашого облікового запису.

Провайдер — це сервіс або endpoint, до якого підключається Klex; модель — це конкретна модель, доступна через цього провайдера. Налаштування провайдера не означає автоматичного вибору моделі для кожного завдання.

<a id="configure-models"></a>

## Налаштування моделей

<Tabs syncKey="hosting" hash={false}>
<Tab title="У хмарі">

1. У Klex Cloud відкрийте свого Bot і виберіть **Models**. Bot має бути підключений, а для зміни моделей потрібен доступ адміністратора.
2. Якщо жодного провайдера не підключено, виберіть **Add a provider**, виберіть провайдера та завершіть налаштування. Необхідні параметри та кроки входу залежать від провайдера.
3. Виберіть готовий набір моделей або виберіть моделі для кожного призначення в таблиці. Перевірте вибір, зокрема моделі для чату, пам’яті та стиснення контексту.

</Tab>
<Tab title="На власному хостингу">

У самостійно розміщеному застосунку Klex:

1. Відкрийте **Settings → Providers & Endpoints**, натисніть `a` і виберіть тип провайдера. Введіть необхідні параметри та виконайте кроки входу, якщо вони потрібні.
2. Відкрийте **Settings → Model Selection**, виберіть **Chat** і додайте модель налаштованого провайдера. Модель чату потрібна для звичайного спілкування та створення Soul.
3. Перегляньте інші призначення та за потреби додайте сумісні моделі. На екрані є варіанти для пам’яті, консультацій, введення зображень, введення аудіо та голосу.

</Tab>
</Tabs>

Деякі провайдери автоматично знаходять моделі, інші вимагають додати відомості про модель вручну. Доступність і підтримувані можливості залежать від провайдера та моделі.

<a id="choosing-models-for-different-tasks"></a>

## Вибір моделей для різних завдань

Ви можете використовувати одну модель для кількох призначень або вибрати різні моделі для різних завдань. Перевірте, чи підтримує модель потрібний тип вхідних даних, і врахуйте вартість та затримку провайдера. Перед використанням ознайомтеся з умовами та цінами провайдера.

Для чату можна налаштувати впорядкований список моделей. У разі помилки моделі Klex може перейти до іншої налаштованої моделі чату. Перевірте порядок в елементах керування моделями.

<a id="instincts-and-model-usage"></a>

## Instincts і використання моделей

Klex може використовувати модель **Instincts** для класифікації контексту перед етапом генерації. Якщо модель Instincts не налаштована, для класифікації використовуються доступні моделі Chat. Ці виклики можуть збільшити використання моделей і витрати. Перевіряйте ціну та стежте за використанням.

<Tabs syncKey="hosting" hash={false}>
<Tab title="У хмарі">

Відкрийте розділ **Models** свого Bot і виберіть модель для **Quick Decisions** у таблиці моделей. Це і є модель Instincts.

</Tab>
<Tab title="На власному хостингу">

Виберіть модель Instincts у **Settings → Model Selection**.

</Tab>
</Tabs>

За замовчуванням dynamic effort працює в тіньовому режимі: він оцінює запропонований рівень зусиль для міркування, не змінюючи налаштування основної моделі. Класифікація в тіньовому режимі все одно може використовувати модель і спричиняти витрати.
