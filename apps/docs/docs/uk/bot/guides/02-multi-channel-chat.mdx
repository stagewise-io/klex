Bot може використовувати кілька з’єднань для обміну повідомленнями. Для кожного потрібні сервер MCP із необхідними можливостями обміну повідомленнями та обліковий запис із доступом до потрібних розмов.

<a id="connect-and-check-each-channel"></a>

## Підключіть і перевірте кожен канал

1. Додайте або підключіть відповідний сервер MCP для застосунку. Див. [MCP і Klex Bots](/uk/bot/concepts/mcp).
2. Налаштуйте або авторизуйте обліковий запис Bot і надайте йому доступ у застосунку. Повторіть для кожного застосунку.
3. Надішліть тестове повідомлення в кожну потрібну розмову та перевірте, чи може Bot відповісти. Якщо ні, перевірте стан з’єднання, авторизацію та доступ облікового запису до розмови.

Для групової розмови перевірте, хто її бачить і чи дозволено обліковому запису Bot брати участь. Налаштуйте аудиторію та дозволи в застосунку. Не припускайте, що з’єднання надає доступ до всіх розмов.
