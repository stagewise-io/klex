Ви можете розподілити незалежні завдання між кількома Bots. Наприклад, доручіть одному Bot переглянути відкриті задачі одного проєкту, а іншому — підсумувати оновлення окремого проєкту. Для кожного Bot визначте окреме завдання, надайте потрібні підключення й дозволи та вкажіть місце для повідомлення результату.

<a id="coordinate-and-review"></a>

## Координуйте та перевіряйте роботу

- Розподіліть роботу так, щоб Bots не редагували той самий ресурс, не знаючи про це. Якщо завдання перетинаються, визначте відповідального за кожну зміну та спосіб розв’язання конфліктів.
- Для передачі результатів використовуйте спільну розмову, якщо облікові записи Bots у месенджері мають до неї доступ. Див. [Як організувати спільну роботу Klex Bots](/uk/guides/bot-collaboration).
- Почніть із невеликого тесту. Перевірте результати, дублювання роботи, доступи й використання постачальника моделей, перш ніж збільшувати навантаження.
