Ви можете запустити бота на власному комп’ютері, не реєструючи його в Klex Cloud.

<a id="install-klex"></a>

## Встановлення Klex

Встановіть Klex у терміналі:

**macOS, Linux або WSL:**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows (PowerShell):**

```powershell
irm https://klex.bot/install.ps1 | iex
```

<a id="create-a-bot-interactively"></a>

## Інтерактивне створення бота

Запустіть застосунок:

```sh
klex --no-cloud
```

1. Натисніть `a`, щоб створити бота, і введіть його ім’я.
2. У **Settings → Providers & Endpoints** налаштуйте постачальника моделей. У **Model Selection** виберіть модель для чату.
3. Відкрийте **Settings → Soul** і створіть Soul з описом характеру та роботи бота.
4. У **Settings → MCP Servers** підключіть потрібні боту сервери. Налаштуйте дозволи його облікового запису в підключених застосунках.

Щоб отримувати події із зовнішнього каналу, підключіть сервер, який підтримує відповідні MCP Events, live resources або [розширення push-сповіщень Klex](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications). Для MCP Events потрібен watch, а для оновлень live resource ресурс має залишатися відкритим. Деякі сервери також потребують окремого налаштування в підключеному сервісі.

<a id="create-a-bot-without-the-picker"></a>

## Створення бота без меню вибору

Щоб створити автономного бота без інтерактивного меню вибору, вкажіть ім’я:

```sh
klex --create-bot --no-cloud --bot-name Ada
```

Додайте `--headless`, щоб запустити бота без термінального інтерфейсу. Перш ніж бот зможе працювати, налаштуйте постачальника, модель для чату та Soul. Щоб налаштувати нового бота інтерактивно, не додавайте `--headless` і використайте налаштування вище. Для налаштування без інтерфейсу використовуйте Admin API; див. [локальний доступ і обмеження безпеки](/uk/bot/guides/observability#access-the-local-admin-api). Під час створення не можна використовувати `--data-dir` або `KLEX_DATA_DIR`: вони призначені для вибору наявного бота. Як зупинити бота без інтерфейсу, див. у посібнику [Керування ботом Klex](/uk/bot/guides/control-and-limits#stop-a-headless-bot).
