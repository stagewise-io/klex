> **Чи можна запустити бота Klex без Klex Cloud?**

Так. Самостійно розміщений бот Klex може працювати без підключення до Cloud. Klex рекомендує більшості користувачів бота в Cloud, а для повнішого керування рекомендує підключити самостійно розміщеного бота до Klex Cloud.

<a id="choose-how-to-host-the-bot"></a>

## Виберіть спосіб розміщення бота

<a id="klex-cloud-hosted-bot"></a>

### Бот у Klex Cloud

Klex запускає бота у своєму хмарному середовищі. Чати й пам’ять бота зберігаються в його каталозі даних у цьому середовищі. У панелі Cloud можна переглядати активність і керувати підключеними MCP.

<a id="self-hosted-bot-enrolled-in-klex-cloud"></a>

### Самостійно розміщений бот, підключений до Klex Cloud

Ви запускаєте бота в середовищі, яким керуєте, і можете підключити його до Klex Cloud. Це дає більше контролю над місцем роботи бота зі збереженням керування через Cloud. Чати й пам’ять залишаються в локальному каталозі даних бота. Панель Cloud надає інтерфейс і зворотний проксі до Admin API бота.

<a id="self-hosted-bot-without-cloud-enrollment"></a>

### Самостійно розміщений бот без підключення до Cloud

Підключення до Cloud не є технічною вимогою для самостійно розміщеного бота. Klex рекомендує підключення, оскільки окрема робота має менш повні можливості.

<a id="self-hosted-cloud"></a>

### Самостійно розміщений Cloud

Самостійне розміщення служби Klex Cloud доступне лише клієнтам Enterprise.

<a id="manage-access-and-stop-a-bot"></a>

## Керування доступом і зупинка бота

У панелі Cloud можна переглядати активність бота та підключати або відключати MCP. Дозволи інших застосунків і облікових записів бота налаштовуйте в них. Щоб зупинити самостійно розміщеного бота, закрийте його застосунок. Щоб зупинити бота в Cloud, скористайтеся **Stop** у панелі Cloud.
