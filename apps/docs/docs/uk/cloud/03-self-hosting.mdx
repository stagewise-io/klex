Самостійно розміщений Klex Cloud доступний лише клієнтам Enterprise. Зверніться до Klex щодо вимог до розгортання та доступності.

Самостійне розміщення Cloud відрізняється від запуску окремого бота у власному середовищі. Самостійно розміщеного бота можна підключити до Klex Cloud, але технічно це не обов’язково. Варіанти розміщення бота описано в статті [Хмарне та самостійне розміщення](/uk/cloud/hosted-vs-local).
