[**Klex Cloud**](https://cloud.klex.bot) розміщує Klex Bots і надає панель керування ними. Ви також можете зареєструвати самостійно розміщеного Bot. Підключіть потрібні Bot застосунки та сервіси й налаштуйте в них його облікові записи та дозволи.

<Panel title="Корисно знати">
Klex Cloud цілком необов’язковий. Ви можете запускати Klex Bots без нього та підключати власні сервери MCP.
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## Налаштування Klex Bot із Cloud

Майстер налаштування Cloud дає змогу створити Bot у Cloud або налаштувати самостійно розміщений Bot. Він допомагає налаштувати Bot і його моделі. Після налаштування можна підключити застосунки та сервіси.

Почніть із [посібника зі швидкого старту](/uk/bot/quickstart).
