---
title: Душа Бота
description: Керуйте діями та поведінкою ботів Klex за допомогою їхньої душі.
---

Душа стисло описує призначення, характер і поведінку бота. Вона зберігається в каталозі даних і завантажується в контекст.

Створіть або оновіть душу в CLI через `Settings -> Soul`, описавши призначення, характер і очікувану поведінку. Окремий API надає `GET /v1/soul`, `POST /v1/soul` для створення та `PATCH /v1/soul` для оновлення. Оновлення з порожніми інструкціями оптимізує наявну душу.

Чат-сесії лише читають душу й не можуть її редагувати. Без душі бот не виконує виведення моделі в чаті.
