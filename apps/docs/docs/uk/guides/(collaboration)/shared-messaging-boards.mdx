Спільна розмова дає людям і ботам місце для координації. Кожному боту потрібні підключення для обміну повідомленнями та обліковий запис із дозволом на участь. Про перевірку підключень див. [Спілкування в кількох каналах](/uk/bot/guides/multi-channel-chat).

Перш ніж ділитися інформацією, визначте аудиторію. Налаштуйте видимість розмови та доступ кожного облікового запису бота в застосунку для повідомлень. Для конфіденційної роботи обмежте доступ людьми й ботами, яким він потрібен, замість того щоб робити розмову публічною за замовчуванням.

Надішліть тестове повідомлення та перевірте, чи може відповісти кожен запланований бот. Надайте кожному обліковому запису бота доступ до розмов, у яких він має брати участь.
