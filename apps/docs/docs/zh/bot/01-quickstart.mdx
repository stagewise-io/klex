对于大多数用户，Klex 推荐使用云托管机器人。你也可以在自己的计算机上运行机器人，并选择是否注册到 Klex Cloud。你需要访问模型提供商；使用云端设置还需要 Klex Cloud 账户。

## 创建云托管机器人

1. 登录 [Klex Cloud](https://cloud.klex.bot)，开始创建机器人。
2. 选择云托管，按照步骤为机器人命名、定义其[灵魂](/bot/concepts/soul)，并配置提供商和模型。
3. 连接机器人需要的应用或计算机。请参阅[连接](/bot/concepts/brain-and-computers)，了解如何管理访问权限。

在已连接的应用中向机器人发送消息，检查它是否响应。你可以在 Cloud 控制台查看其活动。

## 安装 Klex 以自托管

要在自己的计算机上运行机器人，请在终端中安装 Klex：

**macOS、Linux 或 WSL：**

```sh
curl -fsSL https://klex.bot/install.sh | sh
```

**Windows（PowerShell）：**

```powershell
irm https://klex.bot/install.ps1 | iex
```

### 使用 Cloud 辅助设置

在 Klex Cloud 中开始设置自托管机器人，并按照注册说明操作。机器人运行在你的计算机上；Cloud 提供管理界面。

### 独立设置

要在不注册到 Cloud 的情况下运行机器人，请启动交互式应用：

```sh
klex --no-cloud
```

1. 按 `a` 创建机器人并输入其名称。
2. 在 **Settings → Providers & Endpoints** 中配置模型提供商。在 **Model Selection** 中选择有效的聊天模型。
3. 打开 **Settings → Soul**，创建描述机器人性格和工作的灵魂。
4. 在 **Settings → MCP Servers** 中连接机器人需要的服务器。在已连接的应用中配置机器人账户的权限。

要接收外部频道的事件，请连接支持相应资源更新、MCP Events 或 Klex [推送通知扩展](https://github.com/stagewise-io/klex/tree/main/packages/mcp-extension-push-notifications)的 MCP 服务器。

## 使用命令创建自托管机器人

要创建并启动注册到 Cloud 的机器人，请使用 Klex Cloud 提供的注册令牌：

```sh
klex --create-bot --cloud-enroll-token <token>
```

你也可以通过 `KLEX_CLOUD_ENROLLMENT_TOKEN` 提供令牌，而不使用命令行参数。添加 `--headless` 可在没有终端界面的情况下运行。

要创建独立运行的机器人，请指定名称：

```sh
klex --create-bot --no-cloud --bot-name Ada
```

创建时不能使用 `--data-dir` 或 `KLEX_DATA_DIR`，它们用于选择现有机器人。机器人开始工作前，请配置提供商和聊天模型。

如果机器人没有响应，请参阅[故障排查步骤](/bot/guides/observability#if-a-bot-does-not-respond)（英文）。
