将现有智能体的工作和有用知识转交给 Klex Bot。首先整理它做什么、知道什么以及使用哪些资源。

<a id="prepare-the-workflow"></a>

## 收集必要信息

请当前智能体提供交接文档。以下提示词可作为起点，请根据要迁移的工作进行调整。

~~~text
我要将你的工作转交给一个新的 AI 智能体。请创建一份交接文档，供新智能体及其管理员继续你的工作。

请使用清晰的标题和实用细节，包含以下内容：

1. 角色和优先级：你的目的、职责、偏好的工作方式以及与你合作的人员或团队。
2. 知识和背景：你学到的重要事实、术语、决策、偏好和相关背景。指出在哪里可以找到支持信息。
3. 日常工作和日程：重复任务、时间和时区、触发条件、预期输出以及结果发送位置。
4. 常见流程：逐步工作流程、决策点、交接、示例和结果检查方法。
5. 技能和经验：可复用的程序、以往工作的经验、常见问题及其处理方法。
6. 连接和访问权限：每个流程所需的应用、账号、资源和功能。描述所需访问权限，不要包含凭据。
7. 未完成工作：当前任务、待定决策、截止日期及每项工作的下一步。

使用你可获得的信息。对无法访问或不确定的内容做标记，不要猜测。不要包含密码、令牌、API 密钥或其他机密。标记敏感信息，以便我决定分享什么。请将交接内容作为一份结构化文档返回。
~~~

检查交接文档的准确性和敏感信息。补充旧智能体无法访问的内容，例如存放在其他地方的日程或指示。

<a id="set-up-your-klex-bot"></a>

## 设置 Klex Bot

1. [创建 Klex Bot](/zh/bot/quickstart)。使用交接文档描述其工作和性格。
2. 将交接文档的相关内容提供给 Bot，并告诉它要接手哪些工作。使用 [Agent Skills](/zh/bot/concepts/agent-skills)处理可复用程序。
3. [连接工作所需的应用和计算机](/zh/bot/concepts/brain-and-computers)，并在每个服务中配置 Bot 账号的访问权限。
4. 使用连接的日程服务设置重复工作。请参阅[自动执行重复任务](/zh/bot/guides/recurring-tasks)。

<a id="test-before-switching-over"></a>

## 检查交接

尝试一项有代表性的任务并检查结果。确认 Bot 能访问资源、向正确位置报告并接收计划任务。新工作流程运行后，移除不再需要的旧智能体访问权限和日程。
