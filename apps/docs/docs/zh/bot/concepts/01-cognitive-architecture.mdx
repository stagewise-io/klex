Klex 机器人在自己的环境中运行，该环境管理其活动会话和[记忆](/bot/concepts/memory)。机器人在通过 [MCP](/bot/concepts/mcp) 连接的外部计算机和应用中工作。

<a id="技术基础"></a>
<a id="主会话"></a>

## 常规会话

在 Klex 中，常规会话可以访问已连接的 MCP 服务器。机器人在其中处理传入事件，并可以在连接的环境中工作。可执行的操作取决于连接及其权限。

<a id="工具会话"></a>

## 独立任务

机器人可以使用独立会话处理内部任务。例如，它可以就复杂问题请求咨询，并在工作中考虑咨询结果。不要假设多个请求会同时处理或在特定时间内完成。

<a id="上帝会话"></a>

## God Messages

[God Messages](/bot/concepts/god-messages) 是在独立于常规对话的会话中处理的管理指令。例如，它们可以请求更改[灵魂](/bot/concepts/soul)。在 Klex 中，管理员也可以在 Soul 设置中或通过 Admin API 创建和更新灵魂。

有关机器人的环境和连接的更多信息，请参阅 [Klex 机器人的工作原理](/bot/concepts/how-bots-work)。
