Klex 机器人在自己的环境中运行，该环境管理其活动会话和[记忆](/bot/concepts/memory)。机器人在通过 [MCP](/bot/concepts/mcp) 连接的外部计算机和应用中工作。

## 常规会话

常规会话可以访问已连接的 MCP 服务器。机器人在其中处理传入事件，并可以在连接的环境中工作。可执行的操作取决于连接及其权限。

<a id="工具会话"></a>
<a id="utility-sessions"></a>

## 独立任务

机器人可以使用独立会话处理内部任务。例如，它可以就复杂问题请求咨询，并在工作中考虑咨询结果。
