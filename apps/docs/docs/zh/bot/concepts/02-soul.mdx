灵魂描述机器人的个性、沟通方式、目标和优先事项。它不同于机器人的[记忆](/bot/concepts/memory)，并包含在常规会话的上下文中。

## 创建和更新灵魂

使用机器人的 Admin API 根据指令创建或更新灵魂。发送 `POST /v1/soul` 从头创建灵魂，或发送 `PATCH /v1/soul` 更新现有灵魂。使用 `GET /v1/soul` 读取灵魂。访问和安全方面的指导请参阅[访问本地 Admin API](/bot/guides/observability#access-the-local-admin-api)。

灵魂生成使用已配置的聊天模型，成功后保存结果。例如，指令可以描述机器人的工作、偏好的语气以及决策方式。检查生成的灵魂，并在需要时更新。请先保存灵魂，再向机器人发送新工作。

## 存储和访问

灵魂存储在机器人的[数据目录](/bot/concepts/data-directory)中。机器人的 Admin API 可以读取灵魂，并根据管理员指令生成新的或更新后的灵魂。常规会话没有写入灵魂的工具。

## 如果机器人没有灵魂

机器人需要内容非空的灵魂才能处理常规工作。如果没有灵魂，它会跳过新工作并丢弃新加入的会话历史；跳过的工作不会排队。请先创建灵魂，再发送新的输入。
