灵魂描述机器人的个性、沟通方式、工作和优先事项。它不同于机器人的[记忆](/bot/concepts/memory)，并包含在常规会话的上下文中。

## 创建和更新灵魂

在自托管的 Klex 0.30.1 应用中，打开 **Settings → Soul**。你可以在此查看已保存的灵魂、根据指令创建或更新灵魂，或重新创建灵魂。生成过程使用已配置的聊天模型，并保存成功生成的结果。在保存灵魂之前，常规会话会保持暂停。

例如，你可以在指令中描述机器人的工作、偏好的语气以及决策方式。检查生成的灵魂，如果它不符合预期，请更新它。

Klex 也支持使用 [God Messages](/bot/concepts/god-messages) 请求更改灵魂。这不是创建或更新灵魂的唯一方式。

## 存储和访问

灵魂存储在机器人的[数据目录](/bot/concepts/data-directory)中。在 Klex 0.30.1 中，机器人的 Admin API 可以读取灵魂，并根据管理指令创建新的或更新后的灵魂。常规会话没有写入灵魂的工具。
