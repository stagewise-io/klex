---
title: 机器人的灵魂
description: 使用灵魂来控制 Klex 机器人的行为和举止。
---

灵魂是对机器人用途、性格和行为的简要描述。
它存储在机器人的数据目录中，并始终加载到其上下文中，为机器人的行为和反应设定基线。

灵魂不是直接编写的。相反，机器人可以接收一条上帝消息来描述它是谁以及它如何行事。基于该上帝消息，机器人可以创建或更新其灵魂。

灵魂不能在上帝消息聊天之外被更新。

## 创建机器人的灵魂

在机器人生命周期的开始，机器人的创建者必须触发机器人编写其灵魂。这可以通过两种方式完成：

### [创造者模式（仅限云端）](#creator-mode)

在设置向导中，云端提供**创造者模式**。创造者模式让你可以像设计电子游戏角色一样设计机器人的性格。

### [上帝消息模式](#god-message-mode)

你也可以通过云端或 CLI 中的设置向导发送上帝消息。该上帝消息应该以足够详细的方式描述机器人的预期行为，以确保良好的效果。
