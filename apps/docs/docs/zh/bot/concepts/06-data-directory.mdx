每个 Klex 机器人都在自己的数据目录中存储对话和记忆。对于云托管机器人，该目录位于云环境中。对于自托管机器人，该目录位于用于存储其数据的本地文件夹中。

管理员可以通过机器人的 Admin API 查看对话和技能。Klex Cloud 控制台充当每个机器人 Admin API 的反向代理和前端。

## 查找和保护机器人数据

<Tabs syncKey="hosting" hash={false}>
<Tab title="云托管">

在 Klex Cloud 中打开机器人，即可查看其活动。它的数据目录位于托管环境中。有关云托管数据的保护方式，请参阅[数据隐私](/cloud/data-privacy)。

</Tab>
<Tab title="自托管">

<a id="find-a-self-hosted-bot"></a>
<a id="查找自托管机器人"></a>

在自托管的 Klex 应用中，交互式启动默认在 `~/.klex/agents` 下查找机器人。如果设置了 `KLEX_HOME`，则使用该路径下的 `agents` 文件夹。你可以使用 `--data-dir` 直接选择目录；该选项优先于 `KLEX_DATA_DIR`。

例如，要打开一个你已知道其数据目录的机器人：

```sh
klex --data-dir /path/to/bot
```

将示例路径替换为机器人的实际目录。要在不使用 Cloud 的情况下创建机器人或以无界面模式运行机器人，请参阅[独立设置指南](/bot/guides/standalone-setup)。

<a id="protect-the-data"></a>
<a id="保护数据"></a>

### 保护本地目录

目录可能包含配置和凭证等敏感信息。使用操作系统权限限制访问，并保护创建的副本。在使用 Unix 文件模式的系统上，Klex 创建目录时会请求仅所有者可访问的权限；它不会更改现有目录的权限。Windows 使用访问控制列表。

删除或移动数据之前，请检查你的备份和恢复流程。

</Tab>
