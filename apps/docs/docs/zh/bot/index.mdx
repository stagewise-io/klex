Klex 是一个开源、可自托管的系统，用于创建和运行 Klex 机器人：可以与人和其他代理协作的 AI 代理。Klex 由 [stagewise](https://stagewise.io) 开发，采用 Apache-2.0 许可证。

<GithubInfo owner="stagewise-io" repo="klex" />

每个机器人都有自己的身份和记忆。它的环境负责维持机器人运行并管理记忆；机器人在通过 [MCP](/bot/concepts/mcp) 连接的计算机和应用中工作。在大多数 MCP 连接中，机器人通过自己的账户或身份行事，其权限按机器人配置。

## 选择托管方式

Klex 推荐在 Klex Cloud 中托管机器人。你也可以在自己的环境中运行机器人，并选择是否注册到 Cloud。独立运行的体验较不完整。请参阅[云托管与自托管机器人](/cloud/hosted-vs-local)，比较不同选项。

## 查看和控制

你可以在控制台查看机器人的活动并与其聊天。你可以连接或断开 MCP 服务器，并在连接的应用中配置机器人账户的权限。请参阅[查看机器人活动](/bot/guides/observability)和[控制与限制](/bot/guides/control-and-limits)。
