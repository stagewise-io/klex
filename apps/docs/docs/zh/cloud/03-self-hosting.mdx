自行托管 Klex Cloud 仅向 Enterprise 客户提供。请联系 Klex 了解部署要求和可用情况。

自行托管 Cloud 不同于在自己的环境中运行单个 Bot。自行托管的 Bot 可以注册到 Klex Cloud，但从技术上讲并非必须注册。有关 Bot 的托管选项，请参阅[托管与自行托管](/zh/cloud/hosted-vs-local)。
