[**Klex Cloud**](https://cloud.klex.bot) 托管 Klex Bot，并提供管理仪表板。您也可以注册自行托管的 Bot。连接 Bot 所需的应用和服务，并在这些服务中配置其账户和权限。

<Panel title="须知">
Klex Cloud 完全是可选的。您可以不使用 Cloud 运行 Klex Bot，并连接自己的 MCP 服务器。
</Panel>

<a id="set-up-a-klex-bot-with-cloud"></a>

## 使用 Cloud 设置 Klex Bot

Cloud 设置向导可帮助您创建由 Cloud 托管的 Bot，或设置自行托管的 Bot。向导会引导您配置 Bot 及其模型。完成设置后，您可以连接应用和服务。

请按照[快速入门指南](/zh/bot/quickstart)开始使用。
