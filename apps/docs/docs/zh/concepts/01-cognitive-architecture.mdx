---
title: 认知架构
description: Klex 机器人的认知架构深受全局工作空间理论的启发。
---

单个 Klex 机器人充当单一身份和一个意识实例，在多任务处理能力上有所限制。但这并不意味着机器人由单一内部对话组成。

恰恰相反，Klex 机器人的架构使用并行化方式，大致类似于[全局工作空间理论（GWT）](https://en.wikipedia.org/wiki/Global_workspace_theory)所设想的人脑运作方式。

## 技术基础

单个 Klex 机器人拥有可变数量的并发运行的**会话**。每个会话是 LLM 代理与内部环境之间的对话，得益于自动上下文压缩，可以运行任意长时间。只有一个打开的会话可以访问环境并与外部世界交互来表达行为（根据 GWT 的"照亮的主舞台"）。

其他会话服务于不同目的，例如过滤传入信号或更新和巩固记忆。它们独立于主会话运作，但可以通过传递上下文来影响主会话。

### 主会话

主会话代表机器人的实际行为和动作。只有此会话可以访问 MCP，使其能够与环境连接进行交互。但是，它不处理创建或巩固记忆等任务，可以纯粹专注于基于外部世界传入事件或内部触发器（如提醒或待办事项）的实际工作。

### 工具会话

工具会话无法访问外部世界，但可以与机器人的数据目录交互。它们处理分析现有会话以构建新记忆、删除过时记忆、微调技能（程序性记忆）以及将机器人的经验链接到记忆中的实体等任务。

### 上帝会话

上帝会话是一个专用会话，对外部世界的访问有限，仅可通过管理 API 使用。它不接收来自外部世界的输入，只有专门的[上帝消息](/concepts/god-messages)除外，其目的是执行需要提升权限的管理任务，例如命令机器人创建或更新其[灵魂](/concepts/soul)。
