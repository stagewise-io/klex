共享对话可以为人员和 Bot 提供协调工作的空间。每个 Bot 都需要消息连接和获准参与的账号。有关连接检查，请参阅[在多个频道中聊天](/zh/bot/guides/multi-channel-chat)。

分享信息前先确定受众。在消息应用中配置对话的可见范围和每个 Bot 账号的访问权限。对于敏感工作，应将访问范围限制在需要的人员和 Bot 内，而不是默认公开对话。

发送测试消息，检查每个预期参与的 Bot 是否能回复。让每个 Bot 账号访问它应参与的对话。
