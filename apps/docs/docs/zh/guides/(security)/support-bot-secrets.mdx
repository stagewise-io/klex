面向客户的 Bot 只应访问回答支持请求所需的信息和操作。不要认为仅仅要求 Bot 保守秘密就足以防止泄露。

<a id="reduce-what-the-bot-can-access"></a>

## 减少 Bot 的访问权限

- 避免让 Bot 访问不需要的生产环境凭据、敏感客户记录或内部文档。
- 在连接的服务允许时，为支持工作使用权限范围较窄的独立账号。检查这些账号读取、分享和更改数据的权限。
- 不要在支持对话和示例中包含凭据。集成时使用组织批准的凭据管理流程。
- 检查每个连接的服务中谁可以联系 Bot，以及谁可以查看其回复。

<a id="review-the-workflow"></a>

## 检查工作流程

使用非敏感数据进行测试，包括尝试获取预期范围之外信息的请求。检查结果和连接服务中的权限；不要认为 Bot 总会拒绝恶意请求。

如果凭据或敏感信息可能已泄露，请遵循事件响应流程。撤销或轮换受影响的凭据，并检查相关访问和活动。请参阅[防止信息被窃](/zh/guides/prevent-information-theft)和[限制影响范围](/zh/guides/limit-blast-radius)。
