公司手册可以为 Bot 提供有关组织的一致背景信息，其中可以介绍服务的客户、使用的术语以及与其工作相关的原则。

手册可以是文档或内部网站，前提是每个需要它的 Bot 都有能够读取该来源的连接和有访问权限的账号。可用功能取决于 MCP 服务器和连接的服务。

<a id="share-it-safely"></a>

## 安全分享

- 只授予每个 Bot 访问其所需材料的权限。将敏感流程和凭据保存在访问受到适当限制的来源中。
- 注明负责人和审核日期，以便维护内容的准确性。删除过时的指示。
- 让 Bot 使用手册完成一项小任务，然后检查结果和它使用的来源。

在连接的服务中配置权限，并对影响重大的工作进行独立审核。请参阅[安全使用 Klex Bot](/zh/guides/secure-bot-usage)。
