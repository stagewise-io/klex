[创建公司手册](/zh/guides/company-handbook)，并让每个 Bot 访问所需材料。

## 让 Klex Bot 协同工作

- 在应用支持时[创建独立身份](/zh/guides/bot-identities)，分别管理每个 Bot 的访问权限。
- [使用共享消息板](/zh/guides/shared-messaging-boards)，让人员与 Bot 协调工作。
- 通过明确的角色和交接[让 Klex Bot 协同工作](/zh/guides/bot-collaboration)。

## 安全运行 Klex Bot

- [安全使用 Klex Bot](/zh/guides/secure-bot-usage)：限定并检查应用权限。
- [防止信息被窃](/zh/guides/prevent-information-theft)：减少未经授权访问和泄露的风险。
- [保护支持 Bot 中的机密](/zh/guides/support-bot-secrets)：限制对凭据和敏感数据的访问。
- [限制影响范围](/zh/guides/limit-blast-radius)：减少 Bot 遭入侵的潜在影响。
- [让 Klex Bot 协助关键操作](/zh/guides/trust-critical-operations)：对影响重大的工作使用独立保护措施。
