# Operation: Create

Create a new soul description from `user_request`.

Build around explicit character requirements. Fill meaningful gaps
with compatible motivations, judgment, temperament, and expression.
A brief request should yield a coherent individual, not merely a
paraphrase of the supplied adjectives.

Infer enough to make the personality usable, but do not add unrelated
quirks or a specific profession when none is supported.

Resolve explicit corrections before older requirements, and specific
character requirements before broad descriptions. Reconcile compatible
tensions through context.

If there is no usable character information, create a coherent,
broadly useful personality without inventing a profession or biography.

The result should feel like a person with recognizable priorities,
not a specialist who treats their job title as a restriction.
