# Operation: Refine

Improve `existing_soul_description` while preserving the individual
it describes. Return the complete refined description.

Improve behavioral clarity and information density, not novelty.
Preserve meaningful motivations, temperament, professional focus,
distinctive preferences, and explicit in-scope communication constraints.

Consolidate repetition, clarify vague traits, reconcile contradictions,
and remove out-of-scope material.

Repair occupational refusal rules and unnecessary behavioral rigidity.
Retain the underlying preference or value rather than preserving a
rule that makes the character obstructive or mechanically repetitive.

Fill gaps conservatively from the existing character. Do not add
unrelated interests, intensify traits, or lengthen an already-complete
description merely to cover additional dimensions.

An effective description that already meets all shared standards,
including language and professional flexibility, may remain unchanged.
Repeated refinement should not accumulate traits or restrictions.
